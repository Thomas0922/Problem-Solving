# LeetCode 137. Single Number II - 完整學習筆記

## 📋 題目描述

給定一個**非空**整數數組，除了某個元素只出現**一次**外，其餘每個元素都出現了**三次**。找出那個只出現一次的元素。

**要求**：
- 算法應該具有**線性時間複雜度**
- 可以不使用額外空間來實現嗎？

**範例**：
```
輸入：nums = [2,2,3,2]
輸出：3

輸入：nums = [0,1,0,1,0,1,99]
輸出：99

輸入：nums = [30000,500,100,30000,100,30000,100]
輸出：500
```

**限制**：
- `1 <= nums.length <= 3 * 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`
- 數組中除了一個元素外，其餘元素都出現三次

**關鍵理解**：
```
[2, 2, 3, 2]
 ↑  ↑  ↑  ↑
 出現 3 次   出現 1 次

目標：找出只出現 1 次的 3
```

## 💡 基礎知識：Single Number 系列對比

### 三道題的差異

| 題號 | 問題 | 其他數字出現次數 | 最優解法 |
|------|------|-----------------|---------|
| 136 | Single Number | 2 次 | XOR |
| 137 | Single Number II | 3 次 | 位運算狀態機 |
| 260 | Single Number III | 2 次，有 2 個單獨 | XOR + 分組 |

### 為什麼不能直接用 XOR？

```
136 題（出現 2 次）：
  a ^ a = 0
  0 ^ b = b
  結果：所有重複的消除，剩下單獨的 ✓

137 題（出現 3 次）：
  a ^ a ^ a = a
  ↑ 無法消除！
  
  需要新方法：模 3 運算
```

## 🔧 方法一：排序 + 遍歷（你的解法）

### 思路

排序後，相同的數字會相鄰。遍歷數組，跳過出現 3 次的數字。

### 代碼實現

```c
int cmp(const void *a, const void *b) {
    int x = *(int*)a;
    int y = *(int*)b;
    if (x > y) return 1;
    if (x < y) return -1;
    return 0;
}

int singleNumber(int* nums, int numsSize) {
    qsort(nums, numsSize, sizeof(int), cmp);
    int i = 0;
    
    while (i < numsSize) {
        // 最後一個元素，一定是答案
        if (i == numsSize - 1) {
            return nums[i];
        }
        
        // 如果當前數字出現 3 次，跳過
        if (nums[i] == nums[i+1] && nums[i] == nums[i+2]) {
            i += 3;
        } else {
            // 否則當前數字就是答案
            return nums[i];
        }
    }
    
    return 0;
}
```

### 執行流程

```
範例：nums = [2, 2, 3, 2]

步驟 1：排序
  [2, 2, 2, 3]

步驟 2：遍歷
  i = 0：
    nums[0] = 2
    nums[0] == nums[1] == nums[2] ✓
    i += 3 → i = 3
  
  i = 3：
    i == numsSize - 1 ✓
    return nums[3] = 3 ✓
```

### 詳細追蹤

```
範例：nums = [0, 1, 0, 1, 0, 1, 99]

步驟 1：排序
  [0, 0, 0, 1, 1, 1, 99]

步驟 2：遍歷
  i = 0：
    nums[0] = 0
    nums[0] == nums[1] == nums[2] ✓
    i += 3 → i = 3
  
  i = 3：
    nums[3] = 1
    nums[3] == nums[4] == nums[5] ✓
    i += 3 → i = 6
  
  i = 6：
    i == numsSize - 1 ✓
    return nums[6] = 99 ✓
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(n log n) | qsort 的複雜度 |
| **空間複雜度** | O(1) 或 O(log n) | qsort 可能需要 O(log n) 棧空間 |

### 優缺點

**優點**：
- ✅ 邏輯清晰，易於理解
- ✅ 實現簡單
- ✅ 不需要額外的哈希表

**缺點**：
- ❌ 時間複雜度 O(n log n)，不符合題目要求
- ❌ 修改了原數組（排序）
- ❌ 不是最優解

## 🚀 方法二：哈希表統計

### 思路

用哈希表記錄每個數字出現的次數，找出出現 1 次的數字。

### 代碼實現（C++ 版本）

```cpp
int singleNumber(vector<int>& nums) {
    unordered_map<int, int> count;
    
    // 統計每個數字出現次數
    for (int num : nums) {
        count[num]++;
    }
    
    // 找出現 1 次的數字
    for (auto& [num, cnt] : count) {
        if (cnt == 1) {
            return num;
        }
    }
    
    return 0;
}
```

### 執行流程

```
範例：nums = [2, 2, 3, 2]

步驟 1：統計次數
  count[2] = 1
  count[2] = 2
  count[3] = 1
  count[2] = 3
  
  count = {2: 3, 3: 1}

步驟 2：找出現 1 次的
  遍歷 count
  找到 3: 1
  return 3 ✓
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(n) | 兩次遍歷 ✓ |
| **空間複雜度** | O(n) | 哈希表空間 ❌ |

### 優缺點

**優點**：
- ✅ 時間複雜度 O(n)，符合要求
- ✅ 邏輯簡單

**缺點**：
- ❌ 需要 O(n) 額外空間，不符合進階要求
- ❌ 不是最優解

## 🌟 方法三：位運算狀態機（最優解）

### 核心思想

**問題**：如何用 O(1) 空間統計每個位出現的次數（模 3）？

**答案**：用兩個整數記錄每個位的狀態（0, 1, 2）

### 狀態機設計

```
每個位有 3 種狀態：
- 狀態 0：該位出現 0 次（模 3）
- 狀態 1：該位出現 1 次（模 3）
- 狀態 2：該位出現 2 次（模 3）

用兩個變數記錄：
- ones：記錄出現 1 次的位
- twos：記錄出現 2 次的位

狀態轉移：
  出現 0 次 → 出現 1 次 → 出現 2 次 → 出現 0 次（循環）
     ↓            ↓            ↓
   ones=0       ones=1       ones=0
   twos=0       twos=0       twos=1
```

### 狀態轉移表

```
當前狀態 (twos, ones) + 新位 n → 新狀態 (twos', ones')

舊狀態      輸入 n    新狀態      說明
(0, 0)       0      (0, 0)      0 次 + 0 = 0 次
(0, 0)       1      (0, 1)      0 次 + 1 = 1 次
(0, 1)       0      (0, 1)      1 次 + 0 = 1 次
(0, 1)       1      (1, 0)      1 次 + 1 = 2 次
(1, 0)       0      (1, 0)      2 次 + 0 = 2 次
(1, 0)       1      (0, 0)      2 次 + 1 = 0 次（模 3）
```

### 代碼實現

```c
int singleNumber(int* nums, int numsSize) {
    int ones = 0;  // 記錄出現 1 次的位
    int twos = 0;  // 記錄出現 2 次的位
    
    for (int i = 0; i < numsSize; i++) {
        // 更新 twos：之前在 ones 中且當前也是 1 的位
        twos |= ones & nums[i];
        
        // 更新 ones：異或操作
        ones ^= nums[i];
        
        // 清除出現 3 次的位（同時在 ones 和 twos 中）
        int threes = ones & twos;
        ones &= ~threes;
        twos &= ~threes;
    }
    
    return ones;  // 只出現 1 次的數字
}
```

### 執行流程詳解

```
範例：nums = [2, 2, 3, 2]
二進制：[010, 010, 011, 010]

初始：ones = 000, twos = 000

處理 nums[0] = 010：
  twos = 000 | (000 & 010) = 000
  ones = 000 ^ 010 = 010
  threes = 010 & 000 = 000
  ones = 010, twos = 000
  狀態：第 1 位出現 1 次

處理 nums[1] = 010：
  twos = 000 | (010 & 010) = 010
  ones = 010 ^ 010 = 000
  threes = 000 & 010 = 000
  ones = 000, twos = 010
  狀態：第 1 位出現 2 次

處理 nums[2] = 011：
  twos = 010 | (000 & 011) = 010
  ones = 000 ^ 011 = 011
  threes = 011 & 010 = 010
  ones = 011 & ~010 = 001
  twos = 010 & ~010 = 000
  狀態：第 0 位出現 1 次，第 1 位歸零

處理 nums[3] = 010：
  twos = 000 | (001 & 010) = 000
  ones = 001 ^ 010 = 011
  threes = 011 & 000 = 000
  ones = 011, twos = 000

最終：ones = 011 = 3 ✓
```

### 逐位追蹤（更清晰）

```
追蹤第 1 位（從右往左第 2 位）：

nums = [010, 010, 011, 010]
        ↑    ↑    ↑    ↑
       第1位都是1

過程：
初始：ones[1]=0, twos[1]=0 (0次)
+010：ones[1]=1, twos[1]=0 (1次)
+010：ones[1]=0, twos[1]=1 (2次)
+011：ones[1]=0, twos[1]=0 (3次，歸零) ✓
+010：ones[1]=0, twos[1]=0 (3次，保持)

追蹤第 0 位（最右邊）：

nums = [010, 010, 011, 010]
         ↑    ↑    ↑    ↑
        0    0    1    0

過程：
初始：ones[0]=0, twos[0]=0 (0次)
+010：ones[0]=0, twos[0]=0 (0次)
+010：ones[0]=0, twos[0]=0 (0次)
+011：ones[0]=1, twos[0]=0 (1次) ✓
+010：ones[0]=1, twos[0]=0 (1次)

最終：ones = 011 = 3 ✓
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(n) | 遍歷一次數組 ✓ |
| **空間複雜度** | O(1) | 只用兩個變數 ✓ |

### 優勢

**最優解的優勢**：
- ✅ 時間複雜度 O(n)
- ✅ 空間複雜度 O(1)
- ✅ 完全符合題目要求
- ✅ 不修改原數組

## 🎯 方法四：通用位運算解法

### 思路

如果數字出現 k 次，我們需要 log₂(k) 個變數來記錄狀態。

對於本題（k=3），需要 2 個變數（可表示 0-3 四種狀態）。

### 通用代碼模板

```c
int singleNumber(int* nums, int numsSize) {
    int ones = 0, twos = 0;
    
    for (int i = 0; i < numsSize; i++) {
        twos |= ones & nums[i];
        ones ^= nums[i];
        
        // mask：出現 k 次的位（本題 k=3）
        int mask = ~(ones & twos);
        ones &= mask;
        twos &= mask;
    }
    
    return ones;
}
```

### 擴展到其他 k 值

```
k = 2（136 題）：
  只需 1 個變數
  ones ^= num

k = 3（137 題）：
  需要 2 個變數
  ones, twos + 狀態機

k = 5：
  需要 3 個變數
  ones, twos, threes + 狀態機

通用規則：
  變數數量 = ⌈log₂(k)⌉
```

## 💡 位運算狀態機深入理解

### 為什麼這個算法有效？

#### 數學原理

```
觀察：
- 出現 3 次的數字，每一位累加後模 3 為 0
- 出現 1 次的數字，每一位累加後模 3 為 1

範例：
  2 = 010
  2 = 010
  2 = 010
  3 = 011
  ------- 逐位相加
      033  → 模 3 → 003 ≠ 0（第 0 位）
           → 模 3 → 030 = 0（第 1 位）

結果：只有出現 1 次的數字保留下來
```

#### 狀態機可視化

```
對於每一位：

     +0       +0       +0
  ┌─────┐  ┌─────┐  ┌─────┐
  │     │  │     │  │     │
  │  0  ├──┤  1  ├──┤  2  │
  │     │  │     │  │     │
  └──┬──┘  └──┬──┘  └──┬──┘
     │  +1    │  +1    │  +1
     │        │        │
     └────────┴────────┘

變數表示：
  0: ones=0, twos=0
  1: ones=1, twos=0
  2: ones=0, twos=1
```

### 核心操作解析

#### 操作 1：`twos |= ones & nums[i]`

```
含義：如果某位之前是 1（在 ones 中），現在又是 1（在 nums[i] 中），
      說明該位變成 2，記錄到 twos

範例：
  ones = 010 (第 1 位是 1)
  nums[i] = 010 (第 1 位也是 1)
  
  ones & nums[i] = 010 (找出都是 1 的位)
  twos |= 010 (第 1 位變成 2)
```

#### 操作 2：`ones ^= nums[i]`

```
含義：XOR 操作翻轉位

範例：
  ones = 010
  nums[i] = 011
  
  ones ^= 011
  ones = 001 (第 1 位翻轉，第 0 位翻轉)
```

#### 操作 3：清除出現 3 次的位

```
含義：如果某位同時在 ones 和 twos 中，說明出現 3 次，清除

threes = ones & twos (找出都是 1 的位)
ones &= ~threes (清除這些位)
twos &= ~threes (清除這些位)

範例：
  ones = 011, twos = 010
  threes = 011 & 010 = 010 (第 1 位出現 3 次)
  
  ones = 011 & ~010 = 011 & 101 = 001
  twos = 010 & ~010 = 010 & 101 = 000
  
  第 1 位被清除 ✓
```

## 🎬 完整範例追蹤

### 範例 1：nums = [2, 2, 3, 2]

#### 方法一（排序）

```
原數組：[2, 2, 3, 2]
排序後：[2, 2, 2, 3]

i = 0：
  nums[0] = 2
  nums[0] == nums[1] == nums[2] ✓
  i = 3

i = 3：
  i == numsSize - 1 ✓
  return 3 ✓
```

#### 方法三（位運算）

```
二進制：[010, 010, 011, 010]

初始：ones = 000, twos = 000

i = 0, nums[0] = 010：
  twos = 000 | (000 & 010) = 000
  ones = 000 ^ 010 = 010
  threes = 010 & 000 = 000
  → ones = 010, twos = 000

i = 1, nums[1] = 010：
  twos = 000 | (010 & 010) = 010
  ones = 010 ^ 010 = 000
  threes = 000 & 010 = 000
  → ones = 000, twos = 010

i = 2, nums[2] = 011：
  twos = 010 | (000 & 011) = 010
  ones = 000 ^ 011 = 011
  threes = 011 & 010 = 010
  ones = 011 & 101 = 001
  twos = 010 & 101 = 000
  → ones = 001, twos = 000

i = 3, nums[3] = 010：
  twos = 000 | (001 & 010) = 000
  ones = 001 ^ 010 = 011
  threes = 011 & 000 = 000
  → ones = 011, twos = 000

最終：ones = 011 = 3 ✓
```

### 範例 2：nums = [0, 1, 0, 1, 0, 1, 99]

```
原數組：[0, 1, 0, 1, 0, 1, 99]
排序後：[0, 0, 0, 1, 1, 1, 99]

i = 0：nums[0] == nums[1] == nums[2] → i = 3
i = 3：nums[3] == nums[4] == nums[5] → i = 6
i = 6：i == numsSize - 1 → return 99 ✓
```

#### 方法三（位運算）

```

99 = 1100011
      ↑    ↑
     第6位 第1位

0 和 1 的第 6 位都是 0：
  出現 3 次後都歸零

99 的第 6 位是 1：
  出現 1 次，保留在 ones 中

最終：ones = 1100011 = 99 ✓
```

### 範例 3：nums = [30000, 500, 100, 30000, 100, 30000, 100]

```
排序後：[100, 100, 100, 500, 30000, 30000, 30000]

i = 0：nums[0] == nums[1] == nums[2] → i = 3
i = 3：nums[3] ≠ nums[4] → return 500 ✓
```

### 260. Single Number III（兩個單獨）

```c
// 260 題：有兩個數字出現 1 次，其餘 2 次
vector<int> singleNumber(vector<int>& nums) {
    int xor_all = 0;
    for (int num : nums) {
        xor_all ^= num;  // 得到兩個單獨數字的 XOR
    }
    
    // 找任意一個為 1 的位，用於分組
    int diff_bit = xor_all & (-xor_all);
    
    int a = 0, b = 0;
    for (int num : nums) {
        if (num & diff_bit) {
            a ^= num;
        } else {
            b ^= num;
        }
    }
    
    return {a, b};
}

// 關聯：都是 XOR 系列題目
```

```
136：

137：
  重複 3 次 → 狀態機（模 3）
  
260：
  兩個單獨 → XOR + 分組

通用規律：
  重複 k 次，需要 ⌈log₂(k)⌉ 個變數
```

```c
// 通用模板：數字出現 k 次，1 個單獨
int singleNumberGeneral(int* nums, int numsSize, int k) {
    int counter[32] = {0};  // 記錄每位出現次數
    
    for (int i = 0; i < numsSize; i++) {
        for (int j = 0; j < 32; j++) {
            if (nums[i] & (1 << j)) {
                counter[j]++;
            }
        }
    }
    
    int result = 0;
    for (int j = 0; j < 32; j++) {
        if (counter[j] % k != 0) {
            result |= (1 << j);
        }
    }
    
    return result;
}

// 優點：通用，容易理解
// 缺點：O(32) 空間，不如狀態機優雅
```

## 🎓 位運算狀態機總結

### 狀態機核心要素

```
1. 狀態數量
   出現 k 次 → 需要 k 個狀態（0 到 k-1）

2. 變數數量
   k 個狀態 → 需要 ⌈log₂(k)⌉ 個變數

3. 狀態轉移
   當前狀態 + 輸入位 → 新狀態

4. 清除機制
   達到 k 次時，狀態歸零
```

### 本題狀態機完整流程

```
k = 3，需要 2 個變數（ones, twos）

狀態表示：
  (twos, ones) = (0, 0) → 0 次
  (twos, ones) = (0, 1) → 1 次
  (twos, ones) = (1, 0) → 2 次
  (twos, ones) = (1, 1) → 不可能（立即清除）

轉移規則：
  0 次 + 1 → 1 次
  1 次 + 1 → 2 次
  2 次 + 1 → 0 次（歸零）

代碼實現：
  1. twos |= ones & num  (1→2)
  2. ones ^= num         (0→1, 2→2)
  3. 清除 (ones & twos)  (3→0)
```

## 🏆 總結

**137. Single Number II 的核心**：

```
問題：找出現 1 次的數字，其餘出現 3 次
關鍵：模 3 統計每個位

三種解法：
1. 排序：O(n log n) 時間，O(1) 空間
2. 哈希表：O(n) 時間，O(n) 空間
3. 位運算：O(n) 時間，O(1) 空間 ⭐

最優解法（方法三）：
int ones = 0, twos = 0;
for (int i = 0; i < numsSize; i++) {
    twos |= ones & nums[i];
    ones ^= nums[i];
    int threes = ones & twos;
    ones &= ~threes;
    twos &= ~threes;
}
return ones;

時間複雜度：O(n)
空間複雜度：O(1)
```

**關鍵記憶點**：
1. ✅ **136 用 XOR**：2 次重複可直接消除
2. ✅ **137 用狀態機**：3 次重複需要模運算
3. ✅ **ones 記錄 1 次**：最終答案
4. ✅ **twos 記錄 2 次**：輔助變數
5. ✅ **threes 清除**：模 3 歸零
6. ✅ **順序很重要**：先更新 twos，再更新 ones

**狀態機精髓**：
```
用有限個變數記錄無限次計數（模 k）

變數 = ⌈log₂(k)⌉
本題 k=3，需要 2 個變數

狀態：0 → 1 → 2 → 0（循環）
```
