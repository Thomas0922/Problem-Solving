# LeetCode 231. Power of Two - 完整學習筆記

## 📋 題目描述

給你一個整數 `n`，請判斷該整數是否是 2 的冪次方。如果是，返回 `true`；否則，返回 `false`。

如果存在一個整數 `x` 使得 `n == 2^x`，則認為 `n` 是 2 的冪次方。

**範例**：
```
輸入：n = 1
輸出：true
解釋：2^0 = 1

輸入：n = 16
輸出：true
解釋：2^4 = 16

輸入：n = 3
輸出：false

輸入：n = 0
輸出：false

輸入：n = -2147483648
輸出：false
解釋：負數不是 2 的冪
```

**限制**：
- `-2^31 <= n <= 2^31 - 1`

**進階**：你能夠不使用循環/遞歸解決此問題嗎？

---

## 💡 核心觀察

### 2 的冪的特徵

```
2^0 = 1    → 二進制：00000001  ← 只有 1 個 '1'
2^1 = 2    → 二進制：00000010  ← 只有 1 個 '1'
2^2 = 4    → 二進制：00000100  ← 只有 1 個 '1'
2^3 = 8    → 二進制：00001000  ← 只有 1 個 '1'
2^4 = 16   → 二進制：00010000  ← 只有 1 個 '1'

非 2 的冪：
3 = 00000011  ← 有 2 個 '1'
5 = 00000101  ← 有 2 個 '1'
6 = 00000110  ← 有 2 個 '1'
7 = 00000111  ← 有 3 個 '1'
```

**關鍵發現**：
> 2 的冪在二進制表示中**有且僅有 1 個 '1'**！

## 🔧 方法一：循環除法（直覺解法）

### 思路

不斷除以 2，檢查：
- 如果過程中出現奇數（且不是 1）→ 不是 2 的冪
- 如果最後剩下 1 → 是 2 的冪

### 代碼實現

```c
bool isPowerOfTwo(int n) {
    // 特殊情況：0 和負數不是 2 的冪
    if (n <= 0) return false;
    
    // 不斷除以 2
    while (n != 1) {
        if (n % 2 != 0) {  // 遇到奇數（不是 1）
            return false;   // 不是 2 的冪
        }
        n = n / 2;  // 除以 2
    }
    
    return true;  // 最後剩下 1，是 2 的冪
}
```

### 執行流程

#### 範例 1：n = 16（是 2 的冪）

```
n = 16

迭代 1：
  n != 1 ✓
  n % 2 = 0 → 繼續
  n = 16 / 2 = 8

迭代 2：
  n != 1 ✓
  n % 2 = 0 → 繼續
  n = 8 / 2 = 4

迭代 3：
  n != 1 ✓
  n % 2 = 0 → 繼續
  n = 4 / 2 = 2

迭代 4：
  n != 1 ✓
  n % 2 = 0 → 繼續
  n = 2 / 2 = 1

迭代 5：
  n == 1 → 跳出循環

返回：true ✓
```

#### 範例 2：n = 6（不是 2 的冪）

```
n = 6

迭代 1：
  n != 1 ✓
  n % 2 = 0 → 繼續
  n = 6 / 2 = 3

迭代 2：
  n != 1 ✓
  n % 2 = 1 → 是奇數！
  返回：false ✓
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(log n) | 每次除以 2，最多循環 log₂(n) 次 |
| **空間複雜度** | O(1) | 只用常數空間 |

### 優缺點

**優點**：
- ✅ 邏輯清晰，易於理解
- ✅ 不需要位運算知識
- ✅ 正確性高

**缺點**：
- ❌ 需要循環，時間複雜度 O(log n)
- ❌ 沒有利用二進制特性

## 🚀 方法二：位運算 - Brian Kernighan（最優解）

### 核心技巧

**還記得 191 題學的 `n & (n-1)` 嗎？**

```
n & (n - 1) 的作用：消除 n 最右邊的一個 '1'
```

**關鍵推論**：
```
如果 n 只有 1 個 '1'（2 的冪）
→ n & (n-1) 消除這個 '1' 後
→ 結果是 0

如果 n 有多個 '1'（不是 2 的冪）
→ n & (n-1) 消除一個 '1' 後
→ 結果不是 0
```

### 代碼實現

```c
bool isPowerOfTwo(int n) {
    return n > 0 && (n & (n - 1)) == 0;
}
```

**一行代碼！** 😎

### 詳細推導

#### 為什麼這樣判斷？

```
條件 1：n > 0
  - 排除 0 和負數
  - 因為它們不是 2 的冪

條件 2：(n & (n-1)) == 0
  - 2 的冪只有 1 個 '1'
  - 消除這個 '1' 後變成 0
```

### 執行流程

#### 範例 1：n = 8（是 2 的冪）

```
n = 8 (二進制：1000)
n - 1 = 7 (二進制：0111)

n & (n-1) 計算：
    1000
  & 0111
  ------
    0000  → 結果是 0 ✓

檢查：
  n > 0：8 > 0 ✓
  (n & (n-1)) == 0：0 == 0 ✓
  
返回：true ✓
```

#### 範例 2：n = 6（不是 2 的冪）

```
n = 6 (二進制：0110)
n - 1 = 5 (二進制：0101)

n & (n-1) 計算：
    0110
  & 0101
  ------
    0100  → 結果是 4，不是 0 ✓

檢查：
  n > 0：6 > 0 ✓
  (n & (n-1)) == 0：4 == 0 ✗
  
返回：false ✓
```

#### 範例 3：n = 1（是 2 的冪）

```
n = 1 (二進制：0001)
n - 1 = 0 (二進制：0000)

n & (n-1) 計算：
    0001
  & 0000
  ------
    0000  → 結果是 0 ✓

檢查：
  n > 0：1 > 0 ✓
  (n & (n-1)) == 0：0 == 0 ✓
  
返回：true ✓
```

#### 範例 4：n = 0（不是 2 的冪）

```
n = 0

檢查：
  n > 0：0 > 0 ✗
  
返回：false ✓（短路求值，不檢查第二個條件）
```

#### 範例 5：n = -4（負數）

```
n = -4

檢查：
  n > 0：-4 > 0 ✗
  
返回：false ✓
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(1) | 只需要一次位運算 ⭐ |
| **空間複雜度** | O(1) | 只用常數空間 |

### 優勢

**相比方法一的優勢**：
- ✅ 時間複雜度：O(log n) → O(1)
- ✅ 代碼極簡：一行代碼
- ✅ 不需要循環
- ✅ 效率極高
- ✅ 面試加分項 ⭐

## 🎯 與 191 題的聯繫

這題是 **191. Number of 1 Bits** 學到的 `n & (n-1)` 技巧的經典應用！

### 191 題回顧

```c
// 191. Number of 1 Bits
int hammingWeight(int n) {
    int count = 0;
    while (n) {
        n = n & (n - 1);  // 消除一個 '1'
        count++;
    }
    return count;
}
```

**核心技巧**：`n & (n-1)` 消除最右邊的 '1'

### 231 題應用

```c
// 231. Power of Two
bool isPowerOfTwo(int n) {
    return n > 0 && (n & (n - 1)) == 0;
}
```

**應用推論**：
```
如果只有 1 個 '1'（2 的冪）
→ 消除後變 0
→ (n & (n-1)) == 0

如果有多個 '1'（不是 2 的冪）
→ 消除後不是 0
→ (n & (n-1)) != 0
```

### 知識遷移

| 題目 | 問題 | 技巧應用 |
|------|------|---------|
| 191 | 統計 '1' 個數 | 用 `n & (n-1)` 不斷消除 '1' |
| 231 | 判斷是否只有 1 個 '1' | 用 `n & (n-1)` 檢查消除後是否為 0 |

**學習啟示**：
> 掌握一個核心技巧後，要學會在不同場景下靈活應用！

## 🔄 方法三：統計 '1' 的個數

### 思路

既然 2 的冪只有 1 個 '1'，那麼：
```
統計 '1' 個數 == 1 → 是 2 的冪
統計 '1' 個數 != 1 → 不是 2 的冪
```

### 代碼實現

```c
bool isPowerOfTwo(int n) {
    if (n <= 0) return false;
    
    // 使用 191 題的算法統計 '1' 個數
    int count = 0;
    while (n) {
        n = n & (n - 1);
        count++;
    }
    
    return count == 1;
}
```

**或者直接調用 191 題的函數**：
```c
bool isPowerOfTwo(int n) {
    return n > 0 && hammingWeight(n) == 1;
}
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(1) | 最多檢查 32 位 |
| **空間複雜度** | O(1) | 常數空間 |

### 評價

**優點**：
- ✅ 邏輯直觀
- ✅ 復用 191 題知識

**缺點**：
- ❌ 比方法二複雜
- ❌ 需要循環（雖然最多 32 次）

**建議**：
- 方法二更優雅，推薦使用

## 🌟 方法四：取出最右邊的 '1'（進階技巧）

### 核心技巧

**新技巧**：`n & -n` 可以取出 n 最右邊的 '1'

```
n = 12 (二進制：1100)
-n 的計算（二補數）：
  ~n = 0011（取反）
  -n = 0100（加 1）

n & -n：
    1100
  & 0100
  ------
    0100  ← 只保留最右邊的 '1'
```

### 推論

```
如果 n 是 2 的冪（只有 1 個 '1'）
→ n & -n 取出這個 '1'
→ 結果就是 n 本身
→ n & -n == n

如果 n 不是 2 的冪（多個 '1'）
→ n & -n 只取出最右邊的 '1'
→ 結果小於 n
→ n & -n != n
```

### 代碼實現

```c
bool isPowerOfTwo(int n) {
    return n > 0 && (n & -n) == n;
}
```

### 執行流程

#### 範例 1：n = 8

```
n = 8 (1000)
-n 的計算：
  ~8 = ...11110111
  -8 = ...11111000

n & -n：
    00001000
  & 11111000
  ----------
    00001000 = 8

檢查：(n & -n) == n
      8 == 8 ✓
      
返回：true ✓
```

#### 範例 2：n = 6

```
n = 6 (0110)
-n 的計算：
  ~6 = ...11111001
  -6 = ...11111010

n & -n：
    00000110
  & 11111010
  ----------
    00000010 = 2

檢查：(n & -n) == n
      2 == 6 ✗
      
返回：false ✓
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(1) | 只需要一次位運算 |
| **空間複雜度** | O(1) | 常數空間 |

### 評價

**優點**：
- ✅ 時間複雜度 O(1)
- ✅ 一行代碼
- ✅ 展示進階位運算知識

**缺點**：
- ⚠️ 需要理解二補數（負數表示）
- ⚠️ 不如方法二直觀

**建議**：
- 方法二更常用
- 這個技巧可以作為加分項

## 💡 位運算技巧總結

### 核心技巧表

| 技巧 | 代碼 | 作用 | 應用題目 |
|------|------|------|---------|
| **消除最右邊的 '1'** | `n & (n - 1)` | 消除 n 最右邊的一個 '1' | 191, 231 ⭐ |
| **取出最右邊的 '1'** | `n & -n` | 只保留 n 最右邊的 '1' | 231 |
| **判斷 2 的冪** | `n > 0 && (n & (n-1)) == 0` | 檢查是否只有 1 個 '1' | 231 |
| **檢查第 k 位** | `n & (1 << k)` | 檢查第 k 位是否為 1 | - |
| **統計 '1' 個數** | 循環用 `n & (n-1)` | Brian Kernighan 算法 | 191 |

### 記憶口訣

```
「減一反轉右，與操作消一」
n - 1：最右邊的 '1' 變 '0'，右邊的 '0' 變 '1'
n & (n-1)：消除最右邊的 '1'

「2 的冪只一位，消一必為零」
2 的冪只有 1 個 '1'
消除後變成 0
```

### 進階思考

#### 1. Power of Four（4 的冪）

```c
bool isPowerOfFour(int n) {
    // 條件 1：必須是 2 的冪
    // 條件 2：'1' 必須在奇數位（0, 2, 4, 6...位）
    return n > 0 && 
           (n & (n - 1)) == 0 && 
           (n & 0x55555555) != 0;
    // 0x55555555 = 01010101010101010101010101010101
    // 用來檢查 '1' 是否在奇數位
}
```

#### 2. 如何生成 2 的冪序列？

```c
// 生成前 n 個 2 的冪
void generatePowers(int n) {
    int power = 1;
    for (int i = 0; i < n; i++) {
        printf("%d ", power);
        power <<= 1;  // 左移相當於乘以 2
    }
}
// 輸出：1 2 4 8 16 32 64 ...
```

#### 3. 找到小於等於 n 的最大 2 的冪

```c
int largestPowerOfTwo(int n) {
    // 將 n 的最高位 '1' 右邊全部填充為 '1'
    n |= n >> 1;
    n |= n >> 2;
    n |= n >> 4;
    n |= n >> 8;
    n |= n >> 16;
    // 然後加 1 再除以 2
    return (n + 1) >> 1;
}
```

## 🏆 總結

**231. Power of Two 的核心**：

```
問題：判斷是否為 2 的冪
關鍵：2 的冪只有 1 個 '1'

最優解：
return n > 0 && (n & (n - 1)) == 0;

原理：
- n > 0：排除 0 和負數
- n & (n-1)：消除最右邊的 '1'
- == 0：如果只有 1 個 '1'，消除後變 0

時間複雜度：O(1)
空間複雜度：O(1)
```

**關鍵記憶點**：
1. 2 的冪 = 只有 1 個 '1'
2. `n & (n-1)` 消除最右邊的 '1'（191 題學的）
3. 如果只有 1 個 '1'，消除後 = 0
4. 一行代碼：`n > 0 && (n & (n-1)) == 0`
5. 這是 191 題技巧的經典應用 ⭐
