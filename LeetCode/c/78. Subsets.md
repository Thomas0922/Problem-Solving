# LeetCode 78. Subsets - 完整學習筆記

## 📋 題目描述

給定一個整數數組 `nums`，數組中的元素**互不相同**。返回該數組所有可能的**子集**（冪集）。

**解集**不能包含重複的子集。你可以按**任意順序**返回解集。

**範例**：
```
輸入：nums = [1,2,3]
輸出：[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]

輸入：nums = [0]
輸出：[[],[0]]
```

**限制**：
- `1 <= nums.length <= 10`
- `-10 <= nums[i] <= 10`
- `nums` 中的所有元素**互不相同**

**關鍵理解**：
```
nums = [1, 2, 3]

所有子集：
  []           ← 空集
  [1]
  [2]
  [3]
  [1,2]
  [1,3]
  [2,3]
  [1,2,3]

總共：2^3 = 8 個子集
```

---

## 💡 基礎知識：子集與冪集

### 什麼是子集？

```
定義：
  集合 A 的子集是指 A 中部分或全部元素組成的集合

例子：
  A = {1, 2, 3}
  
  子集：
  ∅           (空集)
  {1}
  {2}
  {3}
  {1, 2}
  {1, 3}
  {2, 3}
  {1, 2, 3}   (本身)
```

### 冪集（Power Set）

```
定義：
  一個集合的所有子集的集合

性質：
  - 如果集合有 n 個元素
  - 冪集有 2^n 個子集
  
為什麼是 2^n？
  每個元素有兩種選擇：
  - 選它
  - 不選它
  
  所以：2 × 2 × 2 × ... (n 次) = 2^n
```

## 🔧 方法一：回溯法（Backtracking）

### 思路

使用回溯法，遞歸地選擇或不選擇每個元素。

### 決策樹

```
nums = [1, 2, 3]

                    []
          /                    \
       選1                    不選1
        [1]                     []
      /     \                 /    \
   選2      不選2          選2     不選2
   [1,2]    [1]           [2]      []
   /  \     / \           / \      / \
  3  ×    3  ×          3  ×     3  ×
[1,2,3] [1,2] [1,3] [1] [2,3] [2] [3] []

結果：8 個子集
```

### 代碼實現

```c
void backtrack(int* nums, int numsSize, int start, 
               int* current, int currentSize,
               int** result, int* returnSize, int** returnColumnSizes) {
    // 當前子集加入結果
    result[*returnSize] = (int*)malloc(currentSize * sizeof(int));
    for (int i = 0; i < currentSize; i++) {
        result[*returnSize][i] = current[i];
    }
    (*returnColumnSizes)[*returnSize] = currentSize;
    (*returnSize)++;
    
    // 遞歸選擇後續元素
    for (int i = start; i < numsSize; i++) {
        current[currentSize] = nums[i];  // 選擇
        backtrack(nums, numsSize, i + 1, current, currentSize + 1,
                 result, returnSize, returnColumnSizes);
        // 不需要撤銷，因為 currentSize 沒變
    }
}

int** subsets(int* nums, int numsSize, int* returnSize, int** returnColumnSizes) {
    int totalSubsets = 1 << numsSize;  // 2^n
    int** result = (int**)malloc(totalSubsets * sizeof(int*));
    *returnColumnSizes = (int*)malloc(totalSubsets * sizeof(int));
    *returnSize = 0;
    
    int* current = (int*)malloc(numsSize * sizeof(int));
    backtrack(nums, numsSize, 0, current, 0, result, returnSize, returnColumnSizes);
    free(current);
    
    return result;
}
```

### 執行流程

```
nums = [1, 2]

調用棧：
backtrack(start=0, current=[]):
  加入 []
  i=0: 選 1
    backtrack(start=1, current=[1]):
      加入 [1]
      i=1: 選 2
        backtrack(start=2, current=[1,2]):
          加入 [1,2]
          結束（start=2 >= numsSize）
      結束
  i=1: 選 2
    backtrack(start=2, current=[2]):
      加入 [2]
      結束

結果：[[], [1], [1,2], [2]]
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(n × 2^n) | 2^n 個子集，每個複製需 O(n) |
| **空間複雜度** | O(n) | 遞歸棧深度 |

## 🚀 方法二：迭代法

### 思路

從空集開始，每次加入一個新元素，將現有所有子集複製一份並加入新元素。

### 過程演示

```
nums = [1, 2, 3]

初始：[[]]

加入 1：
  原有：[[]]
  複製：[[]] → [[1]]
  結果：[[], [1]]

加入 2：
  原有：[[], [1]]
  複製：[[], [1]] → [[2], [1,2]]
  結果：[[], [1], [2], [1,2]]

加入 3：
  原有：[[], [1], [2], [1,2]]
  複製：[[], [1], [2], [1,2]] → [[3], [1,3], [2,3], [1,2,3]]
  結果：[[], [1], [2], [1,2], [3], [1,3], [2,3], [1,2,3]]
```

### 代碼實現

```c
int** subsets(int* nums, int numsSize, int* returnSize, int** returnColumnSizes) {
    int totalSubsets = 1 << numsSize;  // 2^n
    int** result = (int**)malloc(totalSubsets * sizeof(int*));
    *returnColumnSizes = (int*)malloc(totalSubsets * sizeof(int));
    
    // 初始化：空集
    result[0] = (int*)malloc(0);
    (*returnColumnSizes)[0] = 0;
    *returnSize = 1;
    
    // 迭代加入每個元素
    for (int i = 0; i < numsSize; i++) {
        int currentSize = *returnSize;
        
        // 複製現有子集並加入新元素
        for (int j = 0; j < currentSize; j++) {
            int newSize = (*returnColumnSizes)[j] + 1;
            result[*returnSize] = (int*)malloc(newSize * sizeof(int));
            
            // 複製原子集
            for (int k = 0; k < (*returnColumnSizes)[j]; k++) {
                result[*returnSize][k] = result[j][k];
            }
            
            // 加入新元素
            result[*returnSize][newSize - 1] = nums[i];
            (*returnColumnSizes)[*returnSize] = newSize;
            (*returnSize)++;
        }
    }
    
    return result;
}
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(n × 2^n) | 2^n 個子集，每個複製需 O(n) |
| **空間複雜度** | O(1) | 不算輸出空間 |

## 🌟 方法三：位運算（你的解法 - 最優雅）

### 核心思想

```
關鍵洞察：
  用二進制數表示子集！
  
例如：nums = [1, 2, 3]

二進制數 i 的每一位表示是否選擇對應元素：
  
  i = 0 = 000 → []           (都不選)
  i = 1 = 001 → [3]          (只選第 0 位)
  i = 2 = 010 → [2]          (只選第 1 位)
  i = 3 = 011 → [2, 3]       (選第 0,1 位)
  i = 4 = 100 → [1]          (只選第 2 位)
  i = 5 = 101 → [1, 3]       (選第 0,2 位)
  i = 6 = 110 → [1, 2]       (選第 1,2 位)
  i = 7 = 111 → [1, 2, 3]    (都選)

規律：
  從 0 到 2^n - 1，每個數字對應一個子集！
```

### 位運算原理

```
檢查第 j 位是否為 1：
  i & (1 << j)

例如：
  i = 5 = 101
  
  檢查第 0 位：5 & (1 << 0) = 101 & 001 = 1 ✓
  檢查第 1 位：5 & (1 << 1) = 101 & 010 = 0 ✗
  檢查第 2 位：5 & (1 << 2) = 101 & 100 = 1 ✓
  
  結果：選擇第 0 和第 2 個元素 → [nums[0], nums[2]]
```

### 代碼實現（你的解法）

```c
int** subsets(int* nums, int numsSize, int* returnSize, int** returnColumnSizes) {
    // ===== Step 1: 計算總子集合數量 =====
    int totalsubset = 1 << numsSize;  // 2^n
    
    // ===== Step 2: 分配記憶體 =====
    int** result = malloc(totalsubset * sizeof(int*));
    *returnColumnSizes = malloc(totalsubset * sizeof(int));
    *returnSize = totalsubset;
    
    // ===== Step 3: 用每個數字表示一個子集合 =====
    for (int i = 0; i < totalsubset; i++) {
        // 計算這個子集的大小
        int count = 0;
        for (int j = 0; j < numsSize; j++) {
            if (i & (1 << j)) {
                count++;
            }
        }
        
        // 分配這個子集合的記憶體
        result[i] = malloc(count * sizeof(int));
        (*returnColumnSizes)[i] = count;
        
        // 填入元素
        int idx = 0;
        for (int j = 0; j < numsSize; j++) {
            if (i & (1 << j)) {
                result[i][idx++] = nums[j];
            }
        }
    }
    
    return result;
}
```

### 執行流程

### 詳細追蹤（i = 5 的例子）

```
i = 5, nums = [1, 2, 3]

5 的二進制：101

步驟 1：計算 count
  j = 0：5 & (1 << 0) = 5 & 1 = 101 & 001 = 001 ≠ 0 ✓ count = 1
  j = 1：5 & (1 << 1) = 5 & 2 = 101 & 010 = 000 = 0 ✗
  j = 2：5 & (1 << 2) = 5 & 4 = 101 & 100 = 100 ≠ 0 ✓ count = 2

步驟 2：分配記憶體
  result[5] = malloc(2 * sizeof(int))

步驟 3：填入元素
  j = 0：5 & 1 ≠ 0 → result[5][0] = nums[0] = 1
  j = 1：5 & 2 = 0 → 跳過
  j = 2：5 & 4 ≠ 0 → result[5][1] = nums[2] = 3

結果：result[5] = [1, 3] ✓
```

## 💡 位運算技巧深入理解

### 技巧 1：1 << n（2 的冪）

```
計算 2^n：

1 << 0 = 1   (2^0)
1 << 1 = 2   (2^1)
1 << 2 = 4   (2^2)
1 << 3 = 8   (2^3)
...
1 << n = 2^n

本題應用：
  totalSubsets = 1 << numsSize  // 計算 2^n
```

### 技巧 2：i & (1 << j)（檢查第 j 位）

```
檢查二進制第 j 位是否為 1：

i = 5 = 101

檢查第 0 位：
  1 << 0 = 001
  5 & 1 = 101 & 001 = 001 ≠ 0 ✓ (第 0 位是 1)

檢查第 1 位：
  1 << 1 = 010
  5 & 2 = 101 & 010 = 000 = 0 ✗ (第 1 位是 0)

檢查第 2 位：
  1 << 2 = 100
  5 & 4 = 101 & 100 = 100 ≠ 0 ✓ (第 2 位是 1)
```

### 技巧 3：位運算與子集的對應

```
關鍵映射：
  二進制位 → 元素選擇
  
  位是 1 → 選擇該元素
  位是 0 → 不選擇

範圍：
  0 到 2^n - 1 涵蓋所有可能的選擇組合
  
  例如 n=3：
  000 ~ 111 (0 ~ 7) 共 8 種組合
  對應 2^3 = 8 個子集
```

## ⚠️ 常見錯誤

### 錯誤 1：位運算方向錯誤

```c
// ❌ 錯誤：從高位檢查
for (int j = numsSize - 1; j >= 0; j--) {
    if (i & (1 << j)) {
        result[i][idx++] = nums[j];
    }
}
// 結果：元素順序可能不符合預期

// ✓ 正確：從低位檢查（你的做法）
for (int j = 0; j < numsSize; j++) {
    if (i & (1 << j)) {
        result[i][idx++] = nums[j];
    }
}
```

### 錯誤 2：記憶體分配錯誤

```c
// ❌ 錯誤：忘記分配 returnColumnSizes
int** result = malloc(totalSubsets * sizeof(int*));
// 沒有分配 returnColumnSizes

// ✓ 正確：必須分配
*returnColumnSizes = malloc(totalSubsets * sizeof(int));
```

### 錯誤 3：count 計算錯誤

```c
// ❌ 錯誤：直接用 i 的值
result[i] = malloc(i * sizeof(int));  // 錯！

// ✓ 正確：計算 1 的個數
int count = 0;
for (int j = 0; j < numsSize; j++) {
    if (i & (1 << j)) count++;
}
result[i] = malloc(count * sizeof(int));
```

### 錯誤 4：索引越界

```c
// ❌ 錯誤：idx 沒有重置
int idx = 0;
for (int i = 0; i < totalSubsets; i++) {
    // idx 沒有重置！
    for (int j = 0; j < numsSize; j++) {
        if (i & (1 << j)) {
            result[i][idx++] = nums[j];
        }
    }
}

// ✓ 正確：每個子集重置 idx
for (int i = 0; i < totalSubsets; i++) {
    int idx = 0;  // 重置
    for (int j = 0; j < numsSize; j++) {
        if (i & (1 << j)) {
            result[i][idx++] = nums[j];
        }
    }
}
```

### 錯誤 5：totalSubsets 計算錯誤

```c
// ❌ 錯誤：使用 pow 函數
int totalSubsets = pow(2, numsSize);  // 可能精度問題

// ✓ 正確：使用位移
int totalSubsets = 1 << numsSize;  // 2^n
```

### 進階思考

#### 問題 1：如何只生成大小為 k 的子集？

```c
// 方法：位運算 + __builtin_popcount
int** subsetsWithK(int* nums, int numsSize, int k, int* returnSize) {
    int totalSubsets = 1 << numsSize;
    int** result = malloc(totalSubsets * sizeof(int*));
    *returnSize = 0;
    
    for (int i = 0; i < totalSubsets; i++) {
        // 計算 1 的個數
        if (__builtin_popcount(i) == k) {
            // 生成這個子集
            result[*returnSize] = malloc(k * sizeof(int));
            int idx = 0;
            for (int j = 0; j < numsSize; j++) {
                if (i & (1 << j)) {
                    result[*returnSize][idx++] = nums[j];
                }
            }
            (*returnSize)++;
        }
    }
    
    return result;
}
```

#### 問題 2：如何處理重複元素？

```
問題：nums = [1, 2, 2]

位運算方法會生成重複：
  001 → [1]
  010 → [2]
  011 → [1, 2]
  100 → [2]    ← 重複！
  101 → [1, 2] ← 重複！
  ...

解決：
1. 排序
2. 在回溯中跳過重複
3. 或使用 Set 去重
```

#### 問題 3：如何優化記憶體？

```c
// 優化：只計算一次 count，不用兩次循環

int** subsets(int* nums, int numsSize, int* returnSize, int** returnColumnSizes) {
    int totalSubsets = 1 << numsSize;
    int** result = malloc(totalSubsets * sizeof(int*));
    *returnColumnSizes = malloc(totalSubsets * sizeof(int));
    *returnSize = totalSubsets;
    
    for (int i = 0; i < totalSubsets; i++) {
        // 使用內建函數計算 1 的個數
        int count = __builtin_popcount(i);
        
        result[i] = malloc(count * sizeof(int));
        (*returnColumnSizes)[i] = count;
        
        int idx = 0;
        for (int j = 0; j < numsSize; j++) {
            if (i & (1 << j)) {
                result[i][idx++] = nums[j];
            }
        }
    }
    
    return result;
}
```

## 🎓 回溯 vs 位運算

### 回溯法的優勢

```
優點：
1. 通用性強：可以處理各種變體
2. 容易剪枝：可以提前終止
3. 經典模板：適合學習

缺點：
1. 需要遞歸：有棧開銷
2. 代碼較長：邏輯複雜

適用場景：
- 有重複元素
- 需要剪枝優化
- 複雜的約束條件
```

### 位運算的優勢

```
優點：
1. 代碼簡潔：幾行搞定 ⭐
2. 直觀映射：數字對應子集
3. 無需遞歸：節省空間

缺點：
1. 限制較多：元素必須不重複
2. 空間需求：需要預分配 2^n 空間
3. 難以剪枝：必須遍歷所有

適用場景：
- 元素互不相同
- n 較小（n <= 20）
- 需要生成所有子集
```
