# LeetCode 155. Min Stack - 完整學習筆記

## 📋 題目描述

設計一個支持 push、pop、top 和 getMin 操作的棧。

實現 `MinStack` 類：
- `MinStack()` 初始化棧對象
- `void push(int val)` 將元素 val 推入棧中
- `void pop()` 刪除棧頂元素
- `int top()` 獲取棧頂元素
- `int getMin()` 獲取棧中的最小元素

**關鍵要求**：所有操作必須在 **O(1)** 時間複雜度內完成 ⭐

**範例**：
```
範例 1：
輸入：
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]

輸出：
[null,null,null,null,-3,null,0,-2]

解釋：
MinStack minStack = new MinStack();
minStack.push(-2);
minStack.push(0);
minStack.push(-3);
minStack.getMin(); // 返回 -3
minStack.pop();
minStack.top();    // 返回 0
minStack.getMin(); // 返回 -2
```

**限制**：
- `-2³¹ <= val <= 2³¹ - 1`
- pop、top 和 getMin 操作總是在**非空棧**上調用
- push、pop、top 和 getMin 最多被調用 `3 * 10⁴` 次

**關鍵理解**：
```
普通棧：
  push、pop、top 都是 O(1)
  但 getMin 需要遍歷 → O(n) ✗

最小棧的挑戰：
  getMin 也要 O(1) ⭐
  
如何做到？
  需要在 O(1) 時間內知道當前最小值
  → 關鍵：用空間換時間
```

## 💡 基礎知識：最小棧的挑戰

### 為什麼 getMin 很難做到 O(1)？

```
普通實現：

棧：[3, 1, 5, 2]
     ↑
    top

getMin()：
  遍歷所有元素找最小值
  時間：O(n) ✗

問題：
  每次 getMin 都要遍歷
  不符合 O(1) 要求
```

### 解決思路

```
核心問題：
  如何在 O(1) 時間內知道最小值？

答案：
  記錄每個時刻的最小值
  
範例：
  push(3)：min = 3
  push(1)：min = 1（新的最小值）
  push(5)：min = 1（還是 1）
  push(2)：min = 1（還是 1）
  
  pop()：移除 2，min 還是 1
  pop()：移除 5，min 還是 1
  pop()：移除 1，min 變成 3 ⭐
  
關鍵：
  pop 時需要知道"之前"的最小值
  → 需要記錄歷史最小值
```

## 🔧 方法一：每個節點記錄最小值（你的解法）⭐

### 核心思想

```
巧妙的想法：
  每個節點不只存值
  還存「到這個節點為止的最小值」

結構：
  struct Node {
      int value;  // 實際值
      int min;    // 到此節點的最小值 ⭐
      struct Node* next;
  }

範例：
  push(3)：[value=3, min=3]
  push(1)：[value=1, min=1] → [value=3, min=3]
  push(5)：[value=5, min=1] → [value=1, min=1] → [value=3, min=3]
           ↑
          top
  
  getMin()：直接返回 top->min = 1 ⭐
  
  pop()：移除 top
         新的 top->min 自動就是之前的最小值 ⭐
```

### 你的代碼（完美！）⭐⭐⭐⭐⭐

```c
typedef struct Node {
    int value;      // 實際值
    int min;        // 到此節點的最小值 ⭐
    struct Node* next;
} Node;

typedef struct {
    Node* top;    
} MinStack;

// ═══════════════════════════════════════
// 創建棧
// ═══════════════════════════════════════
MinStack* minStackCreate() {
    MinStack* st = (MinStack*)malloc(sizeof(MinStack));
    st->top = NULL;
    return st;
}

// ═══════════════════════════════════════
// Push：O(1)
// ═══════════════════════════════════════
void minStackPush(MinStack* obj, int val) {
    Node* new = (Node*)malloc(sizeof(Node));
    new->value = val;

    // 設定 min 值 ⭐
    if (obj->top == NULL) {
        new->min = val;  // 空棧，min 就是自己
    } else {
        // 比較當前值和之前的最小值
        new->min = val < obj->top->min ? val : obj->top->min;
    }

    new->next = obj->top;
    obj->top = new;
}

// ═══════════════════════════════════════
// Pop：O(1)
// ═══════════════════════════════════════
void minStackPop(MinStack* obj) {
    Node* temp = obj->top;
    obj->top = temp->next;
    free(temp);
}

// ═══════════════════════════════════════
// Top：O(1)
// ═══════════════════════════════════════
int minStackTop(MinStack* obj) {
    return obj->top->value;
}

// ═══════════════════════════════════════
// GetMin：O(1) ⭐⭐⭐
// ═══════════════════════════════════════
int minStackGetMin(MinStack* obj) {
    return obj->top->min;  // 直接返回！
}

// ═══════════════════════════════════════
// Free：釋放內存
// ═══════════════════════════════════════
void minStackFree(MinStack* obj) {
    // ⚠️ 這裡有問題，後面會講
    free(obj);
}
```

### 執行流程

```
範例：push(-2), push(0), push(-3)

═══════════════════════════════════════
初始狀態：

  top = NULL

═══════════════════════════════════════
push(-2)：

  創建節點：
    value = -2
    min = -2（棧空，min 就是自己）
    
  結果：
    top → [val=-2, min=-2] → NULL

═══════════════════════════════════════
push(0)：

  創建節點：
    value = 0
    min = 0 < -2 ? 0 : -2
        = -2（保持之前的最小值）
    
  結果：
    top → [val=0, min=-2] → [val=-2, min=-2] → NULL

═══════════════════════════════════════
push(-3)：

  創建節點：
    value = -3
    min = -3 < -2 ? -3 : -2
        = -3（新的最小值！）
    
  結果：
    top → [val=-3, min=-3] → [val=0, min=-2] → [val=-2, min=-2] → NULL

═══════════════════════════════════════
getMin()：

  返回 top->min = -3 ✓
  時間：O(1) ⭐

═══════════════════════════════════════
pop()：

  移除 top（-3）
  
  結果：
    top → [val=0, min=-2] → [val=-2, min=-2] → NULL

═══════════════════════════════════════
top()：

  返回 top->value = 0 ✓

═══════════════════════════════════════
getMin()：

  返回 top->min = -2 ✓
  自動回到之前的最小值！⭐
```

### 為什麼這個方法巧妙？

```
關鍵觀察：

當我們 pop 一個元素時
  如果它是最小值
  我們需要知道"之前"的最小值

你的方法：
  每個節點都記錄了"到它為止的最小值"
  pop 後，top 自動指向下一個節點
  而那個節點的 min 就是之前的最小值！⭐

圖解：
  push(3)：[3, min=3]
  push(1)：[1, min=1] → [3, min=3]
  push(5)：[5, min=1] → [1, min=1] → [3, min=3]
           ↑
          top
          
  pop()：移除 5
         [1, min=1] → [3, min=3]
          ↑
         top
         min 還是 1 ✓
         
  pop()：移除 1
         [3, min=3]
          ↑
         top
         min 自動變成 3 ✓
```

### ⚠️ 需要修正

```
問題：minStackFree 函數

你的代碼：
void minStackFree(MinStack* obj) {
    free(obj);  // ❌ 只釋放了結構，沒釋放節點

  棧裡可能還有很多節點

void minStackFree(MinStack* obj) {

        obj->top = temp->next;
        free(temp);
    }
    // 再釋放棧結構
    free(obj);
}
```

## 🔄 方法二：雙棧法（另一種經典解法）

### 核心思想

```
使用兩個棧：
  1. 數據棧：存儲實際值
  2. 最小棧：存儲最小值

push(val)：
  數據棧 push val
  最小棧 push min(val, 當前最小值)

pop()：
  數據棧 pop
  最小棧 pop

getMin()：
  返回最小棧的 top
```

### 實現（數組版）

```c
typedef struct {
    int data[30000];
    int dataTop;
    int minStack[30000];
    int minTop;
} MinStack;

MinStack* minStackCreate() {
    MinStack* obj = (MinStack*)malloc(sizeof(MinStack));
    obj->dataTop = -1;
    obj->minTop = -1;
    return obj;
}

void minStackPush(MinStack* obj, int val) {
    // 數據棧 push
    obj->data[++obj->dataTop] = val;
    
    // 最小棧 push
    if (obj->minTop == -1) {
        obj->minStack[++obj->minTop] = val;
    } else {
        int currentMin = obj->minStack[obj->minTop];
        int newMin = val < currentMin ? val : currentMin;
        obj->minStack[++obj->minTop] = newMin;
    }
}

void minStackPop(MinStack* obj) {
    obj->dataTop--;
    obj->minTop--;
}

int minStackTop(MinStack* obj) {
    return obj->data[obj->dataTop];
}

int minStackGetMin(MinStack* obj) {
    return obj->minStack[obj->minTop];
}

void minStackFree(MinStack* obj) {
    free(obj);
}
```

## 💡 深入理解：為什麼這個方法有效？

### 數學證明

```
定理：
  如果每個節點都記錄"到它為止的最小值"
  那麼棧頂節點的 min 就是整個棧的最小值

證明：
  
  設棧為：n₁ → n₂ → ... → nₖ
  
  n₁.min = min(n₁.value)
  n₂.min = min(n₂.value, n₁.min)
  n₃.min = min(n₃.value, n₂.min)
  ...
  nₖ.min = min(nₖ.value, nₖ₋₁.min)
  
  展開 nₖ.min：
  nₖ.min = min(nₖ.value, 
               min(nₖ₋₁.value, 
                   min(..., 
                       min(n₂.value, n₁.value))))
  
  = min(n₁.value, n₂.value, ..., nₖ.value)
  
  = 整個棧的最小值 ✓

結論：
  top->min 確實是整個棧的最小值！
```

### 為什麼 pop 後最小值自動更新？

```
關鍵觀察：

假設棧：
  [val=5, min=1] → [val=1, min=1] → [val=3, min=3]
   ↑
  top

當前最小值：top->min = 1

pop() 後：
  [val=1, min=1] → [val=3, min=3]
   ↑
  top
  
新的最小值：top->min = 1

為什麼是對的？
  因為新的 top 節點的 min
  記錄的是"到它為止的最小值"
  這正好就是 pop 後整個棧的最小值！⭐

數學上：
  pop 前：min(n₁, n₂, ..., nₖ)
  pop 後：min(n₁, n₂, ..., nₖ₋₁)
  
  而 nₖ₋₁.min = min(n₁, n₂, ..., nₖ₋₁) ✓
```
