# LeetCode 83. Remove Duplicates from Sorted List - 完整學習筆記

## 📋 題目描述

給定一個已排序鏈表的頭節點 `head`，刪除所有重複的元素，使每個元素**只出現一次**。返回**已排序**的鏈表。

**範例**：
```
範例 1：
輸入：head = [1,1,2]
輸出：[1,2]

  原：1 → 1 → 2
  結果：1 → 2

範例 2：
輸入：head = [1,1,2,3,3]
輸出：[1,2,3]

  原：1 → 1 → 2 → 3 → 3
  結果：1 → 2 → 3
```

**限制**：
- 鏈表中節點數目在範圍 `[0, 300]` 內
- `-100 <= Node.val <= 100`
- 題目數據保證鏈表已經按**升序排列**

**關鍵理解**：
```
重點：鏈表已排序！

這意味著：
  - 重複的元素一定相鄰
  - 只需要比較相鄰節點
  - 不需要額外的空間來記錄

例如：
  1 → 1 → 2 → 3 → 3
  相鄰重複：1和1，3和3
```

## 💡 基礎知識：鏈表去重

### 排序 vs 未排序

```
已排序鏈表（本題）：
  1 → 1 → 2 → 3 → 3
  重複元素相鄰 ✓
  
  只需比較相鄰節點：
  curr.val == curr.next.val?

未排序鏈表（更難）：
  3 → 1 → 2 → 1 → 3
  重複元素不相鄰 ✗
  
  需要哈希表記錄已見過的值
```

### 刪除節點的方法

```
方法：跳過節點

原鏈表：
  1 → 1 → 2
  ↑   ↑
  A   B

刪除B：
  1 ─────→ 2
  ↑
  A

代碼：
  A->next = B->next;  // 或 A->next = A->next->next;
```

## 🌟 方法一：單指針遍歷（你的解法 - 最優解）

### 核心思想

```
關鍵洞察：
  當發現重複時，不移動 curr
  因為新的 curr->next 可能還是重複的！

例子：
  1 → 1 → 1 → 2
  ↑
  curr

  第一次：跳過第二個1，curr 不動
  1 ─────→ 1 → 2
  ↑       ↑
  curr   新的next

  第二次：再次發現重複，跳過第三個1，curr 不動
  1 ─────────→ 2
  ↑           ↑
  curr      新的next

  第三次：1 != 2，curr 移動
```

### 代碼實現（你的解法）

```c
struct ListNode* deleteDuplicates(struct ListNode* head) {
    // 1. 安全檢查：如果 list 是空的或只有一個節點，直接回傳
    if (!head) return NULL;
    
    struct ListNode* curr = head;
    
    // 2. 遍歷清單
    while (curr && curr->next) {
        // 如果當前值跟下一個值一樣
        if (curr->val == curr->next->val) {
            // 直接跳過下一個節點
            curr->next = curr->next->next;
            // 注意：這裡不需要移動 curr，因為新的 curr->next 可能還是重複的
        } else {
            // 如果不一樣，才移動指標到下一個節點
            curr = curr->next;
        }
    }
    
    return head;
}
```

### 執行流程

```
範例：head = [1,1,2,3,3]

初始：
  1 → 1 → 2 → 3 → 3
  ↑
  curr

═══════════════════════════════════════
迭代 1：
  curr->val = 1
  curr->next->val = 1
  1 == 1 ✓ 重複！
  
  操作：curr->next = curr->next->next
  
  結果：
  1 ─────→ 2 → 3 → 3
  ↑
  curr（不移動）

═══════════════════════════════════════
迭代 2：
  curr->val = 1
  curr->next->val = 2
  1 == 2 ✗ 不重複
  
  操作：curr = curr->next
  
  結果：
  1 → 2 → 3 → 3
      ↑
      curr

═══════════════════════════════════════
迭代 3：
  curr->val = 2
  curr->next->val = 3
  2 == 3 ✗ 不重複
  
  操作：curr = curr->next
  
  結果：
  1 → 2 → 3 → 3
          ↑
          curr

═══════════════════════════════════════
迭代 4：
  curr->val = 3
  curr->next->val = 3
  3 == 3 ✓ 重複！
  
  操作：curr->next = curr->next->next
  
  結果：
  1 → 2 → 3 ─────→ NULL
          ↑
          curr（不移動）

═══════════════════════════════════════
迭代 5：
  curr->next = NULL
  結束循環

最終：1 → 2 → 3 ✓
```

### 為什麼 curr 不動很重要？

```
錯誤做法（curr 總是移動）：
  1 → 1 → 1 → 2
  ↑
  curr

  第一次：跳過第二個1，curr 移動
  1 ─────→ 1 → 2
          ↑
          curr

  第二次：1 == 2? ✗，curr 移動
  1 ─────→ 1 → 2
              ↑
              curr

  結果：1 → 1 → 2 ✗（第二個1沒刪除）

正確做法（發現重複時 curr 不動）：
  1 → 1 → 1 → 2
  ↑
  curr

  第一次：跳過第二個1，curr 不動
  1 ─────→ 1 → 2
  ↑       ↑
  curr   新next

  第二次：還是1 == 1，跳過第三個1，curr 不動
  1 ─────────→ 2
  ↑           ↑
  curr      新next

  第三次：1 != 2，curr 移動
  1 → 2
      ↑
      curr

  結果：1 → 2 ✓
```

## 🔧 方法二：遞歸法

### 思路

用遞歸處理子問題，比較當前節點和下一個節點。

### 代碼實現

```c
struct ListNode* deleteDuplicates(struct ListNode* head) {
    if (!head || !head->next) return head;
    
    // 遞歸處理後續節點
    head->next = deleteDuplicates(head->next);
    
    // 如果當前節點和下一個節點重複
    if (head->val == head->next->val) {
        return head->next;  // 跳過當前節點
    }
    
    return head;
}
```

### 執行流程

```
範例：head = [1,1,2]

遞歸調用：

deleteDuplicates(1)
  ↓
deleteDuplicates(1)
  ↓
deleteDuplicates(2)
  ↓
return 2

回溯：
  第二個1：1->next = 2
           1->val == 2->val? ✗
           return 1
  
  第一個1：1->next = 上面的1
           1->val == 1->val? ✓
           return 1->next（第二個1）

結果：第二個1 → 2 ✓
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(n) | 遍歷一次 |
| **空間複雜度** | O(n) | 遞歸棧空間 ❌ |

## 💡 關鍵技巧深入理解

### 技巧 1：循環條件

```c
// ✓ 正確（你的做法）
while (curr && curr->next) {
    // ...
}

為什麼要檢查 curr->next？
  - 避免空指針
  - 確保有下一個節點可比較
  
如果只檢查 curr：
  while (curr) {
      if (curr->val == curr->next->val) {  // curr->next 可能為 NULL！
          // 崩潰！
      }
  }
```

### 技巧 2：重複時 curr 不動

```c
// ✓ 正確（你的做法）
if (curr->val == curr->next->val) {
    curr->next = curr->next->next;
    // curr 不動！
} else {
    curr = curr->next;
    // 只有不重複才動
}

為什麼？
  連續重複：1 → 1 → 1
  
  如果每次都移動：
    第一次：刪除第二個1，移動到第二個1
    第二次：比較第二個1和第三個1，移動到第三個1
    結果：還剩兩個1 ✗
  
  如果重複時不動：
    第一次：刪除第二個1，停在第一個1
    第二次：比較第一個1和第三個1（現在是next），刪除
    結果：只剩一個1 ✓
```

### 技巧 3：不需要 free

```c
// 本題不需要 free
curr->next = curr->next->next;

為什麼？
  - 題目沒要求釋放內存
  - 跳過的節點仍在內存中
  - 實際使用中可能需要 free
  
如果要釋放：
  struct ListNode* duplicate = curr->next;
  curr->next = curr->next->next;
  free(duplicate);
```

### 26. Remove Duplicates from Sorted Array

// 26 題：數組去重
int removeDuplicates(int* nums, int numsSize) {
    if (numsSize == 0) return 0;
    
    int slow = 0;
    for (int fast = 1; fast < numsSize; fast++) {
        if (nums[fast] != nums[slow]) {
            slow++;
            nums[slow] = nums[fast];
        }
    }
    
    return slow + 1;
}

### 82. Remove Duplicates from Sorted List II

```c
// 82 題：刪除所有重複節點（更難）
// 輸入：1 → 2 → 3 → 3 → 4 → 4 → 5
// 輸出：1 → 2 → 5

// 區別：
// 83：保留一個
// 82：完全刪除

struct ListNode* deleteDuplicates(struct ListNode* head) {
    struct ListNode dummy;
    dummy.next = head;
    struct ListNode* prev = &dummy;
    
    while (head) {
        if (head->next && head->val == head->next->val) {
            // 跳過所有重複節點
            while (head->next && head->val == head->next->val) {
                head = head->next;
            }
            prev->next = head->next;
        } else {
            prev = prev->next;
        }
        head = head->next;
    }
    
    return dummy.next;
}
```

#### 問題 1：如果鏈表未排序怎麼辦？

```c
// 需要哈希表記錄已見過的值
struct ListNode* deleteDuplicatesUnsorted(struct ListNode* head) {
    if (!head) return NULL;
    
    // 使用哈希表（這裡簡化，實際需要實現）
    bool seen[201] = {false};  // 假設值範圍 [-100, 100]
    
    struct ListNode dummy;
    dummy.next = head;
    struct ListNode* prev = &dummy;
    struct ListNode* curr = head;
    
    while (curr) {
        int index = curr->val + 100;  // 映射到 [0, 200]
        
        if (seen[index]) {
            prev->next = curr->next;
        } else {
            seen[index] = true;
            prev = curr;
        }
        
        curr = curr->next;
    }
    
    return dummy.next;
}

// 時間：O(n)
// 空間：O(n)（哈希表）
```

#### 問題 2：如何保留後面的重複項而刪除前面的？

// 例如：1 → 1 → 2 → 3 → 3
// 結果：1 → 2 → 3（保留最後一個）

// 方法：先反轉，去重，再反轉回來
struct ListNode* deleteDuplicatesKeepLast(struct ListNode* head) {
    // 1. 反轉鏈表
    head = reverseList(head);
