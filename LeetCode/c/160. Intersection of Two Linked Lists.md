# LeetCode 160. Intersection of Two Linked Lists - 完整學習筆記

## 📋 題目描述

給定兩個單向鏈表的頭節點 `headA` 和 `headB`，請找出並返回兩個單向鏈表**相交的起始節點**。如果兩個鏈表不存在相交節點，返回 `null`。

**注意**：
- 相交是指**節點的引用相同**，而不是值相同
- 返回結果後，兩個鏈表仍須**保持原有的結構**

**範例**：
```
範例 1：
輸入：intersectVal = 8, listA = [4,1,8,4,5], listB = [5,6,1,8,4,5], skipA = 2, skipB = 3
輸出：Reference of the node with value = 8

  A:    4 → 1 ↘
               8 → 4 → 5
  B: 5 → 6 → 1 ↗
  
  相交節點是值為 8 的節點

範例 2：
輸入：intersectVal = 2, listA = [1,9,1,2,4], listB = [3,2,4], skipA = 3, skipB = 1
輸出：Reference of the node with value = 2

  A: 1 → 9 → 1 ↘
                2 → 4
  B:         3 ↗
  
範例 3：
輸入：intersectVal = 0, listA = [2,6,4], listB = [1,5], skipA = 3, skipB = 2
輸出：null

  A: 2 → 6 → 4
  B: 1 → 5
  
  沒有相交
```

**限制**：
- `listA` 中節點數目為 `m`
- `listB` 中節點數目為 `n`
- `1 <= m, n <= 3 * 10^4`
- `1 <= Node.val <= 10^5`
- `0 <= skipA < m`
- `0 <= skipB < n`
- 如果 `listA` 和 `listB` 沒有交點，`intersectVal` 為 `0`
- 如果有交點，`intersectVal == listA[skipA] == listB[skipB]`

**進階要求**：
你能否設計一個時間複雜度 **O(m + n)**、僅用 **O(1)** 空間的解決方案？

**關鍵理解**：
```
相交是指節點引用相同，不是值相同！

  A: 1 → 2 → 3
  B: 4 → 5 → 3
  
  即使都有值為 3 的節點，但不是同一個節點 ✗

  A: 1 → 2 ↘
            3 → 4
  B: 5 → 6 ↗
  
  節點 3 是同一個節點引用 ✓
```

## 💡 基礎知識：鏈表相交

### 什麼是相交？

```
相交：兩個鏈表共享同一個節點

圖示：
  ListA: a1 → a2 ↘
                  c1 → c2 → c3
  ListB: b1 → b2 → b3 ↗
  
  從 c1 開始相交
  c1、c2、c3 是共享的節點
```

### 相交的特點

```
1. 一旦相交，後面的節點都相同
   （因為每個節點只有一個 next）

2. 相交節點之後的長度必定相同

3. 相交前的長度可能不同

4. 如果相交，兩個鏈表形成 "Y" 字型
```

## 🔧 方法一：暴力法（你的解法）

### 思路

對於 A 中的每個節點，遍歷 B 中的所有節點，檢查是否相同。

### 代碼實現（你的解法）

```c
struct ListNode *getIntersectionNode(struct ListNode *headA, struct ListNode *headB) {
    struct ListNode* list1 = headA;
    
    // 邊界檢查
    if (headA == NULL || headB == NULL) {
        return NULL;
    }
    
    // 遍歷 A 的每個節點
    while (list1) {
        struct ListNode* list2 = headB;
        
        // 遍歷 B 的每個節點
        while (list2) {
            if (list1 == list2) {  // 找到相交節點
                return list2;
            } else {
                list2 = list2->next;
            }
        }
        
        list1 = list1->next;
    }
    
    return NULL;  // 沒有相交
}
```

### 執行流程

```
範例：
  A: 4 → 1 → 8 → 4 → 5
  B: 5 → 6 → 1 → 8 → 4 → 5
             （這個 8 和 A 的 8 是同一個節點）

list1 = 4:
  list2 遍歷：5, 6, 1, 8, 4, 5
  4 != 5, 4 != 6, ..., 都不相等

list1 = 1:
  list2 遍歷：5, 6, 1, 8, 4, 5
  1 != 5, 1 != 6, ..., 都不相等（值相等但節點不同）

list1 = 8（A 的 8）:
  list2 遍歷：5, 6, 1, 8（B 的 8）
  8 == 8 ✓（節點引用相同）
  
  return 8（相交節點）
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(m × n) | A 的每個節點都遍歷整個 B ❌ |
| **空間複雜度** | O(1) | 只用常數指針 ✓ |

### 優缺點

**優點**：
- ✅ 邏輯簡單直觀
- ✅ 空間 O(1)
- ✅ 容易實現

**缺點**：
- ❌ 時間複雜度高 O(m×n)
- ❌ 不符合進階要求
- ❌ 效率低（重複遍歷）

## 🚀 方法二：哈希表

### 思路

先遍歷 A，將所有節點存入哈希表，再遍歷 B，檢查是否在哈希表中。

### 代碼實現（C++ 版本）

```cpp
struct ListNode *getIntersectionNode(struct ListNode *headA, struct ListNode *headB) {
    unordered_set<ListNode*> visited;
    
    // 遍歷 A，記錄所有節點
    ListNode* curr = headA;
    while (curr) {
        visited.insert(curr);
        curr = curr->next;
    }
    
    // 遍歷 B，檢查是否在集合中
    curr = headB;
    while (curr) {
        if (visited.count(curr)) {
            return curr;  // 找到相交節點
        }
        curr = curr->next;
    }
    
    return NULL;  // 沒有相交
}
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(m + n) | 遍歷兩次 ✓ |
| **空間複雜度** | O(m) | 哈希表存儲 ❌ |

## 🌟 方法三：雙指針法（最優解）

### 核心思想

```
關鍵洞察：
  讓兩個指針分別遍歷兩個鏈表
  當到達末尾時，跳到另一個鏈表的頭部
  
  如果有相交，兩個指針會在相交點相遇
  如果沒有相交，兩個指針會同時到達 NULL

為什麼會相遇？
  兩個指針走過的總路程相同！
```

### 數學證明

```
設：
  A 的長度為 a
  B 的長度為 b
  相交部分的長度為 c

則：
  A 獨有部分 = a - c
  B 獨有部分 = b - c

指針 pA 的路徑：
  A 獨有部分 → 相交部分 → B 獨有部分 → 相交部分
  (a-c) + c + (b-c) = a + b - c

指針 pB 的路徑：
  B 獨有部分 → 相交部分 → A 獨有部分 → 相交部分
  (b-c) + c + (a-c) = a + b - c

兩者路程相同，會在相交點相遇！✓

如果沒有相交（c = 0）：
  pA 路徑：a + b
  pB 路徑：b + a
  兩者會同時到達 NULL
```

### 圖解過程

```
範例：A: 4 → 1 → 8 → 4 → 5
     B: 5 → 6 → 1 → 8 → 4 → 5
                    ↑
                  相交點

a = 5, b = 6, c = 3（相交部分：8 → 4 → 5）

pA 的路徑：
  步驟 1-5：遍歷 A（4 → 1 → 8 → 4 → 5 → NULL）
  步驟 6-8：跳到 B 的開頭（5 → 6 → 1）
  步驟 9：到達相交點 8 ✓

pB 的路徑：
  步驟 1-6：遍歷 B（5 → 6 → 1 → 8 → 4 → 5 → NULL）
  步驟 7-8：跳到 A 的開頭（4 → 1）
  步驟 9：到達相交點 8 ✓

兩者在步驟 9 相遇！
```

### 代碼實現

```c
struct ListNode *getIntersectionNode(struct ListNode *headA, struct ListNode *headB) {
    if (!headA || !headB) return NULL;
    
    struct ListNode* pA = headA;
    struct ListNode* pB = headB;
    
    // 當兩個指針不相等時繼續
    while (pA != pB) {
        // pA 走到末尾時跳到 B 的開頭，否則走下一步
        pA = (pA == NULL) ? headB : pA->next;
        
        // pB 走到末尾時跳到 A 的開頭，否則走下一步
        pB = (pB == NULL) ? headA : pB->next;
    }
    
    // pA == pB 時，可能是相交點，也可能都是 NULL
    return pA;
}
```

### 執行流程

```
範例：A: 4 → 1 → 8 → 4 → 5
     B: 5 → 6 → 1 → 8 → 4 → 5

初始：pA = 4, pB = 5

迭代 1：
  pA != pB
  pA = 1, pB = 6

迭代 2：
  pA != pB
  pA = 8, pB = 1

迭代 3：
  pA != pB
  pA = 4, pB = 8

迭代 4：
  pA != pB
  pA = 5, pB = 4

迭代 5：
  pA != pB
  pA = NULL, pB = 5

迭代 6：
  pA != pB
  pA = headB = 5（跳到 B）
  pB = NULL

迭代 7：
  pA != pB
  pA = 6
  pB = headA = 4（跳到 A）

迭代 8：
  pA != pB
  pA = 1
  pB = 1

迭代 9：
  pA != pB
  pA = 8
  pB = 8

pA == pB，退出循環
return 8（相交節點）✓
```

### 無相交情況

```
範例：A: 1 → 2 → 3
     B: 4 → 5

pA 路徑：1 → 2 → 3 → NULL → 4 → 5 → NULL
pB 路徑：4 → 5 → NULL → 1 → 2 → 3 → NULL

最終 pA == pB == NULL
return NULL ✓
```

| 項目 | 複雜度 | 說明 |

| **空間複雜度** | O(1) | 只用兩個指針 ✓ |

### 優勢

**最優解的優點**：
- ✅ **時間 O(m+n)**：高效 ⭐

## 💡 雙指針法深入理解

### 為什麼路程相同？

```
視覺化理解：

不相交：
  A: ─────── (長度 a)
  B: ───────── (長度 b)
  
  pA 走：a + b
  pB 走：b + a
  相同，都到達 NULL

相交：
  A: ──── ↘
          ───── (相交部分 c)
  B: ────── ↗
  
  A 獨有：a-c
  B 獨有：b-c
  
  pA 走：(a-c) + c + (b-c) = a + b - c
  pB 走：(b-c) + c + (a-c) = a + b - c
  相同，在相交點相遇
```

### 為什麼不會錯過？

```
問題：會不會一個指針在相交點，另一個跳過了？

答案：不會！

因為：
  當 pA 和 pB 都進入相交部分後
  它們每次都同步移動
  一定會在某個相交節點相遇

例如：
  pA 進入相交部分在步驟 5
  pB 進入相交部分在步驟 4
  
  步驟 5：pA 和 pB 都在相交部分
  之後同步移動，必定相遇 ✓
```

### 簡化版代碼

```c
// 更簡潔的寫法
struct ListNode *getIntersectionNode(struct ListNode *headA, struct ListNode *headB) {
    struct ListNode *pA = headA, *pB = headB;
    
    while (pA != pB) {
        pA = pA ? pA->next : headB;
        pB = pB ? pB->next : headA;
    }
    
    return pA;
}

// 邏輯相同，但更簡潔
```

## ⚠️ 常見錯誤

### 錯誤 1：比較值而不是節點

```c
// ❌ 錯誤：比較值
if (pA->val == pB->val) {
    return pA;
}

// 問題：值相同不代表是同一個節點

// ✓ 正確：比較節點引用
if (pA == pB) {
    return pA;
}
```

### 錯誤 2：跳轉邏輯錯誤

```c
// ❌ 錯誤：跳到對方的 next
pA = (pA == NULL) ? headB->next : pA->next;

// 問題：應該跳到對方的 head

// ✓ 正確
pA = (pA == NULL) ? headB : pA->next;
```

### 錯誤 3：死循環

```c
// ❌ 錯誤：沒有正確跳轉
while (pA != pB) {
    pA = pA->next;  // 沒有跳轉邏輯
    pB = pB->next;  // 會在 NULL 處死循環
}

// ✓ 正確：有跳轉邏輯
pA = (pA == NULL) ? headB : pA->next;
pB = (pB == NULL) ? headA : pB->next;
```

### 錯誤 4：忘記處理空鏈表

```c
// ❌ 錯誤：沒有檢查
struct ListNode *getIntersectionNode(struct ListNode *headA, struct ListNode *headB) {
    struct ListNode *pA = headA;  // headA 可能為 NULL
    // ...
}

// ✓ 正確：先檢查
if (!headA || !headB) return NULL;
```

struct ListNode *detectCycle(struct ListNode *head) {
    struct ListNode *slow = head, *fast = head;
    
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        
        if (slow == fast) {
            slow = head;
            while (slow != fast) {
                slow = slow->next;
                fast = fast->next;

## 🎓 總結

**160. Intersection of Two Linked Lists 的核心**：

```
問題：找兩個鏈表的相交節點
關鍵：雙指針 + 路程相同

你的解法（暴力法）：
  雙重循環，比較每個節點
  時間 O(m×n)，空間 O(1)
  能通過但不是最優 ⭐⭐

最優解法（雙指針）：
struct ListNode *pA = headA, *pB = headB;

while (pA != pB) {
    pA = pA ? pA->next : headB;
    pB = pB ? pB->next : headA;
}

return pA;

時間 O(m+n)，空間 O(1) ⭐⭐⭐⭐⭐
```

**關鍵記憶點**：
1. ✅ **你的解法正確**：暴力法能通過
2. ✅ **雙指針更優**：時間從 O(m×n) 到 O(m+n)
3. ✅ **路程相同**：數學證明的核心
4. ✅ **跳轉邏輯**：到達 NULL 時跳到對方 head
5. ✅ **比較節點**：不是比較值
6. ✅ **優雅解法**：面試必會 ⭐

**記憶口訣**：
```
「雙指針，走兩遍」
  pA 走：A + B
  pB 走：B + A
  
「路程相同，必定相遇」
  有相交：在相交點相遇
  無相交：同時到達 NULL
```

**數學證明記憶**：
```

B 獨有：b-c
相交：c

pB 路徑：(b-c) + c + (a-c) = a + b - c

路程相同，在相交點相遇！
```

你的暴力法正確，但雙指針法更優雅！這是一個非常經典的算法，值得深入理解 👍
