# LeetCode 338. Counting Bits - 完整學習筆記

## 📋 題目描述

給定一個整數 `n`，返回一個長度為 `n + 1` 的數組 `ans`，其中 `ans[i]` 是整數 `i` 的二進制表示中 **1 的個數**。

**範例**：
```
輸入：n = 2
輸出：[0,1,1]
解釋：
  0 的二進制是 0     → 0 個 1
  1 的二進制是 1     → 1 個 1
  2 的二進制是 10    → 1 個 1

輸入：n = 5
輸出：[0,1,1,2,1,2]
解釋：
  0 → 0     → 0 個 1
  1 → 1     → 1 個 1
  2 → 10    → 1 個 1
  3 → 11    → 2 個 1
  4 → 100   → 1 個 1
  5 → 101   → 2 個 1
```

**限制**：
- `0 <= n <= 10^5`

**進階要求**：
- 能否在 **O(n)** 時間和不使用內建函數的情況下完成？
- 能否一次遍歷完成？
- 能否不使用額外空間（輸出數組不算）？

---

## 💡 基礎知識：回顧 191 題

### 191. Number of 1 Bits

```c
// 計算一個數字中 1 的個數
int hammingWeight(int n) {
    int count = 0;
    while (n) {
        n &= (n - 1);  // Brian Kernighan 算法
        count++;
    }
    return count;
}
```

**本題 vs 191 題**：
```
191 題：計算「一個數字」的 1 的個數
338 題：計算「0 到 n 所有數字」的 1 的個數

關鍵：能否利用之前的計算結果？
```

---

## 🔧 方法一：Brian Kernighan 算法（你的解法）

### 思路

對每個數字，使用 191 題的方法計算 1 的個數。

### 代碼實現

```c
int* countBits(int n, int* returnSize) {
    int* ans = (int*)malloc((n + 1) * sizeof(int));
    
    for (int i = 0; i <= n; i++) {
        int count = 0, bit = i;
        while (bit) {
            bit &= (bit - 1);  // 消除最右邊的 1
            count++;
        }
        ans[i] = count;
    }
    
    *returnSize = n + 1;
    return ans;
}
```

### 執行流程

```
範例：n = 5

i = 0 (000)：
  bit = 0，不進入循環
  count = 0

i = 1 (001)：
  bit = 1 & 0 = 0
  count = 1

i = 2 (010)：
  bit = 2 & 1 = 0
  count = 1

i = 3 (011)：
  bit = 3 & 2 = 2 (010)
  bit = 2 & 1 = 0
  count = 2

i = 4 (100)：
  bit = 4 & 3 = 0
  count = 1

i = 5 (101)：
  bit = 5 & 4 = 4 (100)
  bit = 4 & 3 = 0
  count = 2

結果：[0, 1, 1, 2, 1, 2] ✓
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(n × log n) | 每個數字最多有 log n 個 1 |
| **空間複雜度** | O(1) | 不算輸出數組 |

### 優缺點

**優點**：
- ✅ 邏輯清晰，容易理解
- ✅ 利用了 191 題的經典算法
- ✅ 代碼簡潔

**缺點**：
- ❌ 時間複雜度 O(n log n)，不是最優
- ❌ 沒有利用之前的計算結果

## 🚀 方法二：動態規劃 - 最低有效位（最優解）

### 核心思想

```
觀察規律：

i 的 1 的個數 = (i >> 1) 的 1 的個數 + i 的最低位

為什麼？
  i >> 1：右移一位，去掉最低位
  i & 1：最低位是 0 還是 1

例子：
  5 = 101
  5 >> 1 = 10 (2)
  5 & 1 = 1
  
  count[5] = count[2] + 1
           = 1 + 1
           = 2 ✓
```

### 遞推公式

```
dp[i] = dp[i >> 1] + (i & 1)

解釋：
  dp[i >> 1]：右移一位（除以 2）的結果
  i & 1：當前最低位（0 或 1）
```

### 代碼實現

```c
int* countBits(int n, int* returnSize) {
    int* ans = (int*)malloc((n + 1) * sizeof(int));
    ans[0] = 0;
    
    for (int i = 1; i <= n; i++) {
        ans[i] = ans[i >> 1] + (i & 1);
    }
    
    *returnSize = n + 1;
    return ans;
}
```

### 執行流程

```
範例：n = 5

i = 0：ans[0] = 0 (初始化)

i = 1 (001)：
  ans[1] = ans[1 >> 1] + (1 & 1)
         = ans[0] + 1
         = 0 + 1 = 1 ✓

i = 2 (010)：
  ans[2] = ans[2 >> 1] + (2 & 1)
         = ans[1] + 0
         = 1 + 0 = 1 ✓

i = 3 (011)：
  ans[3] = ans[3 >> 1] + (3 & 1)
         = ans[1] + 1
         = 1 + 1 = 2 ✓

i = 4 (100)：
  ans[4] = ans[4 >> 1] + (4 & 1)
         = ans[2] + 0
         = 1 + 0 = 1 ✓

i = 5 (101)：
  ans[5] = ans[5 >> 1] + (5 & 1)
         = ans[2] + 1
         = 1 + 1 = 2 ✓

結果：[0, 1, 1, 2, 1, 2] ✓
```

### 為什麼有效？

```
數學證明：

設 i 的二進制表示為：...abc

則 i >> 1 的二進制表示為：...ab

觀察：
  i     = ...abc
  i>>1  = ...ab
  
  i 的 1 的個數 = ...ab 中 1 的個數 + c 的值

因此：
  count[i] = count[i >> 1] + (i & 1)
```

### 圖解說明

```
i = 5 = 101

右移一位：
  101 → 10 (去掉最後一位)
  
count[5] = count[2] + 最後一位
         = count[10] + 1
         = 1 + 1
         = 2 ✓

可視化：
  101 (5)
   │
   ├─ 10 (2) → count[2] = 1
   │
   └─ 1 (最低位) → 1
   
  count[5] = 1 + 1 = 2
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(n) | 只遍歷一次 ✓ |
| **空間複雜度** | O(1) | 不算輸出數組 ✓ |

### 優勢

**相比方法一的優勢**：
```
方法一：O(n log n) - 每個數字單獨計算
方法二：O(n) - 利用之前的結果

效率提升：約 log n 倍（對於 n=10^5，提升約 17 倍）

符合進階要求：
✓ O(n) 時間
✓ 一次遍歷
✓ O(1) 額外空間
```

## 🌟 方法三：動態規劃 - 最低設置位

### 核心思想

```
另一種 DP 思路：

i 的 1 的個數 = (i & (i-1)) 的 1 的個數 + 1

為什麼？
  i & (i-1)：消除最右邊的 1
  結果比 i 少一個 1

例子：
  5 = 101
  4 = 100
  5 & 4 = 100 (4)
  
  count[5] = count[4] + 1
           = 1 + 1
           = 2 ✓
```

### 遞推公式

```
dp[i] = dp[i & (i-1)] + 1

解釋：
  i & (i-1)：消除最右邊的 1
  + 1：剛消除的那個 1
```

### 代碼實現

```c
int* countBits(int n, int* returnSize) {
    int* ans = (int*)malloc((n + 1) * sizeof(int));
    ans[0] = 0;
    
    for (int i = 1; i <= n; i++) {
        ans[i] = ans[i & (i - 1)] + 1;
    }
    
    *returnSize = n + 1;
    return ans;
}
```

### 執行流程

```
範例：n = 5

i = 0：ans[0] = 0 (初始化)

i = 1 (001)：
  ans[1] = ans[1 & 0] + 1
         = ans[0] + 1
         = 0 + 1 = 1 ✓

i = 2 (010)：
  ans[2] = ans[2 & 1] + 1
         = ans[0] + 1
         = 0 + 1 = 1 ✓

i = 3 (011)：
  ans[3] = ans[3 & 2] + 1
         = ans[2] + 1
         = 1 + 1 = 2 ✓

i = 4 (100)：
  ans[4] = ans[4 & 3] + 1
         = ans[0] + 1
         = 0 + 1 = 1 ✓

i = 5 (101)：
  ans[5] = ans[5 & 4] + 1
         = ans[4] + 1
         = 1 + 1 = 2 ✓

結果：[0, 1, 1, 2, 1, 2] ✓
```

## 🎯 方法四：動態規劃 - 最高有效位

### 核心思想

```
觀察 2 的冪的規律：

0 = 0     → 0 個 1
1 = 1     → 1 個 1
2 = 10    → 1 個 1
3 = 11    → 2 個 1
4 = 100   → 1 個 1
5 = 101   → 2 個 1
6 = 110   → 2 個 1
7 = 111   → 3 個 1
8 = 1000  → 1 個 1

規律：
  從 2^k 到 2^(k+1) - 1
  count[i] = count[i - 2^k] + 1
```

### 遞推公式

```
設 b 是不超過 i 的最大 2 的冪

dp[i] = dp[i - b] + 1

例如：
  i = 5, b = 4 (100)
  dp[5] = dp[5 - 4] + 1
        = dp[1] + 1
        = 1 + 1 = 2 ✓
```

### 代碼實現

```c
int* countBits(int n, int* returnSize) {
    int* ans = (int*)malloc((n + 1) * sizeof(int));
    ans[0] = 0;
    int b = 1;  // 當前最大 2 的冪
    
    for (int i = 1; i <= n; i++) {
        // 當 i 是 2 的冪時，更新 b
        if ((i & (i - 1)) == 0) {
            b = i;
        }
        ans[i] = ans[i - b] + 1;
    }
    
    *returnSize = n + 1;
    return ans;
}
```

### 執行流程

```
範例：n = 7

i = 0：ans[0] = 0, b = 1

i = 1 (001)：
  1 是 2 的冪，b = 1
  ans[1] = ans[1 - 1] + 1 = ans[0] + 1 = 1

i = 2 (010)：
  2 是 2 的冪，b = 2
  ans[2] = ans[2 - 2] + 1 = ans[0] + 1 = 1

i = 3 (011)：
  3 不是 2 的冪，b = 2
  ans[3] = ans[3 - 2] + 1 = ans[1] + 1 = 2

i = 4 (100)：
  4 是 2 的冪，b = 4
  ans[4] = ans[4 - 4] + 1 = ans[0] + 1 = 1

i = 5 (101)：
  5 不是 2 的冪，b = 4
  ans[5] = ans[5 - 4] + 1 = ans[1] + 1 = 2

i = 6 (110)：
  6 不是 2 的冪，b = 4
  ans[6] = ans[6 - 4] + 1 = ans[2] + 1 = 2

i = 7 (111)：
  7 不是 2 的冪，b = 4
  ans[7] = ans[7 - 4] + 1 = ans[3] + 1 = 3

結果：[0, 1, 1, 2, 1, 2, 2, 3] ✓
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(n) | 只遍歷一次 ✓ |
| **空間複雜度** | O(1) | 不算輸出數組 ✓ |

## 💡 核心技巧深入理解

### 技巧 1：i >> 1（右移）

```
數學意義：除以 2（向下取整）

例子：
  5 = 101
  5 >> 1 = 10 (2)
  
  等價於：5 / 2 = 2

二進制角度：
  去掉最後一位
  101 → 10
```

### 技巧 2：i & 1（檢查最低位）

```
作用：取出最低位

例子：
  5 = 101
  5 & 1 = 001 = 1
  
  4 = 100
  4 & 1 = 000 = 0

應用：判斷奇偶
  i & 1 == 1 → 奇數
  i & 1 == 0 → 偶數
```

### 技巧 3：i & (i-1)（消除最右邊的 1）

```
Brian Kernighan 算法

5 = 101
4 = 100
5 & 4 = 100 (消除最右邊的 1)

6 = 110
5 = 101
6 & 5 = 100 (消除最右邊的 1)
```

### 技巧 4：動態規劃的本質

```
DP 三要素：
1. 定義狀態：dp[i] = i 的 1 的個數
2. 找轉移方程：利用之前的結果
3. 初始化：dp[0] = 0

關鍵：
  避免重複計算
  利用子問題的解
```

## ⚠️ 常見錯誤

### 錯誤 1：DP 轉移方程錯誤

```c
// ❌ 錯誤：沒有正確理解右移
ans[i] = ans[i / 2] + (i % 2);  // 可以，但不如位運算清晰

// ✓ 正確：使用位運算
ans[i] = ans[i >> 1] + (i & 1);
```

### 錯誤 2：忘記初始化

```c
// ❌ 錯誤：沒有初始化 ans[0]
for (int i = 1; i <= n; i++) {
    ans[i] = ans[i >> 1] + (i & 1);
}

// ✓ 正確：必須初始化
ans[0] = 0;  // 或者從 i = 0 開始循環
for (int i = 1; i <= n; i++) {
    ans[i] = ans[i >> 1] + (i & 1);
}
```

### 錯誤 3：數組大小錯誤

```c
// ❌ 錯誤：數組太小
int* ans = (int*)malloc(n * sizeof(int));  // 應該是 n+1

// ✓ 正確：包含 0 到 n
int* ans = (int*)malloc((n + 1) * sizeof(int));
```

### 錯誤 4：忘記設置 returnSize

```c
// ❌ 錯誤：沒有設置
return ans;

// ✓ 正確：必須設置
*returnSize = n + 1;
return ans;
```

### 錯誤 5：Brian Kernighan 循環條件

```c
// ❌ 錯誤：循環條件寫錯
while (bit > 0) {  // 可以，但不夠簡潔
    bit &= (bit - 1);
    count++;
}

// ✓ 正確：更簡潔
while (bit) {  // bit != 0
    bit &= (bit - 1);
    count++;
}
```

```
問題：能否 O(1) 空間計算第 i 個數的 1 的個數？

答案：
可以，但需要 O(log n) 時間

方法 1：Brian Kernighan
int countOnes(int n) {
    int count = 0;
    while (n) {
        n &= (n - 1);
        count++;
    }
    return count;
}

方法 2：__builtin_popcount（內建）
int countOnes(int n) {
    return __builtin_popcount(n);
}
```

## 🎓 DP 思路總結

### 三種 DP 轉移方程

```
方法 1：最低位
  dp[i] = dp[i >> 1] + (i & 1)
  
  意義：去掉最後一位 + 最後一位的值
  例子：5 = 101 → dp[5] = dp[2] + 1

方法 2：最低設置位
  dp[i] = dp[i & (i-1)] + 1
  
  意義：消除最右邊的 1 + 1
  例子：5 = 101 → dp[5] = dp[4] + 1

方法 3：最高有效位
  dp[i] = dp[i - b] + 1  (b 是最大 2 的冪)
  
  意義：減去最高位的 2 的冪 + 1
  例子：5 = 101 → dp[5] = dp[1] + 1
```

### 如何選擇？

```
最推薦：方法 1（最低位）
- 代碼最簡單
- 最容易理解
- 不需要額外判斷

也很好：方法 2（最低設置位）
- 利用 Brian Kernighan 技巧
- 展示對位運算的掌握

了解即可：方法 3（最高有效位）
- 需要額外判斷 2 的冪
- 代碼稍複雜
```

**338. Counting Bits 的核心**：

```
問題：計算 0 到 n 所有數字的 1 的個數
關鍵：利用 DP 避免重複計算

三種 DP 方法：
1. 最低位：dp[i] = dp[i >> 1] + (i & 1) ⭐
2. 最低設置位：dp[i] = dp[i & (i-1)] + 1
3. 最高有效位：dp[i] = dp[i - b] + 1

最優解法（方法二 - 最低位）：
int* countBits(int n, int* returnSize) {
    int* ans = (int*)malloc((n + 1) * sizeof(int));
    ans[0] = 0;
    for (int i = 1; i <= n; i++) {
        ans[i] = ans[i >> 1] + (i & 1);
    }
    *returnSize = n + 1;
    return ans;
}

時間複雜度：O(n) ✓
空間複雜度：O(1) ✓
```
