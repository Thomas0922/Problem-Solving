# LeetCode 20. Valid Parentheses - 完整學習筆記

## 📋 題目描述

給定一個只包括 `'('`, `')'`, `'{'`, `'}'`, `'['`, `']'` 的字符串 `s`，判斷字符串是否有效。

有效字符串需滿足：
1. 左括號必須用相同類型的右括號閉合
2. 左括號必須以正確的順序閉合
3. 每個右括號都有一個對應的相同類型的左括號

**範例**：
```
範例 1：
輸入：s = "()"
輸出：true

範例 2：
輸入：s = "()[]{}"
輸出：true

範例 3：
輸入：s = "(]"
輸出：false

範例 4：
輸入：s = "([])"
輸出：true

範例 5：
輸入：s = "([)]"
輸出：false
解釋：交錯的括號，不符合規則
```

**限制**：
- `1 <= s.length <= 10⁴`
- `s` 僅由括號 `'()[]{}'` 組成

**關鍵理解**：
```
有效的括號配對：
  ✓ ()        單對
  ✓ ({})      嵌套
  ✓ ({[]})    多層嵌套
  ✓ ()[]{}    並列

無效的括號配對：
  ✗ (]        類型不匹配
  ✗ ([)]      交錯
  ✗ ((        缺少右括號
  ✗ ))        缺少左括號
  ✗ )(        順序錯誤

特點：
  後進先出（LIFO）
  → 使用棧（Stack）⭐
```

## 💡 基礎知識：棧（Stack）

### 什麼是棧？

```
棧：後進先出（LIFO - Last In First Out）

模型：
  一摞盤子
  
  最後放上去的盤子
  最先被拿走
  
操作：
  push：放入元素（壓棧）
  pop：取出元素（彈棧）
  peek/top：查看頂部元素
  isEmpty：判斷是否為空

範例：
  初始：[]
  push(1)：[1]
  push(2)：[1,2]
  push(3)：[1,2,3]
  pop()：返回3，剩餘[1,2]
  pop()：返回2，剩餘[1]
```

### 為什麼這題用棧？

```
括號匹配的特點：

範例：(({[]}))

  讀到 (：等待對應的 )
  讀到 (：等待對應的 )
  讀到 {：等待對應的 }
  讀到 [：等待對應的 ]
  讀到 ]：匹配最近的 [ ✓
  讀到 }：匹配最近的 { ✓
  讀到 )：匹配最近的 ( ✓
  讀到 )：匹配最近的 ( ✓

規律：
  最後遇到的左括號
  最先被匹配
  
  → 典型的 LIFO 模式
  → 使用棧完美匹配 ⭐
```

## 🔧 方法一：鏈表實現棧（你的解法）

### 核心思路

```
使用鏈表實現棧：

1. 遇到左括號：push 到棧
2. 遇到右括號：
   - 檢查棧是否為空
   - pop 棧頂元素
   - 檢查是否匹配
3. 最後檢查棧是否為空

鏈表棧的結構：
  top → [節點3] → [節點2] → [節點1] → NULL
  
  push：在 top 前插入
  pop：移除 top 節點
```

### 你的代碼

```c
#include<stdio.h>
#include <stdlib.h>

typedef struct Node{
    char data;
    struct Node* next;
}Node;

typedef struct {
    Node* top;
}stack;

bool isValid(char* s) {
   // 創建棧
   stack* st = (stack*)malloc(sizeof(stack));
   st->top = NULL;
   
    // 遍歷字符串
    for(int i = 0; s[i] != '\0'; i++){
        // 左括號：push
        if(s[i] == '(' || s[i] == '{' || s[i] == '['){
            Node* new = (Node*)malloc(sizeof(Node));
            new->data = s[i];
            new->next = st->top;
            st->top = new;
        }
        // 右括號 )：pop 並檢查
        else if(s[i] == ')'){
            if(st->top == NULL) return false;  // 棧空
            Node* temp = st->top;
            char dt = temp->data;
            st->top = temp->next;
            free(temp);
            if(dt != '(') return false;  // 不匹配
        }
        // 右括號 }：pop 並檢查
        else if(s[i] == '}'){
            if(st->top == NULL) return false;
            Node* temp = st->top;
            char dt = temp->data;
            st->top = temp->next;
            free(temp);
            if(dt != '{') return false;
        }
        // 右括號 ]：pop 並檢查
        else if(s[i] == ']'){
            if(st->top == NULL) return false;
            Node* temp = st->top;
            char dt = temp->data;
            st->top = temp->next;
            free(temp);
            if(dt != '[') return false;
        }
    }
    
    // 檢查棧是否為空
    if(st->top != NULL){
        return false;  // 還有未匹配的左括號
    }else{
        return true;
    }
}
```

## 🚀 方法二：數組實現棧（優化版）

### 核心思路

```
使用數組實現棧：

char stack[10000];
int top = -1;

push：stack[++top] = ch;
pop：stack[top--];
peek：stack[top];
isEmpty：top == -1;

優點：
  - 簡單直接
  - 不需要 malloc/free
  - 代碼更短
  - 效率更高
```

### 優化代碼版本 1：使用輔助函數

```c
bool isValid(char* s) {
    char stack[10000];
    int top = -1;
    
    // 輔助函數：檢查是否匹配
    bool isMatch(char left, char right) {
        return (left == '(' && right == ')') ||
               (left == '{' && right == '}') ||
               (left == '[' && right == ']');
    }
    
    for (int i = 0; s[i] != '\0'; i++) {
        char ch = s[i];
        
        // 左括號：push
        if (ch == '(' || ch == '{' || ch == '[') {
            stack[++top] = ch;
        }
        // 右括號：pop 並檢查
        else {
            // 棧空或不匹配
            if (top == -1 || !isMatch(stack[top], ch)) {
                return false;
            }
            top--;  // pop
        }
    }
    
    // 檢查棧是否為空
    return top == -1;
}
```

### 優化代碼版本 2：使用映射

```c
bool isValid(char* s) {
    char stack[10000];
    int top = -1;
    
    for (int i = 0; s[i] != '\0'; i++) {
        char ch = s[i];
        
        // 左括號：push 對應的右括號
        if (ch == '(') {
            stack[++top] = ')';
        } else if (ch == '{') {
            stack[++top] = '}';
        } else if (ch == '[') {
            stack[++top] = ']';
        }
        // 右括號：檢查是否匹配棧頂
        else {
            if (top == -1 || stack[top] != ch) {
                return false;
            }
            top--;
        }
    }
    
    return top == -1;
}
```

### 優化代碼版本 3：最簡潔版

```c
bool isValid(char* s) {
    char stack[10000];
    int top = -1;
    
    for (int i = 0; s[i]; i++) {
        // 左括號：push 對應的右括號
        if (s[i] == '(') stack[++top] = ')';
        else if (s[i] == '{') stack[++top] = '}';
        else if (s[i] == '[') stack[++top] = ']';
        // 右括號：檢查
        else if (top == -1 || stack[top--] != s[i]) {
            return false;
        }
    }
    
    return top == -1;
}
```

| 版本 | 優點 | 缺點 |
|------|------|------|
| **版本 1（輔助函數）** | 邏輯清晰，易讀 | 稍長 |
| **版本 2（映射）** | 巧妙，減少判斷 | 需要理解技巧 |
| **版本 3（最簡潔）** | 最短 ⭐ | 密集，需仔細閱讀 |

## 💡 棧操作深入理解

### Push 操作（鏈表）

```c
// 你的 push 實現
Node* new = (Node*)malloc(sizeof(Node));
new->data = s[i];
new->next = st->top;  // 新節點指向原棧頂
st->top = new;        // 更新棧頂

// 圖解：
原始棧：top → [A] → [B] → NULL

push('C')：
  new → [C]
  new->next = top → [C] → [A] → [B] → NULL
  st->top = new
  
結果：top → [C] → [A] → [B] → NULL
```

### Pop 操作（鏈表）

```c
// 你的 pop 實現
Node* temp = st->top;      // 保存棧頂
char dt = temp->data;      // 取數據
st->top = temp->next;      // 更新棧頂
free(temp);                // 釋放節點

// 圖解：
原始棧：top → [C] → [A] → [B] → NULL

pop()：
  temp = [C]
  dt = 'C'
  st->top = [A] → [B] → NULL
  free([C])
  
結果：top → [A] → [B] → NULL
返回：'C'
```

### 為什麼你的代碼要保存 dt？

```c
// 你的代碼
Node* temp = st->top;
char dt = temp->data;      // ⭐ 為什麼要保存？
st->top = temp->next;
free(temp);                // 節點已釋放
if(dt != '(') return false;  // 這裡用 dt

// 如果不保存：
Node* temp = st->top;
st->top = temp->next;
free(temp);
if(temp->data != '(') return false;  // 錯！💀
// temp 已經被 free，訪問會出錯！

// 所以必須先保存數據 ✓
```
