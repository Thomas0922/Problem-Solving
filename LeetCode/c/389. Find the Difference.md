# LeetCode 389. Find the Difference - 完整學習筆記

## 📋 題目描述

給定兩個字串 `s` 和 `t`，它們只包含小寫字母。

字串 `t` 由字串 `s` 隨機重排，然後在隨機位置添加一個字母。

請找出在 `t` 中被添加的字母。

**範例**：
```
輸入：s = "abcd", t = "abcde"
輸出："e"
解釋：'e' 是唯一被添加的字母

輸入：s = "", t = "y"
輸出："y"

輸入：s = "a", t = "aa"
輸出："a"
```

**限制**：
- `0 <= s.length <= 1000`
- `t.length == s.length + 1`
- `s` 和 `t` 只包含小寫字母

---

## 💡 核心觀察

### 題目特點

```
1. t 是 s 的重排 + 一個額外字符
2. s 中的每個字符在 t 中都會出現一次
3. t 中有一個字符會多出現一次

關鍵發現：
- 這是「找出現 1 次的元素」問題
- 和 136/268 題一樣的思路！
```

### 視覺化理解

```
s = "abcd"
t = "abcde"

字符統計：
s: a(1), b(1), c(1), d(1)
t: a(1), b(1), c(1), d(1), e(1)

差異：e 多出來了
```

### 關鍵思路

```
把 s 和 t 的所有字符 XOR 在一起：
- s 中的字符和 t 中對應的字符會消除
- 剩下的就是多出來的字符

這就是 136/268 題的技巧！⭐
```

---

## 🚀 方法一：XOR 互斥或（最優解）

### 思路

```
步驟 1：對 s 中所有字符 XOR
步驟 2：對 t 中所有字符 XOR
步驟 3：成對的消除，剩下的就是答案
```

### 程式碼實現（你的方法）

```c
char findTheDifference(char* s, char* t) {
    int ans = 0;
    
    // 對 s 中所有字符 XOR
    for (int i = 0; i < strlen(s); i++) {
        ans ^= s[i];
    }
    
    // 對 t 中所有字符 XOR
    for (int j = 0; j < strlen(t); j++) {
        ans ^= t[j];
    }
    
    return (char)ans;
}
```

### 優化版本 1：避免重複計算 strlen

```c
char findTheDifference(char* s, char* t) {
    int ans = 0;
    int len_s = strlen(s);  // 先計算長度
    int len_t = strlen(t);
    
    for (int i = 0; i < len_s; i++) {
        ans ^= s[i];
    }
    
    for (int i = 0; i < len_t; i++) {
        ans ^= t[i];
    }
    
    return (char)ans;
}
```

### 優化版本 2：合併迴圈

```c
char findTheDifference(char* s, char* t) {
    int ans = 0;
    int len = strlen(s);
    
    // 同時處理 s[i] 和 t[i]
    for (int i = 0; i < len; i++) {
        ans ^= s[i] ^ t[i];
    }
    
    // t 多一個字符
    ans ^= t[len];
    
    return (char)ans;
}
```

### 執行流程

#### 範例：s = "abcd", t = "abcde"

```
初始：ans = 0

───────────────────────────────────────
處理 s：
  ans ^= 'a' → ans = 97 (01100001)
  ans ^= 'b' → ans = 3  (00000011)
  ans ^= 'c' → ans = 96 (01100000)
  ans ^= 'd' → ans = 4  (00000100)

───────────────────────────────────────
處理 t：
  ans ^= 'a' → ans = 101 (01100101)
  ans ^= 'b' → ans = 6   (00000110)
  ans ^= 'c' → ans = 101 (01100101)
  ans ^= 'd' → ans = 1   (00000001)
  ans ^= 'e' → ans = 100 (01100100)

───────────────────────────────────────
返回：(char)100 = 'e' ✓
```

### 為什麼有效？

```
所有字符 XOR：
a ^ b ^ c ^ d ^ a ^ b ^ c ^ d ^ e

重新排列（交換律）：
= (a ^ a) ^ (b ^ b) ^ (c ^ c) ^ (d ^ d) ^ e
  ───────   ───────   ───────   ───────
     0         0         0         0

= 0 ^ 0 ^ 0 ^ 0 ^ e
= e ✓

成對的字符消除了，只剩多出來的 'e'！
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(n) | 遍歷字串 |
| **空間複雜度** | O(1) | 只用一個變數 ⭐ |

### 優勢

**這是最優解！**
- ✅ 時間：O(n)，無法更快
- ✅ 空間：O(1)，不用額外空間
- ✅ 程式碼簡潔
- ✅ 利用 136/268 題學過的技巧 ⭐

## 🔄 方法二：字符計數（哈希表）

### 思路

統計每個字符出現次數的差異。

### 程式碼實現

```c
char findTheDifference(char* s, char* t) {
    int count[26] = {0};  // 只有小寫字母
    
    // 統計 s 中的字符
    for (int i = 0; s[i] != '\0'; i++) {
        count[s[i] - 'a']++;
    }
    
    // 減去 t 中的字符
    for (int i = 0; t[i] != '\0'; i++) {
        count[t[i] - 'a']--;
        // 如果出現負數，就是多出來的
        if (count[t[i] - 'a'] < 0) {
            return t[i];
        }
    }
    
    return '\0';  // 不應該到這裡
}
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(n) | 遍歷字串 |
| **空間複雜度** | O(26) = O(1) | 固定大小陣列 |

## 🔄 方法三：ASCII 碼總和

### 思路

計算兩個字串的 ASCII 碼總和差。

### 程式碼實現

```c
char findTheDifference(char* s, char* t) {
    int sum_s = 0, sum_t = 0;
    
    // 計算 s 的總和
    for (int i = 0; s[i] != '\0'; i++) {
        sum_s += s[i];
    }
    
    // 計算 t 的總和
    for (int i = 0; t[i] != '\0'; i++) {
        sum_t += t[i];
    }
    
    return (char)(sum_t - sum_s);
}
```

### 為什麼有效？

```
s = "abc"
t = "abce"

sum_s = 'a' + 'b' + 'c' = 97 + 98 + 99 = 294
sum_t = 'a' + 'b' + 'c' + 'e' = 97 + 98 + 99 + 101 = 395

差值 = 395 - 294 = 101 = 'e' ✓
```

## 💡 XOR 方法的優化細節

### 問題：strlen() 重複計算

```c
// ❌ 不好：每次迴圈都調用 strlen()
for (int i = 0; i < strlen(s); i++) {
    ans ^= s[i];
}

// ✅ 較好：先計算長度
int len = strlen(s);
for (int i = 0; i < len; i++) {
    ans ^= s[i];
}
```

**為什麼？**
```
strlen() 需要遍歷整個字串找 '\0'
在迴圈條件中調用 → 每次迭代都執行
時間複雜度：O(n) × n 次 = O(n²)！

先計算長度 → 只執行一次
時間複雜度：O(n)
```

### 合併迴圈的好處

```c
// 兩個迴圈
for (int i = 0; i < len_s; i++) ans ^= s[i];
for (int i = 0; i < len_t; i++) ans ^= t[i];

// 合併成一個（更好）
for (int i = 0; i < len_s; i++) {
    ans ^= s[i] ^ t[i];
}
ans ^= t[len_s];
```
