# LeetCode 148. Sort List - 完整學習筆記

## 📋 題目描述

給你鏈表的頭節點 `head`，請將其按**升序**排列並返回**排序後的鏈表**。

**範例**：
```
範例 1：
輸入：head = [4,2,1,3]
輸出：[1,2,3,4]

範例 2：
輸入：head = [-1,5,3,4,0]
輸出：[-1,0,3,4,5]

範例 3：
輸入：head = []
輸出：[]
```

**限制**：
- 鏈表中節點的數目在範圍 `[0, 5 * 10⁴]` 內
- `-10⁵ <= Node.val <= 10⁵`

**進階要求**：
你可以在 **O(n log n)** 時間複雜度和常數級空間複雜度下，對鏈表進行排序嗎？

**關鍵理解**：
```
排序鏈表的挑戰：
1. 不能隨機訪問（不能用快速排序）
2. 不能輕易交換（不能用選擇排序）
3. 需要原地操作（空間 O(1)）

適合的算法：
✓ 歸併排序（Merge Sort）- O(n log n) ⭐
✓ 插入排序（Insertion Sort）- O(n²)
✗ 快速排序（Quick Sort）- 鏈表不適合
✗ 堆排序（Heap Sort）- 鏈表不適合
```

## 💡 基礎知識：排序算法對比

### 常見排序算法在鏈表上的適用性

| 算法 | 時間複雜度 | 空間複雜度 | 鏈表適用性 |
|------|-----------|-----------|-----------|
| **歸併排序** | O(n log n) | O(1)或O(log n) | ✓ 最適合 ⭐ |
| **插入排序** | O(n²) | O(1) | ✓ 可以但慢 |
| 快速排序 | O(n log n) | O(log n) | ✗ 不適合 |
| 堆排序 | O(n log n) | O(1) | ✗ 不適合 |
| 選擇排序 | O(n²) | O(1) | ✗ 效率低 |

### 為什麼歸併排序最適合鏈表？

```
歸併排序的特點：
1. 分治思想：把問題分成兩半
2. 遞歸解決：分別排序
3. 合併結果：兩個有序鏈表合併

鏈表的優勢：
1. 容易分割（改指針即可）
2. 合併簡單（21題的技巧）
3. 不需要額外空間複製

完美匹配！⭐
```

## 🔧 方法一：插入排序（你的解法）

### 思路

```
插入排序的邏輯：
  維護一個已排序部分
  每次取一個新節點
  插入到已排序部分的正確位置

範例：[4,2,1,3]

初始：dummy → NULL
      待排：4,2,1,3

步驟 1：插入 4
  dummy → 4

步驟 2：插入 2（2 < 4）
  dummy → 2 → 4

步驟 3：插入 1（1 < 2）
  dummy → 1 → 2 → 4

步驟 4：插入 3（2 < 3 < 4）
  dummy → 1 → 2 → 3 → 4 ✓
```

### 你的代碼

```c
struct ListNode* sortList(struct ListNode* head) {
    // 邊界處理
    if (!head || !head->next) return head;

    // Dummy node
    struct ListNode dummy;
    dummy.next = NULL;

    struct ListNode *curr = head;

    // 遍歷原鏈表
    while (curr) {
        // 保存下一個節點
        struct ListNode *next = curr->next;

        // 找到插入位置
        struct ListNode *prev = &dummy;
        while (prev->next && prev->next->val < curr->val) {
            prev = prev->next;
        }

        // 插入當前節點
        curr->next = prev->next;
        prev->next = curr;

        // 移動到下一個節點
        curr = next;
    }

    return dummy.next;
}
```

### 執行流程

```
範例：[4,2,1,3]

═══════════════════════════════════════
初始化：

  dummy → NULL
  curr = 4

═══════════════════════════════════════
迭代 1：插入 4

  next = 2（保存）
  
  找位置：
    prev = dummy
    prev->next = NULL，停止
    
  插入：
    4->next = NULL
    dummy->next = 4
    
  結果：dummy → 4 → NULL
  
  curr = 2

═══════════════════════════════════════
迭代 2：插入 2

  next = 1（保存）
  
  找位置：
    prev = dummy
    prev->next = 4, 4 >= 2，停止
    
  插入：
    2->next = 4
    dummy->next = 2
    
  結果：dummy → 2 → 4 → NULL
  
  curr = 1

═══════════════════════════════════════
迭代 3：插入 1

  next = 3（保存）
  
  找位置：
    prev = dummy
    prev->next = 2, 2 >= 1，停止
    
  插入：
    1->next = 2
    dummy->next = 1
    
  結果：dummy → 1 → 2 → 4 → NULL
  
  curr = 3

═══════════════════════════════════════
迭代 4：插入 3

  next = NULL（保存）
  
  找位置：
    prev = dummy
    prev->next = 1, 1 < 3，繼續
    prev = 1
    prev->next = 2, 2 < 3，繼續
    prev = 2
    prev->next = 4, 4 >= 3，停止
    
  插入：
    3->next = 4
    2->next = 3
    
  結果：dummy → 1 → 2 → 3 → 4 → NULL
  
  curr = NULL

═══════════════════════════════════════
返回：dummy.next = 1 → 2 → 3 → 4 ✓
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(n²) | 每個節點找位置 O(n) |
| **空間複雜度** | O(1) | 只用常數個指針 |

**詳細說明**：
```
時間複雜度 O(n²)：
  外層循環：遍歷 n 個節點
  內層循環：找位置平均 O(n/2)
  總共：O(n * n/2) = O(n²) ❌

最壞情況：
  輸入：[5,4,3,2,1]（逆序）
  每個節點都要遍歷到最前面
  1 + 2 + 3 + ... + n = O(n²)

最好情況：
  輸入：[1,2,3,4,5]（已排序）
  每個節點只需檢查一次
  O(n) ✓

空間複雜度 O(1)：
  只用了 dummy, curr, next, prev
  常數個指針 ✓
```

### 你的解法優缺點

**優點**：
- ✅ **邏輯簡單**：容易理解
- ✅ **空間 O(1)**：原地操作
- ✅ **代碼簡潔**：實現直觀
- ✅ **穩定排序**：相同元素保持順序
- ✅ **對小數據高效**：n < 100 時很快

**缺點**：
- ❌ **時間 O(n²)**：不符合進階要求
- ❌ **大數據慢**：n = 50000 時會超時

**適用場景**：
```
✓ 小規模數據（n < 100）
✓ 接近有序的數據
✓ 不要求 O(n log n)

✗ 大規模數據（n > 1000）
✗ 嚴格的時間要求
✗ 面試進階要求
```

## 🌟 方法二：歸併排序（最優解）⭐

### 核心思想

```
歸併排序的步驟：

1. 分割（Divide）
   找中點，分成兩半
   
2. 遞歸排序（Conquer）
   分別排序兩半
   
3. 合併（Merge）
   合併兩個有序鏈表

範例：[4,2,1,3]

分割：
  [4,2,1,3]
   ↓
  [4,2] [1,3]
   ↓     ↓
  [4][2][1][3]

遞歸排序：
  [4] [2] [1] [3]
   ↓   ↓   ↓   ↓
  [4] [2] [1] [3]

合併：
  [4] [2] → [2,4]
  [1] [3] → [1,3]
   ↓
  [2,4] [1,3] → [1,2,3,4] ✓
```

### 完整代碼（遞歸版）

```c
// 輔助函數：合併兩個有序鏈表（21題）
struct ListNode* merge(struct ListNode* l1, struct ListNode* l2) {
    struct ListNode dummy;
    dummy.next = NULL;
    struct ListNode* tail = &dummy;
    
    while (l1 && l2) {
        if (l1->val < l2->val) {
            tail->next = l1;
            l1 = l1->next;
        } else {
            tail->next = l2;
            l2 = l2->next;
        }
        tail = tail->next;
    }
    
    tail->next = l1 ? l1 : l2;
    return dummy.next;
}

// 主函數：歸併排序
struct ListNode* sortList(struct ListNode* head) {
    // 遞歸終止條件
    if (!head || !head->next) return head;
    
    // 步驟 1：找中點（快慢指針）
    struct ListNode* slow = head;
    struct ListNode* fast = head;
    struct ListNode* prev = NULL;
    
    while (fast && fast->next) {
        prev = slow;
        slow = slow->next;
        fast = fast->next->next;
    }
    
    // 斷開前後兩部分
    prev->next = NULL;
    
    // 步驟 2：遞歸排序兩部分
    struct ListNode* left = sortList(head);
    struct ListNode* right = sortList(slow);
    
    // 步驟 3：合併
    return merge(left, right);
}
```

### 執行流程（遞歸版）

```
範例：[4,2,1,3]

═══════════════════════════════════════
第 1 層遞歸：sortList([4,2,1,3])

找中點：slow = 1（第2個節點的位置）
斷開：[4,2] | [1,3]

遞歸：
  left = sortList([4,2])
  right = sortList([1,3])

═══════════════════════════════════════
第 2 層遞歸：sortList([4,2])

找中點：slow = 2
斷開：[4] | [2]

遞歸：
  left = sortList([4]) → [4]（單節點）
  right = sortList([2]) → [2]（單節點）

合併：merge([4], [2]) → [2,4] ✓

═══════════════════════════════════════
第 2 層遞歸：sortList([1,3])

找中點：slow = 3
斷開：[1] | [3]

遞歸：
  left = sortList([1]) → [1]（單節點）
  right = sortList([3]) → [3]（單節點）

合併：merge([1], [3]) → [1,3] ✓

═══════════════════════════════════════
第 1 層遞歸：合併

left = [2,4]
right = [1,3]

合併：merge([2,4], [1,3])
  比較：1 < 2 → 取 1
  比較：2 < 3 → 取 2
  比較：3 < 4 → 取 3
  剩餘：4
  
  結果：[1,2,3,4] ✓

═══════════════════════════════════════
返回：[1,2,3,4]
```

### 迭代版歸併排序（真正的 O(1) 空間）

```c
// 輔助函數：分割鏈表
struct ListNode* split(struct ListNode* head, int size) {
    for (int i = 1; head && i < size; i++) {
        head = head->next;
    }
    if (!head) return NULL;
    
    struct ListNode* second = head->next;
    head->next = NULL;
    return second;
}

// 合併函數
struct ListNode* merge(struct ListNode* l1, struct ListNode* l2) {
    struct ListNode dummy;
    dummy.next = NULL;
    struct ListNode* tail = &dummy;
    
    while (l1 && l2) {
        if (l1->val < l2->val) {
            tail->next = l1;
            l1 = l1->next;
        } else {
            tail->next = l2;
            l2 = l2->next;
        }
        tail = tail->next;
    }
    
    tail->next = l1 ? l1 : l2;
    
    // 找到尾節點
    while (tail->next) tail = tail->next;
    
    return dummy.next;
}

// 迭代版歸併排序
struct ListNode* sortList(struct ListNode* head) {
    if (!head || !head->next) return head;
    
    // 計算鏈表長度
    int length = 0;
    struct ListNode* curr = head;
    while (curr) {
        length++;
        curr = curr->next;
    }
    
    struct ListNode dummy;
    dummy.next = head;
    
    // 從小到大的區間進行合併
    for (int size = 1; size < length; size *= 2) {
        struct ListNode* tail = &dummy;
        struct ListNode* curr = dummy.next;
        
        while (curr) {
            struct ListNode* left = curr;
            struct ListNode* right = split(left, size);
            curr = split(right, size);
            
            tail->next = merge(left, right);
            while (tail->next) tail = tail->next;
        }
    }
    
    return dummy.next;
}
```

### 複雜度分析（歸併排序）

| 項目 | 遞歸版 | 迭代版 |
|------|--------|--------|
| **時間複雜度** | O(n log n) ✓ | O(n log n) ✓ |
| **空間複雜度** | O(log n) | O(1) ⭐ |

**詳細說明**：
```
時間複雜度 O(n log n)：
  分割：log n 層
  每層合併：O(n)
  總共：O(n log n) ✓

遞歸版空間 O(log n)：
  遞歸深度：log n
  每層常數空間
  總共：O(log n)

迭代版空間 O(1)：
  不使用遞歸
  只用常數個變量
  總共：O(1) ⭐
```

### 錯誤 1：插入排序比較條件錯誤

```c

    prev = prev->next;
}

// 問題：
// <= 會導致不穩定排序
// 相同元素的相對順序可能改變

// ✓ 正確（你的做法）
while (prev->next && prev->next->val < curr->val) {
    prev = prev->next;
}
// 嚴格小於，保證穩定性 ✓
```

### 錯誤 2：歸併排序找中點錯誤

```c
// ❌ 錯誤：沒有 prev
struct ListNode* slow = head;
struct ListNode* fast = head;

while (fast && fast->next) {
    slow = slow->next;
    fast = fast->next->next;
}

// 然後：slow->next = NULL
// 問題：無法斷開，因為不知道 slow 的前一個

// ✓ 正確：用 prev
struct ListNode* prev = NULL;
while (fast && fast->next) {
    prev = slow;
    slow = slow->next;
    fast = fast->next->next;
}
prev->next = NULL;  // 正確斷開
```

### 錯誤 3：忘記保存 next

```c
// ❌ 錯誤（插入排序）

    prev->next = curr;

// ✓ 正確（你的做法）
while (curr) {
    struct ListNode *next = curr->next;  // 先保存
    
    curr->next = prev->next;
    prev->next = curr;
    
    curr = next;  // 用保存的值
}
```

## 💡 歸併排序深入理解

### 為什麼歸併排序快？

```
時間複雜度對比：

插入排序 O(n²)：
  n = 1000 → 1,000,000 次操作
  n = 10000 → 100,000,000 次操作
  n = 50000 → 2,500,000,000 次操作 💀

歸併排序 O(n log n)：
  n = 1000 → 10,000 次操作
  n = 10000 → 130,000 次操作
  n = 50000 → 800,000 次操作 ✓

差距：
```

### 歸併排序的遞歸樹

```
範例：[4,2,1,3]

深度 0：    [4,2,1,3]         ← 1 次合併，4 個元素
             ↙     ↘
深度 1：  [4,2]   [1,3]       ← 2 次合併，每次 2 個元素
          ↙  ↘   ↙  ↘
深度 2： [4] [2] [1] [3]      ← 4 次合併，每次 1 個元素

總深度：log₂(4) = 2
每層操作：O(n)
總時間：O(n log n) ✓
```

### 21. Merge Two Sorted Lists

```c
// 21：合併兩個有序鏈表
// 歸併排序的合併步驟

struct ListNode* mergeTwoLists(struct ListNode* l1, struct ListNode* l2) {
    struct ListNode dummy;
    struct ListNode* tail = &dummy;
    
    while (l1 && l2) {
        if (l1->val < l2->val) {
            tail->next = l1;
            l1 = l1->next;
        } else {
            tail->next = l2;
            l2 = l2->next;
        }
        tail = tail->next;
    }
    
    tail->next = l1 ? l1 : l2;
    return dummy.next;
}

// 148 用到這個技巧
```

```c
struct ListNode* middleNode(struct ListNode* head) {
    struct ListNode* slow = head;
    struct ListNode* fast = head;
```
