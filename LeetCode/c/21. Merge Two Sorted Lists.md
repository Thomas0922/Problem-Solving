# LeetCode 21. Merge Two Sorted Lists - 完整學習筆記

## 📋 題目描述

將兩個**升序**鏈表合併為一個新的**升序**鏈表並返回。新鏈表是通過拼接給定的兩個鏈表的所有節點組成的。

**範例**：
```
輸入：list1 = [1,2,4], list2 = [1,3,4]
輸出：[1,1,2,3,4,4]

輸入：list1 = [], list2 = []
輸出：[]

輸入：list1 = [], list2 = [0]
輸出：[0]
```

**限制**：
- 兩個鏈表的節點數目範圍是 `[0, 50]`
- `-100 <= Node.val <= 100`
- `list1` 和 `list2` 均按**非遞減順序**排列

**鏈表定義**：
```c
struct ListNode {
    int val;
    struct ListNode *next;
};
```

**關鍵理解**：
```
list1: 1 → 2 → 4 → NULL
list2: 1 → 3 → 4 → NULL

合併過程：
步驟1: 比較 1 和 1 → 選 1 (list1)
步驟2: 比較 2 和 1 → 選 1 (list2)
步驟3: 比較 2 和 3 → 選 2 (list1)
步驟4: 比較 4 和 3 → 選 3 (list2)
步驟5: 比較 4 和 4 → 選 4 (list1)
步驟6: list1 用完，接上 list2 的 4

結果: 1 → 1 → 2 → 3 → 4 → 4 → NULL
```

## 🔧 方法一：迭代法 - Dummy Node（你的解法 - 最優解）

### 核心思想

```
1. 創建虛擬頭節點（dummy node）
2. 用 tail 指針追蹤當前鏈表的末尾
3. 比較兩個鏈表的當前節點
4. 選擇較小的節點接到結果鏈表後面
5. 移動對應鏈表的指針
6. 重複直到某個鏈表為空
7. 將剩餘的鏈表接到結果後面
```

```

list2: 1 → 3 → 4 → NULL

 tail

            ↑

                ↑
               tail
               
list1: 4 → NULL
```

### 代碼實現（你的解法）

```c
struct ListNode* mergeTwoLists(struct ListNode* list1, struct ListNode* list2) {
    // 創建虛擬頭節點
    struct ListNode dum;
    struct ListNode* tail = &dum;
    dum.next = NULL;
    
    // 當兩個鏈表都不為空時
    while (list1 && list2) {
        if (list1->val <= list2->val) {
            tail->next = list1;  // 接上 list1 的節點
            list1 = list1->next; // list1 前進
        } else {
            tail->next = list2;  // 接上 list2 的節點
            list2 = list2->next; // list2 前進
        }
        tail = tail->next;  // tail 前進
    }
    
    // 接上剩下的鏈表
    tail->next = list1 ? list1 : list2;
    
    return dum.next;  // 返回真正的頭節點
}
```

### 執行流程

```

  tail = &dummy

  當前結果：dummy → 1 → 1
  list1: 2 → 4
  list2: 3 → 4

迭代 3：
  list1->val = 2, list2->val = 3
  2 <= 3 ✓
  tail->next = list1 (節點2)
  list1 = list1->next (移到節點4)
  tail = tail->next (移到節點2)
  
  當前結果：dummy → 1 → 1 → 2
  list1: 4
  list2: 3 → 4

迭代 4：
  list1->val = 4, list2->val = 3
  4 <= 3 ✗
  tail->next = list2 (節點3)
  list2 = list2->next (移到節點4)
  tail = tail->next (移到節點3)

  list1: 4
  list2: 4

迭代 5：
  list1->val = 4, list2->val = 4
  4 <= 4 ✓
```

## 🚀 方法二：遞歸法

### 核心思想

```
遞歸定義：
  merge(list1, list2) = 
    if list1 為空: return list2
    if list2 為空: return list1
    if list1.val < list2.val:
      list1.next = merge(list1.next, list2)
      return list1
    else:
      list2.next = merge(list1, list2.next)
      return list2
```

### 遞歸樹

```
merge([1,2,4], [1,3,4])
    ↓
1 <= 1，選 list1 的 1
    ↓
1.next = merge([2,4], [1,3,4])
             ↓
         2 > 1，選 list2 的 1
             ↓
         1.next = merge([2,4], [3,4])
                      ↓
                  2 < 3，選 list1 的 2
                      ↓
                  2.next = merge([4], [3,4])
                               ↓
                           4 > 3，選 list2 的 3
                               ↓
                           3.next = merge([4], [4])
                                        ↓
                                    4 <= 4，選 list1 的 4
                                        ↓
                                    4.next = merge(NULL, [4])
                                                 ↓
                                             return [4]

最終結果：1 → 1 → 2 → 3 → 4 → 4
```

### 代碼實現

```c
struct ListNode* mergeTwoLists(struct ListNode* list1, struct ListNode* list2) {
    // 基本情況
    if (!list1) return list2;
    if (!list2) return list1;
    
    // 遞歸情況
    if (list1->val <= list2->val) {
        list1->next = mergeTwoLists(list1->next, list2);
        return list1;
    } else {
        list2->next = mergeTwoLists(list1, list2->next);
        return list2;
    }
}
```

### 執行流程

```
輸入：list1 = [1,2,4], list2 = [1,3,4]

調用 1: mergeTwoLists([1,2,4], [1,3,4])
  1 <= 1 ✓
  list1->next = 調用 2
  return list1 (節點1)

調用 2: mergeTwoLists([2,4], [1,3,4])
  2 > 1 ✗
  list2->next = 調用 3
  return list2 (節點1)

調用 3: mergeTwoLists([2,4], [3,4])
  2 <= 3 ✓
  list1->next = 調用 4
  return list1 (節點2)

調用 4: mergeTwoLists([4], [3,4])
  4 > 3 ✗
  list2->next = 調用 5
  return list2 (節點3)

調用 5: mergeTwoLists([4], [4])
  4 <= 4 ✓
  list1->next = 調用 6
  return list1 (節點4)

調用 6: mergeTwoLists(NULL, [4])
  list1 為 NULL
  return list2 (節點4)

回溯：
調用 5 返回：4 → 4
調用 4 返回：3 → 4 → 4
調用 3 返回：2 → 3 → 4 → 4
調用 2 返回：1 → 2 → 3 → 4 → 4
調用 1 返回：1 → 1 → 2 → 3 → 4 → 4
```

| **空間複雜度** | O(m + n) | 遞歸棧深度 ❌ |

## 💡 Dummy Node 技巧深入理解

### 為什麼需要 Dummy Node？

```
問題：沒有 Dummy Node 時

struct ListNode* mergeTwoLists(struct ListNode* list1, struct ListNode* list2) {
    if (!list1) return list2;
    if (!list2) return list1;
    
    struct ListNode* head = NULL;  // 頭節點
    struct ListNode* tail = NULL;  // 尾節點
    
    // 初始化頭節點（需要特殊處理）
    if (list1->val <= list2->val) {
        head = tail = list1;
        list1 = list1->next;
    } else {
        head = tail = list2;
        list2 = list2->next;
    }
    
    // 剩餘部分...
    while (list1 && list2) {
        if (list1->val <= list2->val) {
            tail->next = list1;
            list1 = list1->next;
        } else {
            tail->next = list2;
            list2 = list2->next;
        }
        tail = tail->next;
    }
    
    tail->next = list1 ? list1 : list2;
    return head;
}

問題：
1. 需要特殊處理第一個節點
2. 代碼重複（初始化和循環中的邏輯相似）
3. 容易出錯
```

```
解決：使用 Dummy Node

struct ListNode* mergeTwoLists(struct ListNode* list1, struct ListNode* list2) {
    struct ListNode dum;      // Dummy Node
    struct ListNode* tail = &dum;
    dum.next = NULL;
    
    // 統一處理，無需特殊情況
    while (list1 && list2) {
        if (list1->val <= list2->val) {
            tail->next = list1;
            list1 = list1->next;
        } else {
            tail->next = list2;
            list2 = list2->next;
        }
        tail = tail->next;
    }
    
    tail->next = list1 ? list1 : list2;
    return dum.next;  // 返回真正的頭節點
}

優點：
1. 無需特殊處理第一個節點
2. 代碼簡潔統一
3. 減少出錯可能
```

### Dummy Node 的使用場景

```
適用場景：
1. 鏈表合併
2. 鏈表分割
3. 鏈表重排
4. 鏈表插入
5. 任何需要修改鏈表頭的操作

模板：
struct ListNode dummy;
struct ListNode* tail = &dummy;
dummy.next = NULL;

// 操作鏈表...

return dummy.next;  // 返回真正的頭
```

## ⚠️ 常見錯誤

### 錯誤 1：忘記處理剩餘鏈表

```c
// ❌ 錯誤：只處理了循環內的情況

    if (list1->val <= list2->val) {
        tail->next = list1;
        list1 = list1->next;
    } else {
        tail->next = list2;
        list2 = list2->next;
    }
    tail = tail->next;
}
// 忘記接上剩餘的鏈表！

return dum.next;  // 錯誤！結果不完整

// ✓ 正確：接上剩餘鏈表
tail->next = list1 ? list1 : list2;
return dum.next;
```

### 錯誤 2：沒有移動 tail 指針

```c
// ❌ 錯誤：忘記移動 tail
while (list1 && list2) {
    if (list1->val <= list2->val) {
        tail->next = list1;
        list1 = list1->next;

        tail->next = list2;

    // 忘記：tail = tail->next;
}

// 結果：只會接上第一個節點，後面的都丟失

// ✓ 正確：必須移動 tail
tail = tail->next;
```

```c
// 88 題：合併兩個有序數組
void merge(int* nums1, int nums1Size, int m, 
           int* nums2, int nums2Size, int n) {
    int i = m - 1, j = n - 1, k = m + n - 1;
    
    // 從後往前合併
    while (i >= 0 && j >= 0) {
        if (nums1[i] > nums2[j]) {
            nums1[k--] = nums1[i--];
        } else {
            nums1[k--] = nums2[j--];
        }
    }
    
    while (j >= 0) {
        nums1[k--] = nums2[j--];
    }
}
```

```c
struct ListNode* sortList(struct ListNode* head) {
```

#### 問題 1：如何合併 k 個有序鏈表？

```
方法 1：依次合併
  merge(list1, list2) → temp1
  merge(temp1, list3) → temp2
  ...
  
  時間：O(k × n × k) = O(k²n)
  
方法 2：分治法（推薦）
  兩兩合併，類似錦標賽
  
  時間：O(n × k × log k)
  
方法 3：優先隊列（最小堆）
  維護 k 個指針，每次選最小的
  
  時間：O(n × k × log k)
  空間：O(k)
```

```c
        list1 = list1->next;
```
