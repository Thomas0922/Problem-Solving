# LeetCode 24. Swap Nodes in Pairs - 完整學習筆記

## 📋 題目描述

給定一個鏈表，**兩兩交換**其中相鄰的節點，並返回交換後鏈表的頭節點。

你必須在**不修改節點值**的情況下完成本題（即，只能進行節點交換）。

**範例**：
```
範例 1：
輸入：head = [1,2,3,4]
輸出：[2,1,4,3]

  交換前：1 → 2 → 3 → 4
  交換後：2 → 1 → 4 → 3
         ︸︷︷︸   ︸︷︷︸
         第1組   第2組

範例 2：
輸入：head = []
輸出：[]

範例 3：
輸入：head = [1]
輸出：[1]

範例 4：
輸入：head = [1,2,3,4,5]
輸出：[2,1,4,3,5]

  交換前：1 → 2 → 3 → 4 → 5
  交換後：2 → 1 → 4 → 3 → 5
         ︸︷︷︸   ︸︷︷︸   ︸
         第1組   第2組   單獨
```

**限制**：
- 鏈表中節點的數目在範圍 `[0, 100]` 內
- `0 <= Node.val <= 100`

**關鍵理解**：
```
兩兩交換：
  每兩個相鄰節點為一組進行交換
  如果剩下單個節點，保持不變

交換操作：
  1 → 2 → 3 → 4
  變成：
  2 → 1 → 4 → 3
  
  不是交換節點的值！
  而是改變指針連接 ⭐
```

## 💡 基礎知識：鏈表節點交換

### 交換 vs 修改值

```
❌ 錯誤做法：交換值
  1 → 2 → 3 → 4
  只交換 val：
  node1.val = 2
  node2.val = 1
  
  問題：題目要求不能修改節點值！

✓ 正確做法：交換指針
  改變節點之間的連接關係
  
  原本：prev → 1 → 2 → 3
  變成：prev → 2 → 1 → 3
  
  通過修改 next 指針實現
```

### 指針交換的核心步驟

```
交換 1 和 2：

原始狀態：
  prev → 1 → 2 → 3
         ↑   ↑
       slow fast

步驟 1：slow.next = fast.next
  prev → 1 ┐    3
         └→ 2 →┘

步驟 2：fast.next = slow
  prev → 1 ← 2 → 3
         └───────→

步驟 3：prev.next = fast
  prev → 2 → 1 → 3 ✓

關鍵：必須先保存 fast.next！
```

### 為什麼需要 Dummy Node？

```
問題：如果直接從 head 開始
  head = 1 → 2 → 3 → 4
  交換後：2 → 1 → 3 → 4
  
  head 改變了！需要返回新的 head

解決：使用 dummy node
  dummy → 1 → 2 → 3 → 4
    ↑
  不會變
  
  交換後：
  dummy → 2 → 1 → 4 → 3
  
  返回 dummy.next 即可 ✓
```

## 🔧 方法一：迭代 + Dummy Node（你的解法）⭐

### 思路

1. 創建 dummy node 指向 head
2. 使用 prev 指針追蹤當前組的前一個節點
3. 每次交換 prev 後面的兩個節點
4. 移動 prev 到下一組

### 代碼實現（你的解法）

```c
struct ListNode* swapPairs(struct ListNode* head) {
    // 邊界情況：空鏈表或只有一個節點
    if (head == NULL || head->next == NULL) {
        return head;
    }

    // 創建 dummy node
    struct ListNode dummy;
    dummy.next = head;
    struct ListNode* prev = &dummy;

    // 遍歷鏈表，兩兩交換
    while (prev->next && prev->next->next) {
        // 獲取要交換的兩個節點
        struct ListNode* slow = prev->next;      // 第一個節點
        struct ListNode* fast = prev->next->next; // 第二個節點

        // 交換操作（三步）
        slow->next = fast->next;  // 步驟 1
        fast->next = slow;        // 步驟 2
        prev->next = fast;        // 步驟 3

        // 移動到下一組
        prev = slow;
    }

    return dummy.next;
}
```

### 執行流程詳解

```
範例：head = [1,2,3,4]

═══════════════════════════════════════
初始狀態：

  dummy → 1 → 2 → 3 → 4 → NULL
    ↑
   prev

═══════════════════════════════════════
第一次迭代（交換 1 和 2）：

準備：
  prev = dummy
  slow = 1
  fast = 2

  dummy → 1 → 2 → 3 → 4
    ↑     ↑   ↑
  prev slow fast

步驟 1：slow.next = fast.next
  dummy → 1 ┐   3 → 4
          └→ 2 →┘

步驟 2：fast.next = slow
  dummy → 1 ← 2 → 3 → 4
          └───────→

步驟 3：prev.next = fast
  dummy → 2 → 1 → 3 → 4 ✓

移動 prev：
  prev = slow (現在的 1)
  
  dummy → 2 → 1 → 3 → 4
              ↑
            prev

═══════════════════════════════════════
第二次迭代（交換 3 和 4）：

準備：
  prev = 1
  slow = 3
  fast = 4

  dummy → 2 → 1 → 3 → 4
              ↑   ↑   ↑
            prev slow fast

步驟 1：slow.next = fast.next
  dummy → 2 → 1 → 3 ┐
                  └→ 4 → NULL

步驟 2：fast.next = slow
  dummy → 2 → 1 → 3 ← 4
                  └─────→

步驟 3：prev.next = fast
  dummy → 2 → 1 → 4 → 3 → NULL ✓

移動 prev：
  prev = slow (現在的 3)
  
  dummy → 2 → 1 → 4 → 3 → NULL
                      ↑
                    prev

═══════════════════════════════════════
結束條件：

  prev.next = 3 ✓
  prev.next.next = NULL ✗
  
  循環結束

返回：
  dummy.next = 2
  
最終結果：2 → 1 → 4 → 3 ✓
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(n) | 遍歷一次鏈表 |
| **空間複雜度** | O(1) | 只用常數個指針 |

### 你的解法優點

**優勢**：
- ✅ **邏輯清晰**：使用 dummy node 簡化邊界處理
- ✅ **正確處理邊界**：空鏈表和單節點
- ✅ **變量命名**：slow/fast 易於理解
- ✅ **循環條件準確**：`prev->next && prev->next->next`
- ✅ **空間 O(1)**：只用指針，不用額外空間

**你的解法特點**：
```
1. Dummy node：避免特殊處理 head
2. 三步交換：清晰的指針操作順序
3. prev 追蹤：保持對前一個節點的引用
4. 循環條件：確保有兩個節點可交換
```

## 🌟 方法二：遞歸解法

### 核心思想

```
遞歸思路：
  1. 交換前兩個節點
  2. 遞歸處理剩餘鏈表
  3. 連接結果

範例：1 → 2 → 3 → 4

步驟 1：交換 1 和 2
  2 → 1 → ?

步驟 2：遞歸處理 3 → 4
  返回：4 → 3

步驟 3：連接
  2 → 1 → 4 → 3 ✓
```

### 代碼實現

```c
struct ListNode* swapPairs(struct ListNode* head) {
    // 遞歸終止條件
    if (head == NULL || head->next == NULL) {
        return head;
    }

    // 保存第二個節點
    struct ListNode* newHead = head->next;
    
    // 遞歸處理剩餘鏈表
    head->next = swapPairs(newHead->next);
    
    // 第二個節點指向第一個節點
    newHead->next = head;
    
    return newHead;
}
```

### 遞歸執行流程

```
範例：head = [1,2,3,4]

═══════════════════════════════════════
調用棧展開：

swapPairs(1→2→3→4)
  ↓
  newHead = 2
  head.next = swapPairs(3→4)
    ↓
    newHead = 4
    head.next = swapPairs(NULL)
      ↓
      返回 NULL
    ↓
    3.next = NULL
    4.next = 3
    返回 4
  ↓
  1.next = 4→3
  2.next = 1
  返回 2

═══════════════════════════════════════
遞歸回溯過程：

最內層：swapPairs(NULL)
  返回：NULL

第二層：swapPairs(3→4)
  3.next = NULL
  4.next = 3
  返回：4 → 3 → NULL

第一層：swapPairs(1→2→3→4)
  1.next = 4 → 3
  2.next = 1
  返回：2 → 1 → 4 → 3 ✓
```

### 圖解遞歸

```
原始：1 → 2 → 3 → 4

═══════════════════════════════════════
步驟 1：處理 1 和 2

  newHead = 2
  
  1 → ?
  2 → ?
  
  需要：swapPairs(3→4)

═══════════════════════════════════════
步驟 2：遞歸處理 3 和 4

  newHead = 4
  
  3 → NULL
  4 → 3
  
  返回：4 → 3

═══════════════════════════════════════
步驟 3：連接結果

  1.next = 4 → 3
  2.next = 1
  
  最終：2 → 1 → 4 → 3 ✓
```

## ⚠️ 常見錯誤

### 錯誤 1：忘記處理邊界情況

```c
// ❌ 錯誤：沒有檢查空鏈表
struct ListNode* swapPairs(struct ListNode* head) {
    struct ListNode dummy;
    dummy.next = head;
    struct ListNode* prev = &dummy;
    
    while (prev->next && prev->next->next) {  // 如果 head 為 NULL 會出錯
        // ...
    }
}

// ✓ 正確（你的做法）
if (head == NULL || head->next == NULL) {
    return head;
}
```

### 錯誤 2：交換順序錯誤

```c
// ❌ 錯誤：先改 prev.next
prev->next = fast;        // 錯！
slow->next = fast->next;  // slow 已經斷開連接
fast->next = slow;

// ✓ 正確（你的做法）
slow->next = fast->next;  // 先保存後續鏈表
fast->next = slow;        // 再改變連接
prev->next = fast;        // 最後更新 prev
```

### 錯誤 3：循環條件錯誤

```c
// ❌ 錯誤：只檢查 prev->next
while (prev->next) {  // 錯！可能只剩一個節點
    // ...
}

// ✓ 正確（你的做法）
while (prev->next && prev->next->next) {  // 確保有兩個節點
    // ...
}
```

### 錯誤 4：prev 更新錯誤

```c
// ❌ 錯誤：更新到 fast
prev = fast;  // 錯！fast 已經移到前面

// ✓ 正確（你的做法）
prev = slow;  // slow 是交換後的第二個節點
```

### 錯誤 5：使用棧上的 dummy

```c
// ⚠️ 注意：你的做法
struct ListNode dummy;  // 棧上分配
dummy.next = head;
struct ListNode* prev = &dummy;  // 取地址

// 這樣做是可以的，因為：
// 1. dummy 的生命週期在函數內有效
// 2. 最後返回 dummy.next，不返回 dummy 的地址
// 3. 是常見且正確的做法 ✓

// 另一種做法（堆上分配）：
struct ListNode* dummy = (struct ListNode*)malloc(sizeof(struct ListNode));
dummy->next = head;
// ... 使用後需要 free(dummy)
```

### 錯誤 6：沒有保存 fast->next

```c
// ❌ 錯誤：直接修改指針
fast->next = slow;
slow->next = fast->next;  // 錯！fast->next 已經改變

// ✓ 正確（你的做法）
slow->next = fast->next;  // 先保存
fast->next = slow;        // 再修改
```

## 💡 指針操作深入理解

### 三步交換的順序重要性

```
為什麼必須按這個順序？

原始：prev → 1 → 2 → 3

═══════════════════════════════════════
✓ 正確順序（你的做法）：

步驟 1：slow.next = fast.next
  prev → 1 ┐   3
         └→ 2 →┘
  保存了後續鏈表的連接 ✓

步驟 2：fast.next = slow
  prev → 1 ← 2   3
         └───────→
  完成節點 2 的指向 ✓

步驟 3：prev.next = fast
  prev → 2 → 1 → 3
  完成 prev 的指向 ✓

═══════════════════════════════════════
❌ 錯誤順序 1：先改 fast.next

步驟 1：fast.next = slow
  prev → 1 ← 2   3
         └───────→

步驟 2：slow.next = fast.next
  prev → 1 → 1 ✗  (循環！)
  
  問題：fast.next 已經是 slow

═══════════════════════════════════════
❌ 錯誤順序 2：先改 prev.next

步驟 1：prev.next = fast
  prev → 2   1 → 3
         斷開連接 ✗

步驟 2：slow.next = fast.next
  1 找不到了！
```

### Dummy Node 的作用

```
沒有 dummy node 的問題：

原始：1 → 2 → 3 → 4

交換 1 和 2：
  需要修改 head
  但沒有指向 head 的前驅節點
  
  newHead = 2
  1.next = 3
  2.next = 1
  
  必須特殊處理第一組 ✗

═══════════════════════════════════════
使用 dummy node（你的做法）：

  dummy → 1 → 2 → 3 → 4
    ↑
  prev（統一的前驅節點）

  所有組都用相同的邏輯處理 ✓
  不需要特殊處理第一組 ✓
  最後返回 dummy.next ✓
```

### 循環條件的設計

```
為什麼是 prev->next && prev->next->next？

檢查項目：
1. prev->next：確保有第一個節點
2. prev->next->next：確保有第二個節點

範例分析：

情況 1：偶數節點 [1,2,3,4]
  最後：prev = 3
  prev->next = NULL ✓
  停止 ✓

情況 2：奇數節點 [1,2,3]
  最後：prev = 1
  prev->next = 3 ✓
  prev->next->next = NULL ✓
  停止 ✓

情況 3：單節點 [1]
  初始：prev = dummy
  prev->next = 1 ✓
  prev->next->next = NULL ✓
  不進入循環 ✓
```

#### 問題 1：如果要交換三個節點一組？

```c
// k=3 的情況
範例：[1,2,3,4,5,6]
輸出：[3,2,1,6,5,4]

思路：
1. 每次處理三個節點
2. 反轉這三個節點
3. 連接到結果鏈表

這就是 LeetCode 25 題
```

#### 問題 2：能否原地交換值而不是指針？

```c
// ⚠️ 題目要求不能修改節點值
// 但如果允許：

struct ListNode* swapPairs(struct ListNode* head) {
    struct ListNode* curr = head;
    
    while (curr && curr->next) {
        // 交換值
        int temp = curr->val;
        curr->val = curr->next->val;
        curr->next->val = temp;
        
        // 移動到下一對
        curr = curr->next->next;
    }
    
    return head;
}

// 時間 O(n)，空間 O(1)
// 但不符合題目要求！
```

## 🎓 總結

**24. Swap Nodes in Pairs 的核心**：

```
問題：兩兩交換相鄰節點
關鍵：Dummy node + 指針操作

核心步驟：
1. 創建 dummy node
2. 使用 prev 追蹤前驅
3. 三步交換指針
4. 移動到下一組

三步交換順序（必須記住）：
1. slow.next = fast.next  （保存後續）
2. fast.next = slow       （第二個指向第一個）
3. prev.next = fast       （前驅指向第二個）
```

5. ✅ **指針順序正確**：三步交換的順序至關重要
