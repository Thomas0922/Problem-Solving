# LeetCode 476. Number Complement - 完整學習筆記

## 📋 題目描述

給定一個**正整數**，輸出它的**補數**（complement）。補數是將該數的二進制表示中的**每一位**翻轉後得到的數（0 變 1，1 變 0）。

**注意**：只翻轉**有效位元**，不包括前導零。

**範例**：
```
輸入：num = 5
輸出：2
解釋：5 的二進制是 101，補數是 010，即十進制的 2

輸入：num = 1
輸出：0
解釋：1 的二進制是 1，補數是 0

輸入：num = 7
輸出：0
解釋：7 的二進制是 111，補數是 000，即十進制的 0
```

**限制**：
- `1 <= num < 2^31`
- 給定的整數保證在 32 位有符號整數範圍內

**關鍵理解**：
```
5  = 101  → 補數 = 010 = 2  ✓
5  = 00000101 → 補數 ≠ 11111010 ❌ (不翻轉前導零！)
```

## 💡 基礎知識：補數與位翻轉

### 什麼是補數？

```
原數：  101 (二進制)
補數：  010 (每位翻轉)

原數：  1100 (二進制)
補數：  0011 (每位翻轉)
```

### 關鍵：只翻轉有效位元

```
錯誤理解：
5 的 32 位表示：00000000000000000000000000000101
全部翻轉：      11111111111111111111111111111010 ❌

正確理解：
5 的有效位：101
只翻轉有效位：010 ✓
```

### 核心技巧：XOR 翻轉

```
XOR 的性質：
0 ^ 1 = 1  (0 翻轉成 1)
1 ^ 1 = 0  (1 翻轉成 0)

所以：num ^ mask = complement
其中 mask 的每一位都是 1
```

## 🔧 方法一：逐位處理 + 位移構建

### 思路

類似 191 題的位運算方法：
1. 從低位到高位逐位處理
2. 翻轉每一位（0→1, 1→0）
3. 用位移構建結果

### 代碼實現

```c
int findComplement(int num) {
    int result = 0;
    int power = 1;  // 2^0, 2^1, 2^2, ...
    
    while (num > 0) {
        // 如果當前位是 0，翻轉後是 1，加到結果
        if ((num & 1) == 0) {
            result += power;
        }
        
        num >>= 1;    // 處理下一位
        power <<= 1;  // power *= 2
    }
    
    return result;
}
```

### 執行流程

```
num = 5 (二進制：101)

初始：result = 0, power = 1

迭代 1：
  num & 1 = 1 (不加)
  result = 0
  num >>= 1 → num = 2 (10)
  power <<= 1 → power = 2

迭代 2：
  num & 1 = 0 (加 power)
  result = 0 + 2 = 2
  num >>= 1 → num = 1 (1)
  power <<= 1 → power = 4

迭代 3：
  num & 1 = 1 (不加)
  result = 2
  num >>= 1 → num = 0
  power <<= 1 → power = 8

結束：result = 2 ✓

驗證：5 = 101, 補數 = 010 = 2 ✓
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(log n) | n 的位元數，最多 31 次 |
| **空間複雜度** | O(1) | 只用常數空間 |

### 優缺點

**優點**：
- ✅ 邏輯清晰，容易理解
- ✅ 不需要額外計算位元數

**缺點**：
- ❌ 需要額外變數 power
- ❌ 代碼相對冗長

## 🚀 方法二：建立 Mask + XOR（推薦解法）

### 思路

這是很好的解法：
1. 計算 num 的位元數（count）
2. 建立一個有 count 個 '1' 的 mask
3. 用 XOR 翻轉所有位元

### 代碼實現

```c
int findComplement(int num) {
    int mask = 0, ans;
    int count = 0, c = num;
    
    // 步驟 1：計算位元數
    while (c) {
        count++;
        c >>= 1;
    }
    
    // 步驟 2：建立 mask
    for (int i = 0; i < count; i++) {
        mask = (mask << 1) | 1;
    }
    
    // 步驟 3：XOR 翻轉
    ans = mask ^ num;
    return ans;
}
```

### 詳細推演

```
num = 5 (二進制：101)

步驟 1：計算位元數
  c = 5 (101)
  迭代 1：count = 1, c = 2 (10)
  迭代 2：count = 2, c = 1 (1)
  迭代 3：count = 3, c = 0
  → count = 3

步驟 2：建立 mask（3 個 '1'）
  初始：mask = 0 (000)
  
  i = 0：mask = (0 << 1) | 1 = 001
  i = 1：mask = (1 << 1) | 1 = 011
  i = 2：mask = (3 << 1) | 1 = 111
  
  → mask = 7 (111)

步驟 3：XOR 翻轉
  num  = 101
  mask = 111
  -------
  ans  = 010 = 2 ✓
```

### mask 建立過程詳解

```
初始：mask = 000

i = 0：
  mask << 1 = 000
  (000) | 1 = 001
  mask = 001

i = 1：
  mask << 1 = 010
  (010) | 1 = 011
  mask = 011

i = 2：
  mask << 1 = 110
  (110) | 1 = 111
  mask = 111

最終：mask = 111 (3 個 '1')
```

### XOR 翻轉原理

```
為什麼 mask ^ num 能翻轉？

mask 的每一位都是 1：
  1 ^ 0 = 1  (0 翻轉成 1)
  1 ^ 1 = 0  (1 翻轉成 0)

範例：
  num  = 101
  mask = 111
  
  第 1 位：1 ^ 1 = 0 ✓
  第 2 位：1 ^ 0 = 1 ✓
  第 3 位：1 ^ 1 = 0 ✓
  
  結果 = 010 ✓
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(log n) | 兩次循環，都是 O(log n) |
| **空間複雜度** | O(1) | 只用常數空間 |

### 優缺點

**優點**：
- ✅ 思路清晰，分步驟進行
- ✅ 利用 XOR 的翻轉特性
- ✅ 易於理解和實現

**缺點**：
- ⚠️ 需要兩次循環（可優化）
- ⚠️ 代碼稍長

## 🌟 方法三：優化的 Mask 建立（最優解）

### 思路

**關鍵優化**：在計算位元數的同時建立 mask！

```
原方法：
  1. 計算位元數 → O(log n)
  2. 建立 mask  → O(log n)
  總共：2 * O(log n)

優化方法：
  同時進行 → O(log n)
```

### 代碼實現

```c
int findComplement(int num) {
    int mask = 0;
    int temp = num;
    
    // 同時計算位元數和建立 mask
    while (temp > 0) {
        mask = (mask << 1) | 1;  // mask 左移並加 1
        temp >>= 1;              // 處理下一位
    }
    
    return mask ^ num;
}
```

### 執行流程

```
num = 5 (二進制：101)

初始：mask = 0, temp = 5

迭代 1：
  mask = (0 << 1) | 1 = 001
  temp = 5 >> 1 = 2 (10)

迭代 2：
  mask = (1 << 1) | 1 = 011
  temp = 2 >> 1 = 1 (1)

迭代 3：
  mask = (3 << 1) | 1 = 111
  temp = 1 >> 1 = 0

結束：mask = 7 (111)

XOR 翻轉：
  111 ^ 101 = 010 = 2 ✓
```

### 為什麼這樣可以？

```
觀察 num 和 mask 的變化：

num = 5 (101)

temp    mask    說明
5 (101) 000     初始
2 (10)  001     處理第 1 位
1 (1)   011     處理第 2 位
0       111     處理第 3 位

規律：
- temp 每次右移，處理一位
- mask 每次左移並加 1，建立對應的 '1'
- 循環次數 = num 的位元數
- 最終 mask 恰好有 num 位元數個 '1'
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(log n) | 只循環一次 ⭐ |
| **空間複雜度** | O(1) | 只用常數空間 |

### 優勢

**相比方法二的優勢**：
```
方法二：兩次循環
  while (計算位元數)  → O(log n)
  for (建立 mask)     → O(log n)

方法三：一次循環
  while (同時進行)    → O(log n) ⭐

時間複雜度雖然都是 O(log n)，
但實際執行速度快一倍！
```

## 🎯 方法四：利用最高位建立 Mask

### 思路

找到 num 的最高位，然後用位移快速建立 mask。

### 代碼實現

```c
int findComplement(int num) {
    // 找到最高位的位置
    int highestBit = 0;
    int temp = num;
    
    while (temp > 0) {
        highestBit++;
        temp >>= 1;
    }
    
    // 建立 mask：2^highestBit - 1
    // 例如：highestBit = 3，mask = 2^3 - 1 = 7 (111)
    int mask = (1 << highestBit) - 1;
    
    return mask ^ num;
}
```

### 執行流程

```
num = 5 (二進制：101)

步驟 1：找最高位
  temp = 5 (101)
  迭代 1：highestBit = 1, temp = 2
  迭代 2：highestBit = 2, temp = 1
  迭代 3：highestBit = 3, temp = 0
  → highestBit = 3

步驟 2：建立 mask
  1 << highestBit = 1 << 3 = 8 (1000)
  mask = 8 - 1 = 7 (111)

步驟 3：XOR 翻轉
  111 ^ 101 = 010 = 2 ✓
```

### 數學原理

```
為什麼 (1 << n) - 1 能產生 n 個 '1'？

n = 3：
  1 << 3 = 1000 (二進制)
         = 8 (十進制)
  8 - 1  = 0111 (二進制)
         = 7 (十進制)
  結果：3 個 '1' ✓

n = 4：
  1 << 4 = 10000
  16 - 1 = 01111
  結果：4 個 '1' ✓

規律：
  2^n - 1 = n 個 '1'
  例如：2^3 - 1 = 7 = 111
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(log n) | 一次循環 |
| **空間複雜度** | O(1) | 只用常數空間 |

### 優缺點

**優點**：
- ✅ 利用數學性質，代碼簡潔
- ✅ 易於理解 `2^n - 1` 的技巧

**缺點**：
- ⚠️ 和方法三複雜度相同

## 🔥 方法五：NOT 運算（錯誤陷阱）

### ❌ 錯誤代碼

```c
int findComplement(int num) {
    return ~num;  // 錯誤！
}
```

### 為什麼錯誤？

```
num = 5 的二進制（32 位）：
00000000000000000000000000000101

~num 的結果：
11111111111111111111111111111010
= -6 (補碼表示) ❌

期望的結果：
010 = 2 ✓

問題：
- ~ 會翻轉所有 32 位，包括前導零
- 前導零翻轉成 1，導致錯誤結果
```

### 正確做法

```c
// 必須先建立 mask，限制翻轉範圍
int findComplement(int num) {
    int mask = 0;
    int temp = num;
    while (temp > 0) {
        mask = (mask << 1) | 1;
        temp >>= 1;
    }
    return mask ^ num;  // 用 XOR，不是 NOT
}
```

## 💡 核心技巧總結

### 技巧 1：XOR 翻轉位元

```
關鍵性質：
  x ^ 1 = ~x  (翻轉)
  x ^ 0 = x   (不變)

應用：
  num ^ mask = complement
  其中 mask 每位都是 1
```

### 技巧 2：建立全 1 的 Mask

```
方法 A：逐位構建
  mask = 0
  while (temp) {
      mask = (mask << 1) | 1
      temp >>= 1
  }

方法 B：數學公式
  mask = (1 << bitCount) - 1
  
兩者等價，選擇取決於場景
```

### 技巧 3：同時計算多個值

```
優化前：
  第一個循環：計算位元數
  第二個循環：建立 mask

優化後：
  一個循環：同時完成兩件事
  
效率提升：2x → 1x
```

## ⚠️ 常見錯誤

### 錯誤 1：使用 NOT 運算符

```c
// ❌ 錯誤
int findComplement(int num) {
    return ~num;  // 會翻轉所有 32 位！
}

// 測試：num = 5
// ~5 = 11111111111111111111111111111010
//    = -6 ❌

// ✅ 正確：使用 mask 限制範圍
return mask ^ num;
```

### 錯誤 2：Mask 建立錯誤

```c
// ❌ 錯誤：mask 初始值錯誤
int mask = 1;  // 錯！應該從 0 開始
for (int i = 0; i < count; i++) {
    mask = (mask << 1) | 1;
}
// 結果：多一個 '1'

// ✅ 正確
int mask = 0;  // 從 0 開始
for (int i = 0; i < count; i++) {
    mask = (mask << 1) | 1;
}
```

### 錯誤 3：沒有複製 num

```c
// ❌ 錯誤：直接修改 num
while (num) {
    count++;
    num >>= 1;  // num 被改變了！
}
// 之後無法使用 num

// ✅ 正確：用臨時變數
int temp = num;
while (temp) {
    count++;
    temp >>= 1;
}
// num 保持不變
```

### 錯誤 4：位移方向錯誤

```c
// ❌ 錯誤：右移 mask
for (int i = 0; i < count; i++) {
    mask = (mask >> 1) | 1;  // 錯！應該左移
}

// ✅ 正確：左移 mask
for (int i = 0; i < count; i++) {
    mask = (mask << 1) | 1;
}
```

```c
// __builtin_clz = count leading zeros
```

#### 問題 3：如何優化到 O(1)？

```c
// 理論上不可能真正達到 O(1)
// 因為必須檢查所有位元
// 但可以用查表法接近 O(1)

// 查表法：預先計算所有可能的補數
// 限制：只適用於小範圍數字
int table[256];  // 0-255 的補數表

void buildTable() {
    for (int i = 0; i < 256; i++) {
        // 計算 i 的補數
        int bitCount = 0;
        int temp = i;
        if (i == 0) {
            table[i] = 0;
            continue;
        }
        while (temp) {
            bitCount++;
            temp >>= 1;
        }
        int mask = (1 << bitCount) - 1;
        table[i] = mask ^ i;
    }
}

// 使用：O(1) 查表
int findComplement(int num) {
    if (num < 256) {
        return table[num];
    }
    // 大於 255 用一般方法
    // ...
}
```

### 位運算速查表

```
基礎運算：
  & (AND)：兩位都是 1 才是 1
  | (OR)：至少一位是 1 就是 1
  ^ (XOR)：兩位不同為 1
  ~ (NOT)：位取反
  << (左移)：左移 n 位，相當於乘以 2^n
  >> (右移)：右移 n 位，相當於除以 2^n

常用技巧：
  n & 1：檢查最低位
  n & (n-1)：消除最右邊的 '1'
  n & -n：取出最右邊的 '1'
  n | (n+1)：將最右邊的 0 變成 1
  n ^ n：結果為 0
  n ^ 0：結果為 n
  (1 << n) - 1：產生 n 個 '1'
```

## 🏆 總結

**476. Number Complement 的核心**：

```
問題：找出正整數的補數（翻轉二進制的每一位）
關鍵：只翻轉有效位元，不翻轉前導零

核心技巧：
1. XOR 翻轉：mask ^ num
2. 建立 mask：逐位構建或用 2^n - 1
3. 優化：同時計算位元數和建立 mask

最優解法（方法三）：
while (temp > 0) {
    mask = (mask << 1) | 1;
    temp >>= 1;
}
return mask ^ num;

時間複雜度：O(log n)
空間複雜度：O(1)
```

**關鍵記憶點**：
1. ✅ **XOR 用於翻轉**：`x ^ 1` 翻轉位元
2. ✅ **不能用 NOT**：`~num` 會翻轉所有 32 位
3. ✅ **mask 必須精確**：恰好有 num 的位元數個 '1'
4. ✅ **左移構建 mask**：`(mask << 1) | 1`
5. ✅ **2^n - 1 技巧**：快速產生 n 個 '1'
6. ✅ **同時操作優化**：一個循環完成多件事

**與 191 題的聯繫**：
- 191 題：計算 '1' 的個數
- 本題：翻轉所有位元
- 共同點：都需要遍歷位元
- 區別：191 統計，本題翻轉

**面試要點**：
- 能快速想到 XOR 翻轉 ⭐
- 理解為什麼不能用 NOT
- 能優化到一次循環
- 解釋 mask 建立原理
