# LeetCode 225. Implement Stack using Queues - 完整學習筆記

## 📋 題目描述

請你僅使用兩個隊列實現一個後進先出（LIFO）的棧，並支持普通棧的全部四種操作（`push`、`pop`、`top` 和 `empty`）。

實現 `MyStack` 類：
- `void push(int x)` 將元素 x 壓入棧頂
- `int pop()` 移除並返回棧頂元素
- `int top()` 返回棧頂元素
- `boolean empty()` 如果棧是空的，返回 true；否則，返回 false

**注意**：
- 你只能使用隊列的基本操作 —— 也就是 `push to back`、`peek/pop from front`、`size` 和 `is empty` 這些操作
- 你所使用的語言也許不支持隊列。你可以使用 list 或者 deque（雙端隊列）來模擬一個隊列，只要是標準的隊列操作即可

**範例**：
```
輸入：
["MyStack", "push", "push", "top", "pop", "empty"]
[[], [1], [2], [], [], []]

輸出：
[null, null, null, 2, 2, false]

解釋：
MyStack myStack = new MyStack();
myStack.push(1);
myStack.push(2);
myStack.top();   // 返回 2
myStack.pop();   // 返回 2
myStack.empty(); // 返回 False
```

**限制**：
- `1 <= x <= 9`
- 最多調用 `100` 次 `push`、`pop`、`top` 和 `empty`
- 每次調用 `pop` 和 `top` 都保證棧不為空

**進階**：你能否僅用一個隊列來實現棧？

**關鍵理解**：
```
隊列：先進先出（FIFO）
  push(1), push(2), push(3)
  隊列：[1, 2, 3]
        ↑     ↑
      front  rear
  pop() → 1（先進先出）

棧：後進先出（LIFO）
  push(1), push(2), push(3)
  棧：[1, 2, 3]
           ↑
          top
  pop() → 3（後進先出）

挑戰：
  如何用 FIFO 的隊列
  實現 LIFO 的棧？⭐
```

### 發現的問題

```c
你的代碼：

typedef struct {
    Node* front;
    Node* rear;
} MyStack;

void myStackPush(MyStack* obj, int x) {
    Node* new = malloc(sizeof(Node));
    new->val = x;
    new->next = obj->front;  // 直接插入鏈表頭部

```

```
這就像：
  題目：請用勺子吃飯
```

```c

  obj->rear = NULL;  // 創建了但從不使用

問題 2：myStackFree 有嚴重錯誤
  void myStackFree(MyStack* obj) {
```

## 💡 基礎知識：隊列操作

### 隊列的標準操作

```
隊列（Queue）：

結構：
  [1] → [2] → [3] → NULL
   ↑           ↑
  front       rear

允許的操作：
  1. enqueue(x)：從 rear 加入
     [1] → [2] → [3] → [4] → NULL
      ↑                 ↑
     front             rear
  
  2. dequeue()：從 front 移除
     [2] → [3] → [4] → NULL
      ↑           ↑
     front       rear
  
  3. front()/peek()：查看 front 元素
  
  4. isEmpty()：檢查是否為空

不允許的操作：❌
  - 從中間插入
  - 從 rear 移除
  - 直接訪問節點的 next
  
必須遵守這些限制！⭐
```

## 🔧 方法一：雙隊列法

### 核心思想

```
使用兩個隊列：
  q1：主隊列
  q2：輔助隊列

push(x) 操作：
  直接 enqueue 到 q1

pop() 操作：
  1. 把 q1 的前 n-1 個元素移到 q2
  2. q1 剩下最後一個就是要 pop 的
  3. 交換 q1 和 q2
  
範例：
  棧：[1, 2, 3]（3 在頂部）
  
  q1：[1, 2, 3]
       ↑     ↑
      front rear
  
  pop()：
    移動 1 → q2：q2 = [1]
    移動 2 → q2：q2 = [1, 2]
    pop 3：返回 3
    交換：q1 = [1, 2], q2 = []
```

### 完整代碼（雙隊列）

```c
// ═══════════════════════════════════════
// 第一部分：實現隊列
// ═══════════════════════════════════════
typedef struct Node {
    int val;
    struct Node* next;
} Node;

typedef struct {
    Node* front;
    Node* rear;
    int size;
} Queue;

Queue* queueCreate() {
    Queue* q = (Queue*)malloc(sizeof(Queue));
    q->front = NULL;
    q->rear = NULL;
    q->size = 0;
    return q;
}

// Enqueue：從尾部加入 O(1)
void enqueue(Queue* q, int x) {
    Node* new = (Node*)malloc(sizeof(Node));
    new->val = x;
    new->next = NULL;
    
    if (q->rear == NULL) {
        q->front = q->rear = new;
    } else {
        q->rear->next = new;
        q->rear = new;
    }
    q->size++;
}

// Dequeue：從頭部移除 O(1)
int dequeue(Queue* q) {
    if (q->front == NULL) return -1;
    
    Node* temp = q->front;
    int val = temp->val;
    q->front = temp->next;
    
    if (q->front == NULL) {
        q->rear = NULL;
    }
    
    free(temp);
    q->size--;
    return val;
}

// Front：查看頭部元素 O(1)
int queueFront(Queue* q) {
    if (q->front == NULL) return -1;
    return q->front->val;
}

bool queueEmpty(Queue* q) {
    return q->front == NULL;
}

int queueSize(Queue* q) {
    return q->size;
}

void queueFree(Queue* q) {
    while (!queueEmpty(q)) {
        dequeue(q);
    }
    free(q);
}

// ═══════════════════════════════════════
// 第二部分：用雙隊列實現棧
// ═══════════════════════════════════════
typedef struct {
    Queue* q1;
    Queue* q2;
} MyStack;

MyStack* myStackCreate() {
    MyStack* obj = (MyStack*)malloc(sizeof(MyStack));
    obj->q1 = queueCreate();
    obj->q2 = queueCreate();
    return obj;
}

// Push：O(1)
void myStackPush(MyStack* obj, int x) {
    enqueue(obj->q1, x);
}

// Pop：O(n)
int myStackPop(MyStack* obj) {
    // 把 q1 的前 n-1 個移到 q2
    int n = queueSize(obj->q1);
    for (int i = 0; i < n - 1; i++) {
        enqueue(obj->q2, dequeue(obj->q1));
    }
    
    // q1 剩下的就是要 pop 的
    int result = dequeue(obj->q1);
    
    // 交換 q1 和 q2
    Queue* temp = obj->q1;
    obj->q1 = obj->q2;
    obj->q2 = temp;
    
    return result;
}

// Top：O(n)
int myStackTop(MyStack* obj) {
    // 把 q1 的前 n-1 個移到 q2
    int n = queueSize(obj->q1);
    for (int i = 0; i < n - 1; i++) {
        enqueue(obj->q2, dequeue(obj->q1));
    }
    
    // q1 剩下的就是 top
    int result = queueFront(obj->q1);
    
    // 也要移到 q2
    enqueue(obj->q2, dequeue(obj->q1));
    
    // 交換
    Queue* temp = obj->q1;
    obj->q1 = obj->q2;
    obj->q2 = temp;
    
    return result;
}

bool myStackEmpty(MyStack* obj) {
    return queueEmpty(obj->q1);
}

void myStackFree(MyStack* obj) {
    queueFree(obj->q1);
    queueFree(obj->q2);
    free(obj);
}
```

## 🌟 方法二：單隊列法（最優）⭐

### 核心思想

```
只用一個隊列！

關鍵技巧：
  push 時把隊列旋轉
  使得新元素總是在 front

push(x) 操作：
  1. enqueue(x)
  2. 把前面的 n-1 個元素依次 dequeue 再 enqueue
  3. 這樣 x 就到了 front！

範例：
  初始：隊列 = [1, 2]
        1 → 2
        ↑   ↑
       front rear
  
  push(3)：
    步驟 1：enqueue(3)
      隊列 = [1, 2, 3]
    
    步驟 2：旋轉（移動 2 次）
      dequeue(1), enqueue(1)：[2, 3, 1]
      dequeue(2), enqueue(2)：[3, 1, 2]
    
    結果：[3, 1, 2]  ⭐ 3 在 front
          ↑     ↑
         front rear
  
  pop()：
    直接 dequeue() → 3 ✓
```

### 完整代碼（單隊列）⭐

```c
// ═══════════════════════════════════════
// 隊列實現（同上）
// ═══════════════════════════════════════
// ... 省略，和雙隊列法相同 ...

// ═══════════════════════════════════════
// 用單隊列實現棧
// ═══════════════════════════════════════
typedef struct {
    Queue* q;
} MyStack;

MyStack* myStackCreate() {
    MyStack* obj = (MyStack*)malloc(sizeof(MyStack));
    obj->q = queueCreate();
    return obj;
}

// Push：O(n) ⭐ 但讓其他操作變 O(1)
void myStackPush(MyStack* obj, int x) {
    int n = queueSize(obj->q);
    
    // 1. enqueue 新元素
    enqueue(obj->q, x);
    
    // 2. 旋轉：把前面的 n 個元素移到後面
    for (int i = 0; i < n; i++) {
        enqueue(obj->q, dequeue(obj->q));
    }
    
    // 現在 x 在 front！⭐
}

// Pop：O(1) ⭐
int myStackPop(MyStack* obj) {
    return dequeue(obj->q);
}

// Top：O(1) ⭐
int myStackTop(MyStack* obj) {
    return queueFront(obj->q);
}

bool myStackEmpty(MyStack* obj) {
    return queueEmpty(obj->q);
}

void myStackFree(MyStack* obj) {
    queueFree(obj->q);
    free(obj);
}
```

### 執行流程（單隊列）

```
範例：push(1), push(2), push(3), pop(), top()

═══════════════════════════════════════
push(1)：

  enqueue(1)：q = [1]
  旋轉 0 次（因為 n=0）
  
  結果：q = [1]

═══════════════════════════════════════
push(2)：

  enqueue(2)：q = [1, 2]
  旋轉 1 次：
    dequeue(1), enqueue(1)：q = [2, 1]
  
  結果：q = [2, 1]  ⭐ 2 在 front

═══════════════════════════════════════
push(3)：

  enqueue(3)：q = [2, 1, 3]
  旋轉 2 次：
    dequeue(2), enqueue(2)：q = [1, 3, 2]
    dequeue(1), enqueue(1)：q = [3, 2, 1]
  
  結果：q = [3, 2, 1]  ⭐ 3 在 front

═══════════════════════════════════════
pop()：

  dequeue() → 3 ✓
  
  結果：q = [2, 1]

═══════════════════════════════════════
top()：

  queueFront() → 2 ✓
```

| **推薦度** | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |

### 選擇建議

```
單隊列法（推薦）⭐：
  優點：
    - pop/top 是 O(1)
    - 只需一個隊列
    - 代碼更簡單
    
  權衡：
    - push 是 O(n)
    - 但通常 pop/top 更頻繁

雙隊列法：
  優點：
    - push 是 O(1)
    
  缺點：
    - pop/top 是 O(n)
    - 需要兩個隊列
    - 需要交換隊列

結論：
  單隊列法更優 ⭐
  符合進階要求（只用一個隊列）
```

## ⚠️ 常見錯誤

### 錯誤 1：直接用鏈表（你的問題）

```c
// ❌ 錯誤：直接用鏈表實現棧
void myStackPush(MyStack* obj, int x) {
    Node* new = malloc(sizeof(Node));
    new->next = obj->front;  // 直接操作鏈表
    obj->front = new;
}

// 問題：
// 沒有使用隊列的操作
// 題目要求必須用隊列

// ✓ 正確：必須用隊列操作
void myStackPush(MyStack* obj, int x) {
    enqueue(obj->q, x);  // 用隊列的 enqueue
    // 然後旋轉
}
```

### 錯誤 2：單隊列旋轉次數錯誤

```c
// ❌ 錯誤：旋轉 n+1 次
void myStackPush(MyStack* obj, int x) {
    int n = queueSize(obj->q);
    enqueue(obj->q, x);
    
    for (int i = 0; i <= n; i++) {  // 錯！
        enqueue(obj->q, dequeue(obj->q));
    }
}

// 問題：
// 旋轉了 n+1 次，回到原位
// 應該旋轉 n 次

// ✓ 正確
for (int i = 0; i < n; i++) {  // 旋轉 n 次
    enqueue(obj->q, dequeue(obj->q));
}
```

### 錯誤 3：忘記交換隊列（雙隊列法）

```c
// ❌ 錯誤：沒有交換
int myStackPop(MyStack* obj) {
    int n = queueSize(obj->q1);
    for (int i = 0; i < n - 1; i++) {
        enqueue(obj->q2, dequeue(obj->q1));
    }
    return dequeue(obj->q1);
    // 忘記交換！下次 pop 會出錯
}

// ✓ 正確
int result = dequeue(obj->q1);
Queue* temp = obj->q1;
obj->q1 = obj->q2;
obj->q2 = temp;
return result;
```

## 💡 深入理解

### 為什麼單隊列法更好？

```
考慮實際使用：

場景 1：頻繁 push，偶爾 pop
  單隊列：push O(n)，pop O(1)
  雙隊列：push O(1)，pop O(n)
  → 雙隊列更好

場景 2：頻繁 pop/top，偶爾 push
  單隊列：push O(n)，pop/top O(1)
  雙隊列：push O(1)，pop/top O(n)
  → 單隊列更好 ⭐

場景 3：push 和 pop 同樣頻繁
  單隊列：平均更好
  因為只需一個隊列

一般來說：
  棧的 pop/top 通常比 push 更頻繁
  所以單隊列法更優 ⭐
```

### 為什麼旋轉有效？

```
核心：
  隊列是 FIFO
  但通過旋轉可以改變順序

範例：
  初始：[1, 2]
  
  push(3) 後想要：[3, 2, 1]
  （3 在前面，先出）
  
  步驟：
    1. enqueue(3)：[1, 2, 3]
    2. dequeue(1), enqueue(1)：[2, 3, 1]
    3. dequeue(2), enqueue(2)：[3, 1, 2]
    
  錯誤！應該是 [3, 2, 1]
  
  我發現我寫錯了，讓我重新分析：
  
  正確過程：
    初始：[1, 2]（front → rear）
    
    push(3)：
      enqueue(3)：[1, 2, 3]
      旋轉前面 n=2 個：
        move(1)：[2, 3, 1]
        move(2)：[3, 1, 2]
      
      現在 front = 3
      pop 會返回 3 ✓
    
    但我們想要的棧是 [1, 2, 3]
    top 應該是 3
    
    所以 [3, 1, 2] 的 front 是 3 ✓
    
    pop() → 3，剩餘 [1, 2]
    top() → 1 ✓（之前的第二個元素）
```


```
關鍵：必須只用隊列操作

方法一：雙隊列
  push：O(1)
  pop：O(n)

方法二：單隊列（推薦）⭐

你的問題：

```

**關鍵記憶點**：
1. ✅ **必須用隊列**：enqueue/dequeue
2. ✅ **單隊列旋轉**：push 時旋轉 n 次
3. ✅ **雙隊列交換**：pop 時移動並交換
4. ✅ **旋轉次數**：n 次（n 是之前的元素數）
5. ✅ **內存管理**：釋放所有隊列節點

**你的代碼分析**：
```
評價：❌ 不符合題目要求

問題：
❌ 直接用鏈表實現棧
  - 沒有使用隊列
  - 雖然功能正確
  - 但不符合題目要求
  
❌ myStackFree 有內存洩漏
  - 只 free 了一個節點
  - 應該釋放所有節點

❌ rear 指針沒用
  - 創建了但從不使用

學習建議：
  1. 重新理解題目要求
  2. 必須用隊列操作
  3. 學習單隊列旋轉法
  4. 或雙隊列交換法
```

```c
// 使用單隊列法（最優）

typedef struct {
    Queue* q;  // 需要先實現隊列
} MyStack;

void myStackPush(MyStack* obj, int x) {
    int n = queueSize(obj->q);
    enqueue(obj->q, x);
    
    // 旋轉：把前面的 n 個移到後面
    for (int i = 0; i < n; i++) {
        enqueue(obj->q, dequeue(obj->q));
    }
}

int myStackPop(MyStack* obj) {
    return dequeue(obj->q);  // O(1)
}

int myStackTop(MyStack* obj) {
    return queueFront(obj->q);  // O(1)
}
```
