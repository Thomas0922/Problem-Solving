# LeetCode 35. Search Insert Position - 完整學習筆記

## 📋 題目描述

給定一個**排序陣列**和一個目標值，在陣列中找到目標值，並返回其索引。如果目標值不存在於陣列中，返回它將會被**按順序插入**的位置。

請必須使用時間複雜度為 `O(log n)` 的算法。

**範例**：
```
輸入：nums = [1, 3, 5, 6], target = 5
輸出：2

輸入：nums = [1, 3, 5, 6], target = 2
輸出：1

輸入：nums = [1, 3, 5, 6], target = 7
輸出：4

輸入：nums = [1, 3, 5, 6], target = 0
輸出：0
```

**限制**：
- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 為**無重複元素**的**升序**排列陣列
- `-10^4 <= target <= 10^4`

---

## 💡 解題思路

### 關鍵觀察

```
輸入特徵：
✅ 陣列已排序（升序）
✅ 需要查找/插入位置
✅ 要求 O(log n)

思路導向：
→ 已排序 + O(log n) = Binary Search（二分搜尋）！
```

### 插入位置的定義

```
插入位置 = 第一個 >= target 的元素位置

範例：nums = [1, 3, 5, 6]

target = 2: [1, ?, 3, 5, 6]
           第一個 >= 2 的是 3（索引 1）
           → 插入位置 = 1

target = 7: [1, 3, 5, 6, ?]
           沒有 >= 7 的元素
           → 插入位置 = 4（陣列末尾）

target = 5: [1, 3, 5, 6]
           第一個 >= 5 的是 5（索引 2）
           → 插入位置 = 2（找到了）
```

## 🔧 方法一：線性搜尋（直覺解法）

### 思路

遍歷整個陣列，統計有多少個元素小於 target，這個數量就是插入位置。

### 代碼實現

```c
int searchInsert(int* nums, int numsSize, int target) {
    int index = 0;  // 插入位置
    
    // 遍歷陣列
    for (int i = 0; i < numsSize; i++) {
        if (nums[i] < target) {
            index++;  // 小於 target 的元素數量
        }
    }
    
    return index;  // 返回插入位置
}
```

### 為什麼這個方法正確？

```
因為陣列已排序：
- 所有 < target 的元素都在左邊
- 所有 >= target 的元素都在右邊

例如：nums = [1, 3, 5, 6], target = 4
      [1, 3] < 4    → 2 個元素
      [5, 6] >= 4   → 插入位置 = 2
```

### 執行流程範例

```
nums = [1, 3, 5, 6], target = 5

初始：index = 0

i=0: nums[0]=1 < 5 → index++ → index=1
i=1: nums[1]=3 < 5 → index++ → index=2
i=2: nums[2]=5 >= 5 → 不變 → index=2
i=3: nums[3]=6 >= 5 → 不變 → index=2

返回：index = 2 ✓
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(n) | 需要遍歷整個陣列 |
| **空間複雜度** | O(1) | 只用一個變數 |

### 優缺點

**優點**：
- ✅ 代碼簡單直觀
- ✅ 容易理解
- ✅ 正確性高

**缺點**：
- ❌ 時間複雜度 O(n)，沒有利用「已排序」的特性
- ❌ 不符合題目要求的 O(log n)

## 🚀 方法二：二分搜尋（最優解）

### 核心概念

```
二分搜尋（Binary Search）：
- 每次將搜尋範圍縮小一半
- 時間複雜度：O(log n)
- 前提：陣列必須已排序

策略：
1. 設定左右邊界：left = 0, right = numsSize - 1
2. 計算中點：mid = left + (right - left) / 2
3. 比較 nums[mid] 和 target：
   - nums[mid] < target → 答案在右半邊 → left = mid + 1
   - nums[mid] >= target → 答案在左半邊 → right = mid - 1
4. 重複直到 left > right
5. 返回 left（插入位置）
```

### 代碼實現

```c
int searchInsert(int* nums, int numsSize, int target) {
    int left = 0;
    int right = numsSize - 1;
    
    while (left <= right) {
        // 計算中點（防止溢位）
        int mid = left + (right - left) / 2;
        
        if (nums[mid] == target) {
            // 找到目標，直接返回
            return mid;
        } else if (nums[mid] < target) {
            // 目標在右半邊
            left = mid + 1;
        } else {
            // 目標在左半邊
            right = mid - 1;
        }
    }
    
    // 沒找到，left 就是插入位置
    return left;
}
```

### 為什麼返回 `left`？

```
迴圈結束條件：left > right

此時：
- right：最後一個 < target 的位置
- left：第一個 >= target 的位置

插入位置定義：第一個 >= target 的位置
→ 所以返回 left ✓

圖解：
[... < target][... >= target]
            ↑             ↑
          right         left
```

### 詳細執行流程

#### 範例 1：找到目標

```
nums = [1, 3, 5, 6], target = 5

初始：left=0, right=3
[1, 3, 5, 6]
 ↑        ↑
 L        R

───────────────────────────────────────
迭代 1：
  mid = 0 + (3-0)/2 = 1
  nums[1] = 3 < 5
  → left = mid + 1 = 2
  
  [1, 3, 5, 6]
        ↑  ↑
        L  R

───────────────────────────────────────
迭代 2：
  mid = 2 + (3-2)/2 = 2
  nums[2] = 5 == 5
  → 找到了！返回 2 ✓
```

#### 範例 2：插入中間

```
nums = [1, 3, 5, 6], target = 2

初始：left=0, right=3
[1, 3, 5, 6]
 ↑        ↑
 L        R

───────────────────────────────────────
迭代 1：
  mid = 0 + (3-0)/2 = 1
  nums[1] = 3 > 2
  → right = mid - 1 = 0
  
  [1, 3, 5, 6]
   ↑
  L,R

───────────────────────────────────────
迭代 2：
  mid = 0 + (0-0)/2 = 0
  nums[0] = 1 < 2
  → left = mid + 1 = 1
  
  [1, 3, 5, 6]
   ↑ ↑
   R L

───────────────────────────────────────
結束：left > right
返回：left = 1 ✓
```

#### 範例 3：插入開頭

```
nums = [1, 3, 5, 6], target = 0

初始：left=0, right=3

迭代 1：
  mid = 1
  nums[1] = 3 > 0
  → right = 0

迭代 2：
  mid = 0
  nums[0] = 1 > 0
  → right = -1

結束：left=0, right=-1
返回：left = 0 ✓
```

#### 範例 4：插入結尾

```
nums = [1, 3, 5, 6], target = 7

初始：left=0, right=3

迭代 1：
  mid = 1
  nums[1] = 3 < 7
  → left = 2

迭代 2：
  mid = 2
  nums[2] = 5 < 7
  → left = 3

迭代 3：
  mid = 3
  nums[3] = 6 < 7
  → left = 4

結束：left=4, right=3
返回：left = 4 ✓
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(log n) | 每次縮小一半搜尋範圍 |
| **空間複雜度** | O(1) | 只用幾個變數 |

**時間複雜度詳細分析**：
```
n 個元素：
第 1 次：剩 n/2
第 2 次：剩 n/4
第 3 次：剩 n/8
...
第 k 次：剩 n/(2^k) = 1

2^k = n
k = log₂(n)

→ 時間複雜度 O(log n)
```

## 🔑 二分搜尋關鍵細節

### 1. 中點計算防溢位

```c
// ❌ 錯誤：可能溢位
int mid = (left + right) / 2;
// 當 left + right > INT_MAX 時會溢位

// ✅ 正確：防止溢位
int mid = left + (right - left) / 2;
```

**為什麼？**
```
假設：left = 2,000,000,000
      right = 2,000,000,000
      
錯誤寫法：
  left + right = 4,000,000,000 > INT_MAX (2,147,483,647)
  → 溢位！
  
正確寫法：
  right - left = 0
  left + 0/2 = 2,000,000,000
  → 安全！
```

### 2. 迴圈條件：`left <= right`

```c
while (left <= right) {  // ✅ 使用 <=
    // ...
}
```

**為什麼用 `<=` 而不是 `<`？**

```
考慮單一元素：nums = [5], target = 5

初始：left=0, right=0

如果用 while (left < right)：
  0 < 0 → false，迴圈不執行
  → 錯誤！

如果用 while (left <= right)：
  0 <= 0 → true，進入迴圈
  mid = 0, nums[0] = 5 = target
  → 正確！返回 0
```

### 3. 邊界更新

```c
if (nums[mid] < target) {
    left = mid + 1;   // ✅ mid + 1，不是 mid
} else {
    right = mid - 1;  // ✅ mid - 1，不是 mid
}
```

**為什麼要 ±1？**

```
如果不 ±1：
  nums = [1, 3], target = 1
  left=0, right=1
  
  mid = 0
  nums[0] = 1 = target
  → 應該返回 0
  
  但如果寫成：
    if (nums[mid] < target) {
        left = mid;  // ❌ 
    }
  
  當 mid=0, nums[0]=1 < 2（假設）
  left = 0（沒變！）
  → 無限迴圈！
```

### 4. 返回值：為什麼是 `left`？

```c
return left;  // ✅ 不是 right，不是 mid
```

**原因分析**：

```
迴圈結束時：left = right + 1

此時的狀態：
- nums[right] < target（或 right < 0）
- nums[left] >= target（或 left >= numsSize）

插入位置 = 第一個 >= target 的位置
→ 就是 left！

驗證：
nums = [1, 3, 5, 6], target = 4

最終：left=2, right=1
  nums[1] = 3 < 4 ✓
  nums[2] = 5 >= 4 ✓
  
插入位置 = 2 = left ✓
```

## 🎯 二分搜尋的變體

這題是二分搜尋的**查找插入位置**變體，還有其他常見變體：

### 變體 1：標準二分搜尋（查找元素）

```c
// 如果只是查找元素，不需要插入位置
int binarySearch(int* nums, int numsSize, int target) {
    int left = 0, right = numsSize - 1;
    
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) {
            return mid;  // 找到
        } else if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    
    return -1;  // 沒找到返回 -1
}
```

### 變體 2：查找第一個等於 target 的位置

```c
// 如果有重複元素，找第一個
int findFirst(int* nums, int numsSize, int target) {
    int left = 0, right = numsSize - 1;
    int result = -1;
    
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) {
            result = mid;    // 記錄位置
            right = mid - 1; // 繼續往左找
        } else if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    
    return result;
}
```

### 變體 3：查找最後一個等於 target 的位置

```c
// 如果有重複元素，找最後一個
int findLast(int* nums, int numsSize, int target) {
    int left = 0, right = numsSize - 1;
    int result = -1;
    
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) {
            result = mid;    // 記錄位置
            left = mid + 1;  // 繼續往右找
        } else if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    
    return result;
}
```

## 💡 學習技巧

### 1. 二分搜尋的記憶口訣

```
「左閉右閉，循環相等，中點安全，左右跨步」

左閉右閉：left=0, right=numsSize-1
循環相等：while (left <= right)
中點安全：mid = left + (right-left)/2
左右跨步：left=mid+1, right=mid-1
```

### 2. 視覺化理解

```
每次縮小一半：
[1, 2, 3, 4, 5, 6, 7, 8]  ← 8 個
       ↓
    [5, 6, 7, 8]          ← 4 個
       ↓
       [7, 8]             ← 2 個
       ↓
        [8]               ← 1 個
        
總共 3 次 = log₂(8)
```

### 3. Debug 技巧

```c

           left, mid, right, nums[mid]);
```

## 🏆 總結

**35. Search Insert Position 的核心**：

```
問題：在已排序陣列中查找插入位置
關鍵：已排序 → 二分搜尋
目標：O(log n) 時間複雜度

兩種解法：
1. 線性搜尋：O(n) - 簡單但慢
2. 二分搜尋：O(log n) - 最優解

二分搜尋要點：
- 中點計算防溢位
- 使用 left <= right
- 邊界更新 ±1
- 返回 left（插入位置）
```

**關鍵記憶點**：
1. 已排序 + 查找 = 二分搜尋
2. 插入位置 = 第一個 >= target 的位置
3. 返回 `left`（最後 left 指向插入位置）
4. 時間複雜度：O(log n) vs O(n)
5. 二分搜尋是重要的基礎算法

**學習建議**：
- 先理解線性搜尋（建立正確性認知）
- 再學習二分搜尋（理解優化思路）
- 多練習二分搜尋的變體
- 注意邊界條件和細節處理
