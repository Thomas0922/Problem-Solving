# LeetCode 2. Add Two Numbers - 完整學習筆記

## 📋 題目描述

給你兩個**非空**鏈表，表示兩個非負整數。它們的每位數字都是按照**逆序**的方式存儲的，並且每個節點只能存儲**一位**數字。

請你將兩個數相加，並以相同形式返回一個表示和的鏈表。

你可以假設除了數字 0 之外，這兩個數都不會以 0 開頭。

**範例**：
```
範例 1：
輸入：l1 = [2,4,3], l2 = [5,6,4]
輸出：[7,0,8]
解釋：342 + 465 = 807

  l1: 2 → 4 → 3  (表示 342)
  l2: 5 → 6 → 4  (表示 465)
  和: 7 → 0 → 8  (表示 807)

範例 2：
輸入：l1 = [0], l2 = [0]
輸出：[0]

範例 3：
輸入：l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
輸出：[8,9,9,9,0,0,0,1]
解釋：9999999 + 9999 = 10009998

  l1: 9→9→9→9→9→9→9  (表示 9999999)
  l2: 9→9→9→9        (表示 9999)
  和: 8→9→9→9→0→0→0→1 (表示 10009998)
```

**限制**：
- 每個鏈表中的節點數在範圍 `[1, 100]` 內
- `0 <= Node.val <= 9`
- 題目數據保證列表表示的數字不含前導零

**關鍵理解**：
```
⭐ 核心：數字已經是逆序存儲！

[2,4,3] 不是 243
[2,4,3] 是 342
      ↑ ↑ ↑
    個十百位

所以：不需要反轉鏈表！
     直接從頭相加就是從個位加起 ✓
```

## 💡 基礎知識：逆序存儲

### 什麼是逆序存儲？

```
正常表示：342
  百位：3
  十位：4
  個位：2

逆序存儲：2 → 4 → 3
  第一個節點：2（個位）
  第二個節點：4（十位）
  第三個節點：3（百位）

為什麼這樣設計？
  → 加法從個位開始算
  → 逆序存儲正好從頭開始加 ✓
```

### 加法的基本原理

```
手算加法：從右往左（個位→十位→百位）

  3 4 2
+ 4 6 5
-------
  8 0 7

步驟：
  個位：2 + 5 = 7
  十位：4 + 6 = 10 → 寫 0 進 1
  百位：3 + 4 + 1 = 8

鏈表加法：從左往右（因為已經逆序）

  2 → 4 → 3
+ 5 → 6 → 4
-----------
  7 → 0 → 8

步驟：
  第1位：2 + 5 = 7
  第2位：4 + 6 = 10 → 寫 0 進 1
  第3位：3 + 4 + 1 = 8

兩者邏輯完全相同！✓
```

## ✅ 正確解法

### 核心思路

```
三個關鍵點：

1. 不需要反轉
   鏈表已經逆序，直接從頭加

2. 同時遍歷
   兩個鏈表一起走，短的當 0

3. 處理進位
   carry = sum / 10
   digit = sum % 10
```

### 完整代碼實現

```c
struct ListNode* addTwoNumbers(struct ListNode* l1, struct ListNode* l2) {
    // 創建 dummy node
    struct ListNode dummy;
    dummy.next = NULL;
    struct ListNode* current = &dummy;
    
    int carry = 0;  // 進位初始化為 0
    
    // 只要有節點或有進位就繼續
    while (l1 != NULL || l2 != NULL || carry != 0) {
        // 獲取當前位的值（鏈表結束則為 0）
        int val1 = (l1 != NULL) ? l1->val : 0;
        int val2 = (l2 != NULL) ? l2->val : 0;
        
        // 計算當前位的和
        int sum = val1 + val2 + carry;
        
        // 計算新的進位和當前位數字
        carry = sum / 10;      // 進位：0 或 1
        int digit = sum % 10;  // 當前位：0-9
        
        // 創建新節點存儲當前位
        struct ListNode* newNode = (struct ListNode*)malloc(sizeof(struct ListNode));
        newNode->val = digit;
        newNode->next = NULL;
        
        // 連接到結果鏈表
        current->next = newNode;
        current = current->next;
        
        // 移動指針
        if (l1 != NULL) l1 = l1->next;
        if (l2 != NULL) l2 = l2->next;
    }
    
    return dummy.next;
}
```

### 代碼解析

```c
關鍵部分解釋：

1. Dummy Node：
   struct ListNode dummy;
   dummy.next = NULL;
   → 簡化頭節點處理

2. 循環條件：
   while (l1 || l2 || carry)
   → 三個條件，任一滿足就繼續
   → 確保最後的進位也被處理

3. 取值處理：
   val1 = (l1 != NULL) ? l1->val : 0;
   → 短鏈表當 0 處理

4. 進位計算：
   carry = sum / 10;   // 整數除法
   digit = sum % 10;   // 取餘數
   → 數學方法分離進位和數字

5. 創建節點：
   malloc + 設置 val + 連接
   → 構建結果鏈表
```

## 💡 進位處理深入理解

### 為什麼用除法和取餘？

```
數學原理：

任何兩位數可以表示為：
  num = 十位 × 10 + 個位

範例：18 = 1 × 10 + 8

所以：
  十位 = 18 / 10 = 1  （整數除法）
  個位 = 18 % 10 = 8  （取餘）

應用到加法：
  sum = 4 + 6 + 0 = 10
  carry = 10 / 10 = 1  （進位）
  digit = 10 % 10 = 0  （當前位）
```

### 所有可能的 sum 值

```
sum 的範圍：0 到 19

兩個數字：0-9
進位：0 或 1

最小：0 + 0 + 0 = 0
最大：9 + 9 + 1 = 19

對應的 carry 和 digit：

sum  | carry | digit
-----|-------|------
 0   |   0   |   0
 1   |   0   |   1
 2   |   0   |   2
...  |  ...  |  ...
 9   |   0   |   9
10   |   1   |   0  ⭐ 產生進位
11   |   1   |   1
...  |  ...  |  ...
18   |   1   |   8
19   |   1   |   9

結論：
  carry 永遠是 0 或 1
  digit 永遠是 0-9
```

### 進位的傳播

```
範例：999 + 1 = 1000

個位：
  9 + 1 + 0 = 10
  carry = 1, digit = 0
  結果：[0]

十位：
  9 + 0 + 1 = 10
  carry = 1, digit = 0
  結果：[0,0]

百位：
  9 + 0 + 1 = 10
  carry = 1, digit = 0
  結果：[0,0,0]

千位（最後的進位）：
  0 + 0 + 1 = 1
  carry = 0, digit = 1
  結果：[0,0,0,1] ✓

進位一直傳播到最高位！
```

  [2,4,3] 不是 243

1. 取值：val1 = l1 ? l1->val : 0
2. 相加：sum = val1 + val2 + carry
3. 分離：carry = sum/10, digit = sum%10

3. ✅ **短的補零**：`val = l ? l->val : 0`
4. ✅ **進位計算**：`carry = sum / 10`
5. ✅ **當前位**：`digit = sum % 10`
6. ✅ **最後進位**：循環條件加 `carry != 0`
