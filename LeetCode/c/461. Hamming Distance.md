# LeetCode 461. Hamming Distance - 完整學習筆記

## 📋 題目描述

兩個整數之間的 **Hamming Distance（漢明距離）** 指的是這兩個數字對應二進位位不同的位置的數目。

給你兩個整數 `x` 和 `y`，計算並返回它們之間的漢明距離。

**範例**：
```
輸入：x = 1, y = 4
輸出：2
解釋：
1   (0 0 0 1)
4   (0 1 0 0)
       ↑   ↑
有 2 位不同

輸入：x = 3, y = 1
輸出：1
解釋：
3   (0 0 1 1)
1   (0 0 0 1)
         ↑
有 1 位不同
```

**限制**：
- `0 <= x, y <= 2^31 - 1`

---

## 💡 核心觀察

### 什麼是 Hamming Distance？

```
Hamming Distance = 二進位表示中不同位的個數

範例：
x = 1 (0001)
y = 4 (0100)

逐位比較：
位置 3: 0 ≠ 0 → 相同
位置 2: 0 ≠ 1 → 不同 ✓
位置 1: 0 ≠ 0 → 相同
位置 0: 1 ≠ 0 → 不同 ✓

不同的位數 = 2
```

### 關鍵發現

```
1. XOR 可以找出不同的位
   - 相同位 → 0
   - 不同位 → 1

2. 統計 XOR 結果中 '1' 的個數
   - 就是 Hamming Distance

這題 = XOR + 統計 '1' 個數
     = 136/268 題 + 191 題
```

## 🔧 方法一：XOR + 逐位檢查（你的方法）

### 思路

```
步驟 1：用 XOR 找出不同的位
  xor_result = x ^ y

步驟 2：統計 xor_result 中 '1' 的個數
  方法：逐位檢查
```

### 程式碼實現

```c
int hammingDistance(int x, int y) {
    int xor_result = x ^ y;  // 找出不同的位
    int count = 0;
    
    // 統計 '1' 的個數（191 題的方法一）
    while (xor_result) {
        if (xor_result & 1) {  // 檢查最低位
            count++;
        }
        xor_result >>= 1;  // 右移一位
    }
    
    return count;
}
```

**你的寫法**（也完全正確）：
```c
int hammingDistance(int x, int y) {
    int ans = 0, count = 0;
    ans = x ^ y;
    while(ans){
        if(ans & 1){
            count++;
        }
        ans >>= 1;
    } 
    return count;
}
```

### 執行流程

#### 範例：x = 1, y = 4

```
x = 1 (0001)
y = 4 (0100)

步驟 1：XOR 找不同位
  xor_result = 1 ^ 4
             = 0001 ^ 0100
             = 0101
             = 5

步驟 2：統計 '1' 個數
  初始：xor_result = 5 (0101), count = 0
  
  迭代 1：
    0101 & 1 = 1 → count = 1
    0101 >> 1 = 0010
  
  迭代 2：
    0010 & 1 = 0 → count = 1
    0010 >> 1 = 0001
  
  迭代 3：
    0001 & 1 = 1 → count = 2
    0001 >> 1 = 0000
  
  結束：count = 2 ✓
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(1) 或 O(log n) | 最多循環 32 次（32 位） |
| **空間複雜度** | O(1) | 只用常數空間 |

### 優缺點

**優點**：
- ✅ 邏輯清晰
- ✅ 結合了兩個學過的技巧
- ✅ 正確性高

**缺點**：
- ⚠️ 總是循環 32 次（即使只有 1 個 '1'）

## 🚀 方法二：XOR + Brian Kernighan（最優解）

### 核心技巧

**還記得 191 題學的 `n & (n-1)` 嗎？**

```
n & (n - 1) 的效果：消除 n 最右邊的一個 '1'

優勢：
- 只循環 '1' 的個數次
- 不是固定 32 次
```

### 程式碼實現

```c
int hammingDistance(int x, int y) {
    int xor_result = x ^ y;  // 找出不同的位
    int count = 0;
    
    // Brian Kernighan 算法（191 題的方法三）
    while (xor_result) {
        xor_result = xor_result & (xor_result - 1);  // 消除一個 '1'
        count++;
    }
    
    return count;
}
```

**更簡潔的寫法**：
```c
int hammingDistance(int x, int y) {
    int xor_result = x ^ y;
    int count = 0;
    
    while (xor_result) {
        xor_result &= xor_result - 1;
        count++;
    }
    
    return count;
}
```

### 執行流程

#### 範例：x = 1, y = 4

```
xor_result = 1 ^ 4 = 5 (0101)

迭代 1：
  xor_result & (xor_result - 1)
  = 0101 & 0100
  = 0100
  count = 1

迭代 2：
  xor_result & (xor_result - 1)
  = 0100 & 0011
  = 0000
  count = 2

結束：count = 2 ✓
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(k) | k = 不同位的個數 ⭐ |
| **空間複雜度** | O(1) | 只用常數空間 |

### 優勢

**相比方法一**：
- ✅ 只循環不同位的個數次（不是固定 32 次）
- ✅ 效率更高
- ✅ 使用 191 題學過的技巧 ⭐

## 💡 視覺化理解

### XOR 如何找出不同位

```
x = 5 (0101)
y = 3 (0011)

逐位比較：
位置 3: 0 vs 0 → 相同 → 0
位置 2: 1 vs 0 → 不同 → 1 ✓
位置 1: 0 vs 1 → 不同 → 1 ✓
位置 0: 1 vs 1 → 相同 → 0

XOR 結果：
  0101
^ 0011
──────
  0110  ← 有 2 個 '1' → Hamming Distance = 2
```

### 為什麼 XOR 有效？

```
XOR 真值表：
a  b | a^b
─────┼────
0  0 | 0   ← 相同 → 0
0  1 | 1   ← 不同 → 1
1  0 | 1   ← 不同 → 1
1  1 | 0   ← 相同 → 0

結論：XOR 天生就是用來找「不同」的！
```

## ⚠️ 常見錯誤

### 錯誤 1：忘記 XOR

```c
// ❌ 錯誤：直接統計
int hammingDistance(int x, int y) {
    int count = 0;
    while (x || y) {
        count += (x & 1) != (y & 1);
        x >>= 1;
        y >>= 1;
    }
    return count;
}

// 雖然也能做，但複雜且低效

// ✅ 正確：先 XOR
int hammingDistance(int x, int y) {
    int xor = x ^ y;
    // 然後統計
}
```

### 錯誤 2：誤解 Hamming Distance

```c
// ❌ 錯誤理解：以為是數值差
return abs(x - y);  // 不對！

// ✅ 正確理解：是二進位不同位的個數
return hammingWeight(x ^ y);
```

### 錯誤 3：沒有優化統計方法

```c
// ⚠️ 可以但不是最優
while (xor) {
    count += xor & 1;
    xor >>= 1;
}

// ✅ 更優：使用 Brian Kernighan
while (xor) {
    xor &= xor - 1;
    count++;
}

### 進階思考

#### 1. Total Hamming Distance（477 題）

```
問題：計算陣列中所有數對的 Hamming Distance 總和

暴力：O(n² * 32)
優化：O(n * 32)

思路：
- 對每一位分別統計
- 有 k 個 1，則有 (n-k) 個 0
- 這一位貢獻的距離 = k * (n-k)
```

#### 2. 檢查是否只有一位不同

```c
bool isOneAway(int x, int y) {
    int xor = x ^ y;
    // 檢查 xor 是否是 2 的冪（只有一個 '1'）
    return xor > 0 && (xor & (xor - 1)) == 0;
}
```

#### 3. 找出不同位的位置

```c
void findDifferentBits(int x, int y) {
    int xor = x ^ y;
    int pos = 0;
    
    while (xor) {
        if (xor & 1) {
            printf("位置 %d 不同\n", pos);
        }
        xor >>= 1;
        pos++;
    }
}
```
