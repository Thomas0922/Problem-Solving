# LeetCode 203. Remove Linked List Elements - 完整學習筆記

## 📋 題目描述

給定一個鏈表的頭節點 `head` 和一個整數 `val`，刪除鏈表中所有滿足 `Node.val == val` 的節點，並返回**新的頭節點**。

**範例**：
```
範例 1：
輸入：head = [1,2,6,3,4,5,6], val = 6
輸出：[1,2,3,4,5]

  原：1 → 2 → 6 → 3 → 4 → 5 → 6
  刪除 6：1 → 2 → 3 → 4 → 5

範例 2：
輸入：head = [], val = 1
輸出：[]

範例 3：
輸入：head = [7,7,7,7], val = 7
輸出：[]
```

**限制**：
- 鏈表中節點數目在範圍 `[0, 10^4]` 內
- `1 <= Node.val <= 50`
- `0 <= val <= 50`

**關鍵理解**：
```
與 83 題的區別：

83 題（刪除重複）：
  - 頭節點永遠不會被刪除
  - 不需要 Dummy Node

203 題（刪除特定值）：
  - 頭節點可能被刪除 ⭐
  - 需要 Dummy Node
  
例如：
  head = [6,1,2,6], val = 6
  頭節點就是 6，需要刪除！
```

## 💡 基礎知識：Dummy Node

### 什麼是 Dummy Node？

```
Dummy Node（虛擬頭節點）：
  一個不存儲實際數據的虛擬節點
  指向真正的頭節點

作用：
  統一處理頭節點和其他節點
  避免特殊情況判斷

圖示：
  Dummy → 1 → 2 → 3
  ↑       ↑
  虛擬   真正的頭
```

### 為什麼需要 Dummy Node？

```
問題：頭節點可能被刪除

沒有 Dummy Node：
  if (head->val == val) {
      head = head->next;  // 特殊處理頭節點
  }
  // 然後處理其他節點...

有 Dummy Node：
  Dummy → head
  
  統一處理所有節點：
  if (curr->next->val == val) {
      curr->next = curr->next->next;
  }
  
  無需特殊判斷！✓
```

## 🌟 方法一：Dummy Node（你的解法 - 最優解）

### 核心思想

```
1. 創建 Dummy Node 指向 head
2. 用指針遍歷，檢查 next 節點
3. 如果 next->val == val，跳過該節點
4. 否則移動指針
5. 返回 Dummy.next（真正的頭）
```

### 代碼實現（你的解法）

```c
struct ListNode* removeElements(struct ListNode* head, int val) {
    // 創建 Dummy Node
    struct ListNode Dummy;
    Dummy.next = NULL;
    struct ListNode* cun = &Dummy;
    cun->next = head;
    
    // 遍歷鏈表
    while (cun && cun->next) {
        if (cun->next->val == val) {
            // 找到要刪除的節點
            struct ListNode* temp = cun->next;
            cun->next = cun->next->next;
            free(temp);  // 釋放內存 ⭐
            // cun 不動，因為新的 next 可能還是 val
        } else {
            // 不需要刪除，移動指針
            cun = cun->next;
        }
    }
    
    return Dummy.next;  // 返回真正的頭節點
}
```

## 🔧 方法二：不使用 Dummy Node

### 思路

先特殊處理頭節點，再處理其他節點。

### 代碼實現

```c
struct ListNode* removeElements(struct ListNode* head, int val) {
    // 特殊處理：刪除頭節點
    while (head && head->val == val) {
        struct ListNode* temp = head;
        head = head->next;
        free(temp);
    }
    
    if (!head) return NULL;
    
    // 處理其他節點
    struct ListNode* curr = head;
    while (curr && curr->next) {
        if (curr->next->val == val) {
            struct ListNode* temp = curr->next;
            curr->next = curr->next->next;
            free(temp);
        } else {
            curr = curr->next;
        }
    }
    
    return head;
}
```

### 執行流程

```
範例：head = [6,6,1,2,6], val = 6

步驟 1：刪除頭節點
  while (head && head->val == 6) {
      刪除第一個 6
      刪除第二個 6
  }
  
  現在：head = 1 → 2 → 6

步驟 2：處理其他節點
  刪除最後的 6
  
  結果：1 → 2
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(n) | 遍歷一次 |
| **空間複雜度** | O(1) | 只用常數指針 |

### 缺點

```
需要兩個步驟：
1. 特殊處理頭節點
2. 處理其他節點

代碼更複雜，不如 Dummy Node 優雅
```

## 💡 Dummy Node 技巧深入理解

### 何時使用 Dummy Node？

```
需要 Dummy Node 的情況：
✓ 頭節點可能被刪除（203 題）
✓ 頭節點可能改變（合併鏈表）
✓ 需要統一處理所有節點

不需要 Dummy Node 的情況：
✗ 頭節點不會改變（83 題）
✗ 只是查詢、遍歷
✗ 頭節點有特殊意義
```

### Dummy Node 的創建方式

```c
// 方式 1：棧上分配（你的做法）⭐
struct ListNode Dummy;
Dummy.next = head;
struct ListNode* curr = &Dummy;
// ...
return Dummy.next;

優點：
- 不需要 malloc
- 不需要 free
- 更快

// 方式 2：堆上分配
struct ListNode* Dummy = malloc(sizeof(struct ListNode));
Dummy->next = head;
// ...
struct ListNode* result = Dummy->next;
free(Dummy);
return result;

缺點：
- 需要 malloc 和 free
- 稍慢

推薦：方式 1（你的做法）✓
```

### 為什麼 cun 不動？

```
與 83 題類似的技巧：

刪除時 cun 不動的原因：
  連續的目標值可能存在

例如：head = [6,6,1,2], val = 6

如果刪除後移動：
  迭代 1：刪除第一個 6，移動到第二個 6
  迭代 2：6 == 6，刪除，但已經是第二個了
  可能漏刪

如果刪除時不動：
  迭代 1：刪除第一個 6，停在 Dummy
  迭代 2：再次檢查，發現第二個 6，刪除
  迭代 3：1 != 6，移動
  
完美處理連續值 ✓
```

### 21. Merge Two Sorted Lists

// 21 題：合併兩個鏈表（也用 Dummy Node）
struct ListNode* mergeTwoLists(struct ListNode* l1, struct ListNode* l2) {
    struct ListNode dummy;
    struct ListNode* tail = &dummy;
    dummy.next = NULL;
    
    while (l1 && l2) {
        if (l1->val <= l2->val) {
            tail->next = l1;
            l1 = l1->next;
        } else {
            tail->next = l2;
            l2 = l2->next;
        }
        tail = tail->next;

}

struct ListNode* deleteDuplicates(struct ListNode* head) {

#### 問題 1：如何刪除多個不同的值？

```c
// 例如：刪除所有 6 和 7
struct ListNode* removeMultipleValues(struct ListNode* head, int* vals, int n) {
    struct ListNode Dummy;
    Dummy.next = head;
    struct ListNode* curr = &Dummy;
    
    while (curr && curr->next) {
        bool shouldDelete = false;
        
        // 檢查是否在刪除列表中
        for (int i = 0; i < n; i++) {
            if (curr->next->val == vals[i]) {
                shouldDelete = true;
                break;
            }
        }
        
        if (shouldDelete) {
            struct ListNode* temp = curr->next;
            curr->next = curr->next->next;
            free(temp);
        } else {
            curr = curr->next;
        }
    }
    
    return Dummy.next;
}
```

struct ListNode* removeElements(struct ListNode* head, int val) {
    if (!head) return NULL;
    
    // 遞歸處理後續節點
    head->next = removeElements(head->next, val);
    
    // 如果當前節點是目標值
    if (head->val == val) {
        struct ListNode* temp = head;
        head = head->next;
        free(temp);
    }
    
    return head;
}

// 時間：O(n)
// 空間：O(n)（遞歸棧）
