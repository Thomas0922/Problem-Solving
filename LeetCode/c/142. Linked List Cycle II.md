# LeetCode 142. Linked List Cycle II - 完整學習筆記

## 📋 題目描述

給定一個鏈表的頭節點 `head`，返回鏈表開始入環的**第一個節點**。如果鏈表無環，則返回 `null`。

如果鏈表中有某個節點，可以通過連續跟蹤 `next` 指針再次到達，則鏈表中存在環。為了表示給定鏈表中的環，評測系統內部使用整數 `pos` 來表示鏈表尾連接到鏈表中的位置（索引從 0 開始）。如果 `pos` 是 `-1`，則在該鏈表中沒有環。**注意：`pos` 不作為參數進行傳遞**，僅僅是為了標識鏈表的實際情況。

**不允許修改**鏈表。

**範例**：
```
範例 1：
輸入：head = [3,2,0,-4], pos = 1
輸出：返回索引為 1 的鏈表節點
解釋：鏈表中有一個環，其尾部連接到第二個節點

  3 → 2 → 0 → -4
      ↑_________|
      環的入口

範例 2：
輸入：head = [1,2], pos = 0
輸出：返回索引為 0 的鏈表節點
解釋：鏈表中有一個環，其尾部連接到第一個節點

  1 → 2
  ↑___|
  環的入口

範例 3：
輸入：head = [1], pos = -1
輸出：返回 null
解釋：鏈表中沒有環
```

**限制**：
- 鏈表中節點的數目範圍在範圍 `[0, 10^4]` 內
- `-10^5 <= Node.val <= 10^5`
- `pos` 的值為 `-1` 或者鏈表中的一個有效索引

**進階要求**：
你能用 **O(1)** 空間解決此題嗎？

## 🌟 Floyd's Cycle Detection（你的解法 - 最優解）

### 核心思想

```
兩個階段：

階段 1：檢測環（141 題）
  - 快慢指針找到相遇點

階段 2：找環的入口
  - 將 slow 重置到 head
  - slow 和 fast 都每次走 1 步
  - 再次相遇的點就是環的入口
```

### 🔢 數學證明（核心！）

```
設定變數：
  a = 起點到環入口的距離
  b = 環入口到第一次相遇點的距離
  c = 第一次相遇點到環入口的距離
  L = 環的長度 = b + c

圖示：
  起點 ─────a───── 環入口 ───b─── 相遇點
                    ↑               |
                    └──────c────────┘

第一次相遇時：
  slow 走了：a + b
  fast 走了：a + b + n×L（n 是 fast 多走的圈數）
  
因為 fast 速度是 slow 的兩倍：
  2(a + b) = a + b + n×L
  2a + 2b = a + b + n×L
  a + b = n×L
  a = n×L - b
  
因為 L = b + c：
  a = n×L - b
  a = n×(b + c) - b
  a = n×b + n×c - b
  a = (n-1)×b + b + n×c - b
  a = (n-1)×b + n×c
  a = (n-1)×(b + c) + c
  a = (n-1)×L + c

結論：
  從起點走到環入口的距離 a
  = 從相遇點走到環入口的距離 c（加上若干圈）

所以：
  slow 從 head 出發
  fast 從相遇點出發
  兩者都每次走 1 步
  會在環入口相遇！✓
```

### 代碼實現（你的解法）

```c
struct ListNode *detectCycle(struct ListNode *head) {
    struct ListNode* fast = head;
    struct ListNode* slow = head;
    
    // 階段 1：檢測環並找到相遇點
    while (fast && fast->next) {
        slow = slow->next;        // 走 1 步
        fast = fast->next->next;  // 走 2 步
        
        if (slow == fast) {
            // 找到相遇點，進入階段 2
            
            // 階段 2：找環的入口
            slow = head;  // 重置 slow 到起點
            
            while (slow != fast) {
                slow = slow->next;  // 走 1 步
                fast = fast->next;  // 也走 1 步
            }
            
            return slow;  // 環的入口
        }
    }
    
    return NULL;  // 無環
}
```

### 執行流程

```
範例：head = [3,2,0,-4], pos = 1

  3 → 2 → 0 → -4
      ↑_________|

═══════════════════════════════════════
階段 1：檢測環

初始：slow = 3, fast = 3

迭代 1：slow = 2, fast = 0
迭代 2：slow = 0, fast = 2
迭代 3：slow = -4, fast = -4 ✓ 相遇！

═══════════════════════════════════════
階段 2：找環入口

重置：slow = 3（head）, fast = -4（相遇點）

迭代 1：
  slow = 2
  fast = 2
  相遇！✓

return 2（環的入口）
```

## ⚠️ 常見錯誤

### 錯誤 1：忘記重置 slow

```c
// ❌ 錯誤
if (slow == fast) {
    // 忘記：slow = head;
    while (slow != fast) {
        slow = slow->next;
        fast = fast->next;
    }
}

// ✓ 正確（你的做法）
if (slow == fast) {
    slow = head;  // 必須重置！
    while (slow != fast) {
        slow = slow->next;
        fast = fast->next;
    }
}
```

### 錯誤 2：階段 2 fast 走 2 步

```c
// ❌ 錯誤
slow = head;
while (slow != fast) {
    slow = slow->next;
    fast = fast->next->next;  // 錯！
}

// ✓ 正確（你的做法）
slow = head;
while (slow != fast) {
    slow = slow->next;
    fast = fast->next;  // 都走 1 步
}
```

## 🏆 總結

**142. Linked List Cycle II 的核心**：

```
問題：找環的入口節點
關鍵：Floyd's Algorithm + 數學證明

你的解法（最優）：
// 階段 1：檢測環
while (fast && fast->next) {
    slow = slow->next;
    fast = fast->next->next;
    
    if (slow == fast) {
        // 階段 2：找入口
        slow = head;  // 重置
        
        while (slow != fast) {
            slow = slow->next;
            fast = fast->next;  // 都走 1 步
        }
        
        return slow;  // 入口
    }
}
return NULL;

時間：O(n)，空間：O(1) ✓
```
