# LeetCode 69. Sqrt(x) - 完整學習筆記

## 📋 題目描述

給你一個非負整數 `x`，計算並返回 `x` 的**算術平方根**。

由於返回類型是整數，結果只保留**整數部分**，小數部分將被**捨去**。

**注意**：不允許使用任何內置指數函數和算符，例如 `pow(x, 0.5)` 或者 `x ** 0.5`。

**範例**：
```
範例 1：
輸入：x = 4
輸出：2
解釋：4 的平方根是 2

範例 2：
輸入：x = 8
輸出：2
解釋：8 的平方根是 2.82842...，向下取整為 2
```

**限制**：
- `0 <= x <= 2³¹ - 1`

**關鍵理解**：
```
問題：找最大的整數 k，使得 k² ≤ x

範例：x = 8
  1² = 1 ≤ 8 ✓
  2² = 4 ≤ 8 ✓
  3² = 9 > 8 ✗
  
  答案：2

範例：x = 15
  3² = 9 ≤ 15 ✓
  4² = 16 > 15 ✗
  
  答案：3

本質：
  找最大的 k，滿足 k² ≤ x
  → 搜索問題 ⭐
```

## 💡 基礎知識：平方根

### 什麼是平方根？

```
定義：
  如果 k² = x，則 k 是 x 的平方根
  
  記作：k = √x

範例：
  √4 = 2（因為 2² = 4）
  √9 = 3（因為 3² = 9）
  √16 = 4（因為 4² = 16）

非完全平方數：
  √8 = 2.828...
  題目要求：向下取整 → 2
  
  √15 = 3.872...
  題目要求：向下取整 → 3
```

### 搜索範圍

```
問題：√x 的範圍是多少？

觀察：
  如果 k > x/2（且 x > 1）
  那麼 k² > x
  
證明：
  當 k > x/2 時
  k² > (x/2)² = x²/4
  
  當 x > 1 時，x²/4 > x
  所以 k² > x

結論：
  √x 一定在 [0, x/2] 範圍內（當 x > 1）
  
特殊情況：
  x = 0：√0 = 0
  x = 1：√1 = 1
  
搜索範圍：
  x = 0：[0, 0]
  x = 1：[0, 1]
  x > 1：[0, x/2] ⭐
```

## ✅ 你的解法：暴力遍歷

### 你的代碼

```c
int mySqrt(int x) {
    long max = 0;
    if(x == 1) return 1;
    
    for(long i = 1; i <= x; i++){
        max = i * i >= max ? i * i : max;
        if(max > x){
            return i - 1;
        }
    }
    return 0;
}
```

### 代碼分析

```c
思路：
  從 1 開始遍歷
  計算 i * i
  找到第一個 i * i > x 的 i
  返回 i - 1

執行過程（x = 8）：
  i = 1：1² = 1 ≤ 8，繼續
  i = 2：2² = 4 ≤ 8，繼續
  i = 3：3² = 9 > 8，返回 3-1 = 2 ✓

時間複雜度：O(√x)
空間複雜度：O(1)
```

## 🌟 方法二：二分查找（最優）⭐

### 核心思想

```
觀察：
  平方根具有單調性
  
  k² ≤ x 的 k：0, 1, 2, ..., ans
  k² > x 的 k：ans+1, ans+2, ...
  
  0  1  2  ... ans  ans+1 ...
  ✓  ✓  ✓  ... ✓    ✗    ✗

典型的二分查找問題！⭐

目標：
  找最大的 k，使得 k² ≤ x
  
  → 找最右邊的滿足條件的位置
```

### 完整代碼（二分查找）⭐

```c
int mySqrt(int x) {
    if(x == 0) return 0;
    
    long left = 1;
    long right = x;
    long ans = 0;
    
    while(left <= right){
        long mid = left + (right - left) / 2;
        long square = mid * mid;
        
        if(square <= x){
            ans = mid;           // 記錄答案
            left = mid + 1;      // 繼續找更大的
        }else{
            right = mid - 1;     // mid 太大了
        }
    }
    
    return ans;
}
```

### 執行流程

```
範例：x = 8

═══════════════════════════════════════
初始：
  left = 1, right = 8
  ans = 0

═══════════════════════════════════════
迭代 1：

  mid = (1 + 8) / 2 = 4
  square = 4² = 16
  
  16 > 8 ✗
  right = mid - 1 = 3
  
  狀態：left = 1, right = 3

═══════════════════════════════════════
迭代 2：

  mid = (1 + 3) / 2 = 2
  square = 2² = 4
  
  4 ≤ 8 ✓
  ans = 2
  left = mid + 1 = 3
  
  狀態：left = 3, right = 3

═══════════════════════════════════════
迭代 3：

  mid = (3 + 3) / 2 = 3
  square = 3² = 9
  
  9 > 8 ✗
  right = mid - 1 = 2
  
  狀態：left = 3, right = 2

═══════════════════════════════════════
結束：left > right

  返回 ans = 2 ✓
```

### 優化版本（縮小搜索範圍）

```c
int mySqrt(int x) {
    if(x < 2) return x;  // 0 和 1
    
    long left = 1;
    long right = x / 2;  // ⭐ 優化：最多到 x/2
    long ans = 0;
    
    while(left <= right){
        long mid = left + (right - left) / 2;
        long square = mid * mid;
        
        if(square <= x){
            ans = mid;
            left = mid + 1;
        }else{
            right = mid - 1;
        }
    }
    
    return ans;
}

// 時間：O(log x)
// 空間：O(1)
```

## 🚀 方法三：牛頓迭代法（最快）⭐⭐⭐

### 核心思想

```
牛頓法：
  求 f(k) = k² - x = 0 的解
  
  迭代公式：
    k_{n+1} = k_n - f(k_n) / f'(k_n)
           = k_n - (k_n² - x) / (2k_n)
           = (k_n + x/k_n) / 2

幾何意義：
  每次用切線逼近根
  收斂速度非常快 ⭐
```

### 完整代碼（牛頓法）

```c
int mySqrt(int x) {
    if(x < 2) return x;
    
    long k = x;
    
    while(k * k > x){
        k = (k + x / k) / 2;  // 牛頓迭代公式
    }
    
    return k;
}

// 時間：O(log log x) ⭐ 收斂極快
// 空間：O(1)
```

### 執行流程

```
範例：x = 8

初始：k = 8

迭代 1：
  k = (8 + 8/8) / 2
    = (8 + 1) / 2
    = 4
  4² = 16 > 8，繼續

迭代 2：
  k = (4 + 8/4) / 2
    = (4 + 2) / 2
    = 3
  3² = 9 > 8，繼續

迭代 3：
  k = (3 + 8/3) / 2
    = (3 + 2) / 2  // 整數除法
    = 2
  2² = 4 ≤ 8，停止

返回：2 ✓

只需要 3 次迭代！⭐
```

## ⚠️ 常見錯誤

### 錯誤 1：溢出問題

```c
// ❌ 錯誤：使用 int
int mySqrt(int x) {
    for(int i = 1; i <= x; i++){
        if(i * i > x){  // i*i 可能溢出！
            return i - 1;
        }
    }
}

// 問題：
// 當 i 很大時，i*i 可能超過 INT_MAX
// 導致溢出變成負數

// ✓ 正確：使用 long
for(long i = 1; i <= x; i++){
    if(i * i > x){  // 安全
        return i - 1;
    }
}
```

### 錯誤 2：二分查找邊界錯誤

```c
// ❌ 錯誤：mid 計算溢出
long mid = (left + right) / 2;  // left+right 可能溢出

// ✓ 正確
long mid = left + (right - left) / 2;
```

### 錯誤 3：沒有記錄答案

```c
// ❌ 錯誤
while(left <= right){
    long mid = left + (right - left) / 2;
    if(mid * mid <= x){
        left = mid + 1;  // 沒記錄 mid
    }else{
        right = mid - 1;
    }
}
return right;  // 可能不對

// ✓ 正確
long ans = 0;
while(left <= right){
    long mid = left + (right - left) / 2;
    if(mid * mid <= x){
        ans = mid;  // 記錄答案 ⭐
        left = mid + 1;
    }else{
        right = mid - 1;
    }
}
return ans;
```

## 💡 深入理解

### 為什麼二分查找可以？

```
關鍵：單調性

定義函數 f(k) = k²

觀察：
  k 越大，k² 越大（單調遞增）
  
  0² = 0
  1² = 1
  2² = 4
  3² = 9
  4² = 16
  ...
  
問題：找最大的 k，使得 k² ≤ x

等價於：
  在單調遞增的序列中
  找最右邊滿足條件的元素
  
  → 二分查找的經典應用 ⭐
```

### 牛頓法為什麼快？

```
牛頓法收斂速度：

每次迭代後
誤差大約變為原來的平方

範例：
  初始誤差：e₀
  迭代 1 後：e₁ ≈ e₀²
  迭代 2 後：e₂ ≈ e₁² ≈ e₀⁴
  迭代 3 後：e₃ ≈ e₂² ≈ e₀⁸
  
誤差指數級減小 ⭐

vs 二分查找：
  每次迭代後
  誤差變為原來的 1/2
  
  線性減小

結論：
  牛頓法收斂更快 ⭐
  但需要良好的初始值
```
