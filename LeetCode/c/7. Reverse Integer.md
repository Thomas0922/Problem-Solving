# LeetCode 7. Reverse Integer - 完整學習筆記

## 📋 題目描述

給定一個 32 位有符號整數 `x`，返回將 `x` 中的數字部分反轉後的結果。

如果反轉後整數超過 32 位的有符號整數的範圍 `[−2^31, 2^31 − 1]`，就返回 `0`。

**假設環境不允許存儲 64 位整數（有符號或無符號）。**

**範例**：
```
輸入：x = 123
輸出：321

輸入：x = -123
輸出：-321

輸入：x = 120
輸出：21
解釋：反轉後是 021，前導零會被去掉

輸入：x = 0
輸出：0
```

**限制**：
- `-2^31 <= x <= 2^31 - 1`

**關鍵理解**：
```
123 → 321
  取最後一位：3
  取倒數第二位：2
  取倒數第三位：1
  結果：3×100 + 2×10 + 1 = 321

重要：
  INT_MAX = 2147483647（2^31 - 1）
  INT_MIN = -2147483648（-2^31）
  
  反轉後可能溢出！
  例如：1534236469 反轉後 9646324351 > INT_MAX
```

## 💡 基礎知識：整數反轉與溢出

### 整數反轉的方法

```c
// 方法 1：逐位提取
int x = 123;
int digit1 = x % 10;  // 3
x = x / 10;           // 12
int digit2 = x % 10;  // 2
x = x / 10;           // 1
int digit3 = x % 10;  // 1

結果：3×100 + 2×10 + 1 = 321

// 方法 2：累加構建
int result = 0;
result = result * 10 + 3;  // 3
result = result * 10 + 2;  // 32
result = result * 10 + 1;  // 321
```

### 溢出的概念

```
32 位有符號整數範圍：
  INT_MAX =  2147483647 (2^31 - 1)
  INT_MIN = -2147483648 (-2^31)

溢出示例：
  x = 1534236469
  反轉：9646324351 > 2147483647 ✗ 溢出！
  
  x = -1534236469
  反轉：-9646324351 < -2147483648 ✗ 溢出！
```

### 為什麼不能用 64 位？

```
題目假設：環境不允許存儲 64 位整數

如果可以用 64 位：
  long long result = 0;
  result = result * 10 + digit;
  if (result > INT_MAX || result < INT_MIN) return 0;
  
但題目要求只用 32 位，所以必須：
  - 在乘以 10 之前檢查溢出
  - 不能讓中間結果溢出
```

## 🌟 方法：數學反轉 + 溢出檢查（你的解法 - 最優解）

### 核心思想

```
1. 逐位提取數字（從右往左）
2. 累加構建結果（從左往右）
3. 在每次乘以 10 之前檢查是否會溢出
```

### 溢出檢查的關鍵

```c
// 問題：如何在不溢出的情況下檢查溢出？

// ❌ 錯誤：先計算再檢查
result = result * 10 + digit;
if (result > INT_MAX) return 0;  // 太遲了！result 已經溢出

// ✓ 正確：先檢查再計算（你的做法）
if (result > INT_MAX/10) return 0;  // 提前檢查
result = result * 10 + digit;
```

### 溢出條件推導

```
什麼時候會溢出？

正數溢出：
  result * 10 + digit > INT_MAX
  
  情況 1：result > INT_MAX / 10
    → result * 10 已經 > INT_MAX
    → 一定溢出
    
  情況 2：result == INT_MAX / 10 且 digit > 7
    → result * 10 = 2147483640
    → 加上 digit > 7 會 > 2147483647
    → 溢出
    
負數溢出：
  result * 10 + digit < INT_MIN
  
  情況 1：result < INT_MIN / 10
    → result * 10 已經 < INT_MIN
    → 一定溢出
    
  情況 2：result == INT_MIN / 10 且 digit < -8
    → result * 10 = -2147483640
    → 加上 digit < -8 會 < -2147483648
    → 溢出
```

### 代碼實現（你的解法）

```c
#include <limits.h>

int reverse(int x) {
    int result = 0;
    
    while (x != 0) {
        int digit = x % 10;  // 取最後一位
        x /= 10;              // 去掉最後一位
        
        // 溢出檢查（在乘以 10 之前）
        if (result > INT_MAX/10 || (result == INT_MAX/10 && digit > 7))
            return 0;
        if (result < INT_MIN/10 || (result == INT_MIN/10 && digit < -8))
            return 0;
        
        result = result * 10 + digit;
    }
    
    return result;
}
```

## 🔍 溢出檢查深入理解

### INT_MAX 和 INT_MIN 的特殊性

```
INT_MAX = 2147483647
         └─────┘└┘
         214748364 7

INT_MAX / 10 = 214748364（整數除法，向下取整）

所以：
  如果 result > 214748364
    → result * 10 > 2147483640 > INT_MAX
    → 一定溢出
    
  如果 result == 214748364
    → result * 10 = 2147483640
    → 還差 7 就到 INT_MAX
    → 如果 digit > 7，會溢出

INT_MIN = -2147483648
         └────────┘└┘
         -214748364 -8

INT_MIN / 10 = -214748364（整數除法，向零取整）

所以：
  如果 result < -214748364
    → result * 10 < -2147483640 < INT_MIN
    → 一定溢出
    
  如果 result == -214748364
    → result * 10 = -2147483640
    → 還差 -8 就到 INT_MIN
    → 如果 digit < -8，會溢出
```

### 為什麼是 7 和 -8？

```
INT_MAX = 2147483647
                   └─ 最後一位是 7

INT_MIN = -2147483648
                    └─ 最後一位是 -8

這不是巧合，這是 32 位整數的定義：
  正數最大值：2^31 - 1 = 2147483647
  負數最小值：-2^31 = -2147483648

所以邊界檢查要用 7 和 -8
```

### 完整的溢出檢查邏輯

```c
// 正數溢出檢查
if (result > INT_MAX/10 || (result == INT_MAX/10 && digit > 7))
    return 0;

// 拆解：
// 條件 1：result > INT_MAX/10
//   → result > 214748364
//   → result * 10 > 2147483640
//   → 已經超過 INT_MAX - 7
//   → 無論 digit 是什麼，都會溢出

// 條件 2：result == INT_MAX/10 && digit > 7
//   → result = 214748364
//   → result * 10 = 2147483640
//   → result * 10 + digit > 2147483640 + 7 = 2147483647
//   → 超過 INT_MAX

// 負數溢出檢查
if (result < INT_MIN/10 || (result == INT_MIN/10 && digit < -8))
    return 0;

// 類似邏輯
```
