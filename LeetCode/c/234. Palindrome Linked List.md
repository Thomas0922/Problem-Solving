# LeetCode 234. Palindrome Linked List - 完整學習筆記

## 📋 題目描述

給定一個單鏈表的頭節點 `head`，請判斷該鏈表是否為**回文鏈表**。

如果是，返回 `true`；否則，返回 `false`。

**範例**：
```
範例 1：
輸入：head = [1,2,2,1]
輸出：true

  1 → 2 → 2 → 1
  從前往後：1 2 2 1
  從後往前：1 2 2 1
  相同 ✓

範例 2：
輸入：head = [1,2]
輸出：false

  1 → 2
  從前往後：1 2
  從後往前：2 1
  不同 ✗
```

**限制**：
- 鏈表中節點數目在範圍 `[1, 10^5]` 內
- `0 <= Node.val <= 9`

**進階要求**：
你能否用 **O(n)** 時間複雜度和 **O(1)** 空間複雜度解決此題？

**關鍵理解**：
```
回文：正著讀和反著讀一樣

回文鏈表：
  1 → 2 → 3 → 2 → 1 ✓
  正：1 2 3 2 1
  反：1 2 3 2 1

非回文鏈表：
  1 → 2 → 3 ✗
  正：1 2 3
  反：3 2 1
```

## 💡 基礎知識：什麼是回文

### 回文的定義

```
回文（Palindrome）：
  正著讀和反著讀都一樣的序列

例子：
  "aba" ✓（回文）
  "abc" ✗（不是回文）
  "abba" ✓（回文）
  "abcd" ✗（不是回文）

數字回文：
  121 ✓
  123 ✗
  1221 ✓
```

### 回文的特點

```
對稱性：
  以中點為軸，左右對稱

奇數長度：
  1 2 3 2 1
      ↑
    中心點

偶數長度：
  1 2 2 1
    ↑ ↑
  兩個中心
```

## 🔧 方法一：數組 + 雙指針（你的解法）

### 思路

1. 將鏈表的值複製到數組中
2. 使用雙指針從兩端向中間比較

### 代碼實現（你的解法）

```c
bool isPalindrome(struct ListNode* head) {
    struct ListNode* list = head;
    int n = 0, count = 0;
    
    // 步驟 1：計算鏈表長度
    while (list) {
        count++;
        list = list->next;
    }
    
    // 步驟 2：將值複製到數組
    int* arr = (int*)malloc(count * sizeof(int));
    while (head) {
        arr[n++] = head->val;
        head = head->next;
    }
    
    // 步驟 3：雙指針判斷回文
    int left = 0, right = n - 1;
    while (left < right) {
        if (arr[left] == arr[right]) {
            left++;
            right--;
        } else {
            free(arr);  // 釋放內存
            return false;
        }
    }
    
    free(arr);
    return true;
}
```

### 執行流程

```
範例：head = [1,2,2,1]

步驟 1：計算長度
  count = 4

步驟 2：複製到數組
  arr = [1, 2, 2, 1]
        ↑        ↑
      left     right

步驟 3：雙指針比較
  left=0, right=3: arr[0]=1, arr[3]=1 ✓
  left=1, right=2: arr[1]=2, arr[2]=2 ✓
  left=2, right=1: left >= right，結束
  
  return true ✓
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(n) | 遍歷兩次 + 比較 |
| **空間複雜度** | O(n) | 需要數組存儲 ❌ |

### 優缺點

**優點**：
- ✅ 邏輯簡單直觀
- ✅ 容易理解和實現
- ✅ 不修改鏈表結構

**缺點**：
- ❌ 需要 O(n) 額外空間
- ❌ 不符合進階要求
- ❌ 需要遍歷兩次

## 🌟 方法二：快慢指針 + 反轉鏈表（最優解）

### 核心思想

```
三個步驟：

1. 用快慢指針找到鏈表中點（876 題）
2. 反轉後半部分鏈表（206 題）
3. 比較前半部分和反轉後的後半部分
```

### 步驟詳解

```
步驟 1：找中點

  1 → 2 → 3 → 2 → 1
          ↑
        slow（中點）

步驟 2：反轉後半部分

  前半：1 → 2 → 3
  後半：3 → 2 → 1（反轉後）

步驟 3：比較

  1 → 2 → 3
  1 → 2 → 3（反轉後的後半）
  
  逐個比較：
  1 == 1 ✓
  2 == 2 ✓
  3 == 3 ✓
  
  return true ✓
```

### 輔助函數：反轉鏈表

```c
struct ListNode* reverseList(struct ListNode* head) {
    struct ListNode* prev = NULL;
    struct ListNode* curr = head;
    
    while (curr) {
        struct ListNode* next = curr->next;
        curr->next = prev;
        prev = curr;
        curr = next;
    }
    
    return prev;
}
```

### 完整代碼實現

```c
bool isPalindrome(struct ListNode* head) {
    if (!head || !head->next) return true;
    
    // 步驟 1：快慢指針找中點
    struct ListNode* slow = head;
    struct ListNode* fast = head;
    
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    
    // 步驟 2：反轉後半部分
    struct ListNode* secondHalf = reverseList(slow);
    
    // 步驟 3：比較前後兩部分
    struct ListNode* p1 = head;
    struct ListNode* p2 = secondHalf;
    
    while (p2) {  // 後半部分可能更短
        if (p1->val != p2->val) {
            return false;
        }
        p1 = p1->next;
        p2 = p2->next;
    }
    
    // 可選：恢復鏈表（如果需要）
    // reverseList(secondHalf);
    
    return true;
}
```

### 執行流程

```

初始：slow = 1, fast = 1

  slow = 2, fast = 3

迭代 2：
  slow = 3, fast = NULL（奇數長度）

slow 停在中點 3

鏈表：1 → 2 → 3 → 2 → 1
              ↑
            slow

═══════════════════════════════════════
步驟 2：反轉後半部分（從 slow 開始）

反轉前：3 → 2 → 1
反轉後：1 → 2 → 3

secondHalf 指向反轉後的頭（1）

═══════════════════════════════════════
步驟 3：比較

前半：1 → 2 → 3
後半：1 → 2 → 3（反轉後）

比較：
  p1=1, p2=1 ✓
  p1=2, p2=2 ✓
  p1=3, p2=3 ✓
  p2=NULL，結束

```

## 💡 快慢指針 + 反轉鏈表深入理解

### 為什麼從 slow 開始反轉？

```
奇數長度（5 個節點）：
  1 → 2 → 3 → 2 → 1
          ↑
        slow

  slow 在中點
  反轉 slow 及其後面：3 → 2 → 1 變成 1 → 2 → 3
  
  比較：
  前半：1 → 2 → 3
  後半：1 → 2 → 3（包含中點）
  
偶數長度（4 個節點）：
  1 → 2 → 2 → 1
          ↑
        slow

  slow 在第二個中點
  反轉 slow 及其後面：2 → 1 變成 1 → 2
  
  比較：
  前半：1 → 2
  後半：1 → 2
```

### 為什麼比較時用 p2 作為循環條件？

```c
while (p2) {  // 用 p2
    if (p1->val != p2->val) return false;
    p1 = p1->next;
    p2 = p2->next;
}

為什麼？

奇數長度：
  前半：1 → 2 → 3 → ...
  後半：1 → 2 → 3（反轉後，包含中點）
  
  p2 會先到達 NULL
  因為後半部分包含中點，可能更長或相等

偶數長度：
  前半：1 → 2 → ...
  後半：1 → 2（反轉後）
  
  兩者長度相等
  p2 到達 NULL 時比較完成

使用 p2 可以處理兩種情況 ✓
```

### 反轉鏈表的原理回顧

```
反轉：1 → 2 → 3 → NULL

步驟：
  prev = NULL
  curr = 1

迭代 1：
  next = 2
  1→NULL
  prev = 1
  curr = 2

迭代 2：
  next = 3
  2→1→NULL
  prev = 2
  curr = 3

迭代 3：
  next = NULL
  3→2→1→NULL
  prev = 3
  curr = NULL

結果：3 → 2 → 1 → NULL
返回：prev
```

## ⚠️ 常見錯誤

### 錯誤 1：忘記處理空鏈表

```c
// ❌ 錯誤：沒有檢查空鏈表
bool isPalindrome(struct ListNode* head) {
    struct ListNode* slow = head;  // head 可能為 NULL
    // ...
}

// ✓ 正確：檢查邊界
if (!head || !head->next) return true;
```

### 錯誤 2：反轉整個鏈表

```c
// ❌ 錯誤：反轉整個鏈表
struct ListNode* reversed = reverseList(head);

// 問題：無法比較，因為 head 也被修改了

// ✓ 正確：只反轉後半部分
struct ListNode* secondHalf = reverseList(slow);
```

### 錯誤 3：比較循環條件錯誤

```c
// ❌ 錯誤：用 p1 && p2
while (p1 && p2) {
    if (p1->val != p2->val) return false;
    p1 = p1->next;
    p2 = p2->next;
}

// 問題：奇數長度時 p1 更長，會漏掉中點

// ✓ 正確：用 p2
while (p2) {
    if (p1->val != p2->val) return false;
    p1 = p1->next;
    p2 = p2->next;
}
```

### 錯誤 4：數組方法忘記釋放內存

```c
// ❌ 錯誤：return 前忘記 free
int* arr = (int*)malloc(count * sizeof(int));
// ...
if (arr[left] != arr[right]) {
    return false;  // 忘記 free！
}

// ✓ 正確（你的做法）
if (arr[left] != arr[right]) {
    free(arr);
    return false;
}
```

### 錯誤 5：快慢指針初始化錯誤

```c
// ❌ 錯誤：初始化不同
struct ListNode* slow = head;

// 問題：slow 會停在第一個中點（偶數時）

// ✓ 正確：都從 head 開始

```

#### 問題 1：如何恢復原鏈表？

```c
bool isPalindrome(struct ListNode* head) {
    if (!head || !head->next) return true;
    
    // 找中點
    struct ListNode* slow = head;
    struct ListNode* fast = head;
    
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    
    // 反轉後半部分
    struct ListNode* secondHalf = reverseList(slow);
    struct ListNode* secondHalfCopy = secondHalf;  // 保存用於恢復
    
    // 比較
    bool result = true;
    struct ListNode* p1 = head;
    struct ListNode* p2 = secondHalf;
    
    while (p2) {
        if (p1->val != p2->val) {
            result = false;
            break;
        }
        p1 = p1->next;
        p2 = p2->next;
    }
    
    // 恢復鏈表
    reverseList(secondHalfCopy);
    
    return result;
}
```

#### 問題 2：遞歸方法如何實現？

```c
struct ListNode* frontPointer;

bool recursivelyCheck(struct ListNode* currentNode) {
    if (currentNode) {
        if (!recursivelyCheck(currentNode->next)) {
            return false;
        }
        if (currentNode->val != frontPointer->val) {
            return false;
        }
        frontPointer = frontPointer->next;
    }
    return true;
}

bool isPalindrome(struct ListNode* head) {
    frontPointer = head;
    return recursivelyCheck(head);
}

// 時間：O(n)
// 空間：O(n)（遞歸棧）
```
