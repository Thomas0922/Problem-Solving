# LeetCode 19. Remove Nth Node From End of List - 完整學習筆記

## 📋 題目描述

給定一個鏈表，刪除鏈表的倒數第 `n` 個節點，並且返回鏈表的頭節點。

**範例**：
```
範例 1：
輸入：head = [1,2,3,4,5], n = 2
輸出：[1,2,3,5]

  原鏈表：1 → 2 → 3 → 4 → 5
                      ↑
                  倒數第 2 個
  
  結果：1 → 2 → 3 → 5

範例 2：
輸入：head = [1], n = 1
輸出：[]

範例 3：
輸入：head = [1,2], n = 1
輸出：[1]
```

**限制**：
- 鏈表中節點的數目為 `sz`
- `1 <= sz <= 30`
- `0 <= Node.val <= 100`
- `1 <= n <= sz`

**進階要求**：
你能嘗試使用**一次遍歷**實現嗎？

**關鍵理解**：
```
倒數第 n 個 = 正數第 (length - n + 1) 個

例如：1 → 2 → 3 → 4 → 5（長度 5）
倒數第 2 個 = 正數第 (5-2+1) = 第 4 個

問題：
  方法 1：先計算長度，再遍歷刪除（兩次遍歷）
  方法 2：反转链表处理（三次遍历）
  方法 3：雙指針（一次遍歷）⭐
```

---

## 💡 基礎知識：倒數第 n 個

### 倒數 vs 正數

```
鏈表：1 → 2 → 3 → 4 → 5

正數：
  第 1 個：1
  第 2 個：2
  第 3 個：3
  第 4 個：4
  第 5 個：5

倒數：
  倒數第 1 個：5（最後一個）
  倒數第 2 個：4
  倒數第 3 個：3
  倒數第 4 個：2
  倒數第 5 個：1（第一個）

轉換公式：
  倒數第 n 個 = 正數第 (length - n + 1) 個
```

## 🔧 方法一：反轉鏈表（你的解法）

### 思路

1. 反轉鏈表
2. 從頭開始數第 n 個（就是原來的倒數第 n 個）
3. 刪除該節點
4. 再反轉回來

### 代碼實現（你的解法）

```c
// 反轉鏈表的輔助函數
struct ListNode* reverse(struct ListNode* head) {
    struct ListNode* prev = NULL;
    struct ListNode* curr = head;
    struct ListNode* nex = NULL;
    
    while (curr) {
        nex = curr->next;
        curr->next = prev;
        prev = curr;
        curr = nex;
    }
    
    return prev;
}

struct ListNode* removeNthFromEnd(struct ListNode* head, int n) {
    // 步驟 1：反轉鏈表
    struct ListNode* rev = reverse(head);
    struct ListNode* remove = rev;
    
    // 使用 Dummy Node
    struct ListNode dummy;
    dummy.next = rev;
    struct ListNode* list = &dummy;
    
    // 步驟 2：找到第 n 個節點（原倒數第 n 個）
    for (int i = 1; i < n; i++) {
        remove = remove->next;
    }
    
    // 步驟 3：刪除節點
    while (list && list->next) {
        if (list->next == remove) {
            list->next = list->next->next;
            free(remove);
        } else {
            list = list->next;
        }
    }
    
    // 步驟 4：反轉回來
    return reverse(dummy.next);
}
```

### 執行流程

```
範例：head = [1,2,3,4,5], n = 2

步驟 1：反轉
  原：1 → 2 → 3 → 4 → 5
  反轉後：5 → 4 → 3 → 2 → 1

步驟 2：找到第 2 個節點
  5 → 4 → 3 → 2 → 1
      ↑
    remove（第 2 個）

步驟 3：刪除節點 4
  5 ─────→ 3 → 2 → 1

步驟 4：再反轉回來
  1 → 2 → 3 → 5 ✓
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(n) | 反轉兩次 + 遍歷刪除 |
| **空間複雜度** | O(1) | 只用常數指針 ✓ |

### 優缺點

**優點**：
- ✅ 思路創新
- ✅ 空間 O(1)
- ✅ 使用 Dummy Node
- ✅ 記得 free

**缺點**：
- ❌ 需要反轉鏈表兩次
- ❌ 修改了鏈表結構（中間過程）
- ❌ 不符合進階要求（一次遍歷）

## 🚀 方法二：計算長度（兩次遍歷）

### 思路

1. 第一次遍歷計算長度
2. 計算正數位置：length - n + 1
3. 第二次遍歷刪除

### 代碼實現

```c
struct ListNode* removeNthFromEnd(struct ListNode* head, int n) {
    // 步驟 1：計算長度
    int length = 0;
    struct ListNode* curr = head;
    while (curr) {
        length++;
        curr = curr->next;
    }
    
    // 邊界情況：刪除頭節點
    if (length == n) {
        struct ListNode* temp = head;
        head = head->next;
        free(temp);
        return head;
    }
    
    // 步驟 2：找到倒數第 n+1 個節點
    int stepsToGo = length - n;
    curr = head;
    for (int i = 0; i < stepsToGo - 1; i++) {
        curr = curr->next;
    }
    
    // 步驟 3：刪除
    struct ListNode* temp = curr->next;
    curr->next = curr->next->next;
    free(temp);
    
    return head;
}
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(n) | 遍歷兩次 |
| **空間複雜度** | O(1) | 只用常數指針 ✓ |

## 🌟 方法三：雙指針（最優解）

### 核心思想

```
關鍵洞察：
  使用兩個指針，間隔 n 個節點
  
  fast 指針先走 n 步
  然後 fast 和 slow 同時走
  
  當 fast 到達末尾時：
    slow 在倒數第 n+1 個位置
    刪除 slow->next
```

### 圖解過程

```
範例：[1,2,3,4,5], n = 2

初始：
  Dummy → 1 → 2 → 3 → 4 → 5 → NULL
  ↑
  slow, fast

步驟 1：fast 先走 n 步（2 步）
  Dummy → 1 → 2 → 3 → 4 → 5 → NULL
  ↑           ↑
  slow      fast

步驟 2：fast 和 slow 同時走
  
  迭代 1：
    Dummy → 1 → 2 → 3 → 4 → 5 → NULL
            ↑           ↑
          slow        fast
  
  迭代 2：
    Dummy → 1 → 2 → 3 → 4 → 5 → NULL
                    ↑           ↑
                  slow        fast
  
  迭代 3：
    Dummy → 1 → 2 → 3 → 4 → 5 → NULL
                        ↑           ↑
                      slow        fast

步驟 3：fast 到達 NULL，刪除 slow->next
  Dummy → 1 → 2 → 3 ─────→ 5 → NULL
                        ↑
                      slow

結果：1 → 2 → 3 → 5 ✓
```

### 為什麼間隔 n 個節點？

```
關鍵：
  fast 比 slow 快 n 個節點
  
  當 fast 到達末尾（NULL）時
  slow 在倒數第 n+1 個位置
  
  slow->next 就是倒數第 n 個！

數學證明：
  設總長度為 L
  
  fast 到達 NULL：走了 L 步
  slow 的位置：L - n
  
  倒數第 n 個 = 正數第 (L - n + 1) 個
  slow->next = 正數第 (L - n + 1) 個
  
  正好是倒數第 n 個！✓
```

### 代碼實現

```c
struct ListNode* removeNthFromEnd(struct ListNode* head, int n) {
    // 使用 Dummy Node（處理刪除頭節點的情況）
    struct ListNode dummy;
    dummy.next = head;
    
    struct ListNode* slow = &dummy;
    struct ListNode* fast = &dummy;
    
    // 步驟 1：fast 先走 n 步
    for (int i = 0; i < n; i++) {
        fast = fast->next;
    }
    
    // 步驟 2：fast 和 slow 同時走
    while (fast->next) {
        slow = slow->next;
        fast = fast->next;
    }
    
    // 步驟 3：刪除 slow->next（倒數第 n 個）
    struct ListNode* temp = slow->next;
    slow->next = slow->next->next;
    free(temp);
    
    return dummy.next;
}
```

### 執行流程

```
範例：head = [1,2,3,4,5], n = 2

初始：
  Dummy → 1 → 2 → 3 → 4 → 5 → NULL
  ↑
  slow, fast

═══════════════════════════════════════
步驟 1：fast 先走 n=2 步

i=0: fast = 1
i=1: fast = 2

  Dummy → 1 → 2 → 3 → 4 → 5 → NULL
  ↑           ↑
  slow      fast

═══════════════════════════════════════
步驟 2：同時移動

迭代 1：
  fast->next = 3 ✓
  slow = 1, fast = 3
  
  Dummy → 1 → 2 → 3 → 4 → 5 → NULL
          ↑           ↑
        slow        fast

迭代 2：
  fast->next = 4 ✓
  slow = 2, fast = 4
  
  Dummy → 1 → 2 → 3 → 4 → 5 → NULL
                  ↑           ↑
                slow        fast

迭代 3：
  fast->next = 5 ✓
  slow = 3, fast = 5
  
  Dummy → 1 → 2 → 3 → 4 → 5 → NULL
                      ↑           ↑
                    slow        fast

迭代 4：
  fast->next = NULL ✗
  結束循環

═══════════════════════════════════════
步驟 3：刪除 slow->next（節點 4）

  temp = slow->next = 4
  slow->next = 5
  free(temp)
  
  Dummy → 1 → 2 → 3 ─────→ 5 → NULL

═══════════════════════════════════════
return dummy.next = 1

結果：1 → 2 → 3 → 5 ✓
```

### 處理刪除頭節點

```
範例：head = [1,2], n = 2（刪除頭節點）

初始：
  Dummy → 1 → 2 → NULL
  ↑
  slow, fast

步驟 1：fast 先走 2 步
  fast = 1
  fast = 2
  
  Dummy → 1 → 2 → NULL
  ↑           ↑
  slow      fast

步驟 2：fast->next = NULL，不進入循環

步驟 3：刪除 slow->next（節點 1）
  Dummy ─────→ 2 → NULL

關鍵：Dummy Node 讓頭節點的處理統一！
```

## 💡 雙指針法深入理解

### 為什麼間隔 n 個？

```
關鍵數學：

總長度：L
fast 位置：L（到達 NULL）
slow 位置：L - n（因為間隔 n）

slow->next 的位置：L - n + 1
倒數第 n 個位置：L - n + 1

完美匹配！✓

例子：
  L = 5, n = 2
  slow 位置：5 - 2 = 3（第 3 個）
  slow->next：第 4 個
  倒數第 2 個：5 - 2 + 1 = 第 4 個
  
  吻合！✓
```

### 為什麼用 Dummy Node？

```
問題：如果刪除頭節點怎麼辦？

沒有 Dummy Node：
  需要特殊處理
  if (要刪除頭節點) {
      head = head->next;
  }

有 Dummy Node：
  統一處理
  slow 永遠在要刪除節點的前一個
  
  即使刪除頭節點：
    Dummy → head → ...
    ↑
    slow
    
    刪除：slow->next = slow->next->next
    完美！✓
```

### 為什麼 fast 先走 n 步？

```
目標：slow 要停在倒數第 n+1 個

方法：
  fast 和 slow 間隔 n 個節點
  當 fast 到末尾時
  slow 自然在正確位置

實現：
  fast 先走 n 步（建立間隔）
  然後同時走（保持間隔）
  
簡單優雅！✓
```

```c

## 🎓 總結

**19. Remove Nth Node From End of List 的核心**：

```
問題：刪除倒數第 n 個節點
關鍵：雙指針（間隔 n 個）

最優解法（雙指針）：
struct ListNode dummy;
dummy.next = head;
struct ListNode* slow = &dummy;
struct ListNode* fast = &dummy;

// fast 先走 n 步
for (int i = 0; i < n; i++) {
    fast = fast->next;
}

// 同時走
while (fast->next) {
    slow = slow->next;
    fast = fast->next;
}

// 刪除 slow->next
struct ListNode* temp = slow->next;
slow->next = slow->next->next;
