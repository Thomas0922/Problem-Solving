# LeetCode 143. Reorder List - 完整學習筆記

## 📋 題目描述

給你一個單鏈表的頭節點 `head`，鏈表中的節點按順序為：

L₀ → L₁ → L₂ → ... → Lₙ₋₁ → Lₙ

請將其重新排列後變為：

L₀ → Lₙ → L₁ → Lₙ₋₁ → L₂ → Lₙ₋₂ → ...

不能只是單純的改變節點內部的值，而是需要實際的進行節點交換。

**範例**：
```
範例 1：
輸入：head = [1,2,3,4]
輸出：[1,4,2,3]

原始：1 → 2 → 3 → 4
重排：1 → 4 → 2 → 3
      ↑   ↑   ↑   ↑
      L₀  L₃  L₁  L₂

範例 2：
輸入：head = [1,2,3,4,5]
輸出：[1,5,2,4,3]

原始：1 → 2 → 3 → 4 → 5
重排：1 → 5 → 2 → 4 → 3
      ↑   ↑   ↑   ↑   ↑
      L₀  L₄  L₁  L₃  L₂
```

**限制**：
- 鏈表的長度範圍為 `[1, 5 * 10⁴]`
- `1 <= Node.val <= 1000`

**關鍵理解**：
```
重排規律：
  從頭尾交替取節點

原始：1 → 2 → 3 → 4 → 5
      ↓       ↓       ↓
     頭部    中間    尾部

重排後：
  取頭部第1個：1
  取尾部第1個：5
  取頭部第2個：2
  取尾部第2個：4
  取頭部第3個：3
  
  結果：1 → 5 → 2 → 4 → 3 ✓
```

## 💡 基礎知識：鏈表重排

### 什麼是重排（Reorder）？

```
數組重排很簡單：
  arr = [1,2,3,4,5]
  
  result = []
  left = 0, right = 4
  
  while left <= right:
      result.add(arr[left++])
      if left <= right:
          result.add(arr[right--])
  
  結果：[1,5,2,4,3] ✓

鏈表重排的挑戰：
  - 無法反向訪問（沒有 arr[right]）
  - 無法隨機訪問（沒有下標）
  
  需要技巧：
  1. 找到中點
  2. 反轉後半部分
  3. 交叉合併
```

### 重排的模式

```
偶數長度：[1,2,3,4]
  前半：1,2
  後半：3,4 → 反轉 → 4,3
  
  合併：
    1 → 4
    4 → 2
    2 → 3
    3 → NULL
    
  結果：1 → 4 → 2 → 3 ✓

奇數長度：[1,2,3,4,5]
  前半：1,2,3
  後半：4,5 → 反轉 → 5,4
  
  合併：
    1 → 5
    5 → 2
    2 → 4
    4 → 3
    3 → NULL
    
  結果：1 → 5 → 2 → 4 → 3 ✓
  
規律：
  前半部分總是 >= 後半部分
```

## ✅ 標準三步法（你的解法）⭐⭐⭐⭐⭐

### 核心思路

```
三個步驟：

1. 找中點（快慢指針）
   1 → 2 → 3 → 4 → 5
           ↑
          slow

2. 反轉後半部分
   前半：1 → 2 → 3
   後半：5 → 4（反轉後）

3. 交叉合併
   1 → 5 → 2 → 4 → 3 ✓
```

### 你的代碼（完美！）⭐⭐⭐⭐⭐

```c
void reorderList(struct ListNode* head) {
    // 邊界處理
    if (!head || !head->next) return;
    
    // ═══════════════════════════════════════
    // 步驟 1：快慢指針找中點
    // ═══════════════════════════════════════
    struct ListNode* slow = head;
    struct ListNode* fast = head;
    while(fast && fast->next){
        slow = slow->next;
        fast = fast->next->next;
    }

    // ═══════════════════════════════════════
    // 步驟 2：分割並反轉後半部分
    // ═══════════════════════════════════════
    struct ListNode* curr = slow->next;
    slow->next = NULL;  // 斷開前後兩部分 ⭐
    
    // 反轉後半部分
    struct ListNode* prev = NULL;
    while(curr){
        struct ListNode* nex = curr->next;
        curr->next = prev;
        prev = curr;
        curr = nex;
    }
    
    // ═══════════════════════════════════════
    // 步驟 3：交叉合併兩個鏈表
    // ═══════════════════════════════════════
    struct ListNode* t1 = head;      // 前半部分
    struct ListNode* t2 = prev;      // 反轉後的後半部分

    while(t2){
        // 保存下一個節點
        struct ListNode *p1 = t1->next;
        struct ListNode *p2 = t2->next;
        
        // 交叉連接
        t1->next = t2;
        t2->next = p1;

        // 移動指針
        t1 = p1;
        t2 = p2;
    }
}
```

### 代碼解析

```c
關鍵部分詳解：

1. 快慢指針找中點：
   while(fast && fast->next){
       slow = slow->next;
       fast = fast->next->next;
   }
   → slow 停在中點（偶數）或中間偏左（奇數）

2. 分割鏈表：
   struct ListNode* curr = slow->next;
   slow->next = NULL;  ⭐ 關鍵：斷開連接
   → 前半：head 到 slow
   → 後半：curr 到尾部

3. 反轉後半部分：
   標準的鏈表反轉（206題）
   → prev 是反轉後的頭節點

4. 交叉合併：
   while(t2){  ⭐ 用 t2 作為條件
       // 保存下一個
       p1 = t1->next;
       p2 = t2->next;
       
       // 交叉連接
       t1->next = t2;
       t2->next = p1;
       
       // 移動
       t1 = p1;
       t2 = p2;
   }
   → 為什麼用 t2？因為後半部分可能更短
```

### 為什麼循環條件是 while(t2)？

```
關鍵觀察：

奇數長度（n=5）：
  前半：1,2,3（3個）
  後半：4,5（2個）
  
  前半更長 ✓
  
  合併時：
    1→5, 5→2, 2→4, 4→3
    t2 先變成 NULL
    t1 還剩 3（自動成為尾節點）

偶數長度（n=4）：
  前半：1,2（2個）
  後半：3,4（2個）
  
  長度相等 ✓
  
  合併時：
    1→4, 4→2, 2→3
    t2 和 t1 同時變成 NULL

結論：
  後半部分總是 <= 前半部分
  所以用 while(t2) ✓
  
  如果用 while(t1)：
    奇數時 t1 還有剩餘，會出錯 ✗
```

## 💡 三個步驟深入理解

### 步驟 1：為什麼用快慢指針找中點？

```
快慢指針的原理：

fast 走 2 步，slow 走 1 步
當 fast 到達終點時，slow 在中點

範例：[1,2,3,4,5]

  slow  fast
   ↓     ↓
   1 →  2 → 3 → 4 → 5

迭代 1：
  slow = 2, fast = 3

迭代 2：
  slow = 3, fast = 5

迭代 3：
  fast->next = NULL，停止
  
slow 停在 3（中點）✓

數學證明：
  slow 走了 k 步
  fast 走了 2k 步
  2k ≈ n
  k ≈ n/2（中點）✓
```

### 步驟 2：為什麼要反轉後半部分？

```
目標：實現頭尾交替

原始鏈表：1 → 2 → 3 → 4 → 5

如果不反轉：
  前半：1,2,3
  後半：4,5
  
  無法從後往前取！
  鏈表不支持反向訪問 ✗

反轉後：
  前半：1,2,3
  後半：5,4（反轉）
  
  現在可以交替取：
  取前：1
  取後：5（反轉後的第一個）
  取前：2
  取後：4（反轉後的第二個）
  取前：3
  
  結果：1,5,2,4,3 ✓

本質：
  反轉 = 把「從後往前」變成「從前往後」
```

### 步驟 3：為什麼這樣合併？

```
交叉合併的邏輯：

前半：1 → 2 → 3
後半：5 → 4

目標：1 → 5 → 2 → 4 → 3

步驟：
  1. 取前半第1個：1
  2. 連接後半第1個：1→5
  3. 取後半第1個：5
  4. 連接前半第2個：5→2
  5. 取前半第2個：2
  6. 連接後半第2個：2→4
  7. ...

代碼實現：
  while(t2){
      // 保存下一個
      p1 = t1->next;  // 前半的下一個
      p2 = t2->next;  // 後半的下一個
      
      // 交叉連接
      t1->next = t2;  // 前→後
      t2->next = p1;  // 後→前的下一個
      
      // 移動到下一對
      t1 = p1;
      t2 = p2;
  }

為什麼要保存 p1 和 p2？
  因為 t1->next 會被修改
  如果不保存，會丟失原來的連接
```

```c
    struct ListNode* prev = NULL;
    
    while(head) {
        struct ListNode* next = head->next;
        head->next = prev;
        prev = head;
        head = next;
```

```c
  3. 交叉合併 k 個鏈表
```
