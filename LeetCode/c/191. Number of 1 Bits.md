# LeetCode 191. Number of 1 Bits - 完整學習筆記

## 📋 題目描述

寫一個函數，輸入是一個無符號整數（32 位元），返回其二進制表示中 **'1' 的個數**（也稱為 **Hamming Weight 漢明權重**）。

**範例**：
```
輸入：n = 11
輸出：3
解釋：11 的二進制是 00000000000000000000000000001011，有 3 個 '1'

輸入：n = 128
輸出：1
解釋：128 的二進制是 00000000000000000000000010000000，有 1 個 '1'

輸入：n = 2147483645
輸出：30
解釋：2147483645 的二進制是 01111111111111111111111111111101，有 30 個 '1'
```

**限制**：
- 輸入必須是長度為 `32` 的**二進制串**

**注意**：
- 在某些語言（如 Java）中，沒有無符號整數類型
- 輸入將會被視為有符號整數，但這不影響實現（內部二進制表示相同）

---

## 💡 基礎知識：二進制表示

### 十進制 → 二進制

```
11 (十進制)
= 8 + 2 + 1
= 2³ + 2¹ + 2⁰
= 1011 (二進制)
= 00000000000000000000000000001011 (32 位)
     ↑  ↑  ↑
     有 3 個 '1'
```

### 位運算基礎

| 運算符 | 名稱 | 說明 | 範例 |
|--------|------|------|------|
| `&` | AND（與） | 兩位都是 1 才是 1 | `1 & 1 = 1`, `1 & 0 = 0` |
| `\|` | OR（或） | 至少一位是 1 就是 1 | `1 \| 0 = 1`, `0 \| 0 = 0` |
| `^` | XOR（異或） | 兩位不同為 1 | `1 ^ 0 = 1`, `1 ^ 1 = 0` |
| `~` | NOT（非） | 位取反 | `~1 = 0`, `~0 = 1` |
| `<<` | 左移 | 左移 n 位 | `1 << 2 = 4` (二進制 0001 → 0100) |
| `>>` | 右移 | 右移 n 位 | `4 >> 2 = 1` (二進制 0100 → 0001) |

## 🔧 方法一：模運算 + 除法（直覺解法）

### 思路

把數字看成十進制處理：
- `n % 2` 得到最低位（0 或 1）
- `n / 2` 去掉最低位（相當於右移）

### 代碼實現

```c
int hammingWeight(int n) {
    int count = 0;
    
    while (n) {
        if (n % 2 == 1) {  // 檢查最低位是否為 1
            count++;
        }
        n = n / 2;  // 去掉最低位（右移）
    }
    
    return count;
}
```

### 執行流程

```
n = 11 (二進制：1011)

迭代 1：
  n % 2 = 1 → count = 1
  n / 2 = 5 (二進制：101)

迭代 2：
  n % 2 = 1 → count = 2
  n / 2 = 2 (二進制：10)

迭代 3：
  n % 2 = 0 → count = 2
  n / 2 = 1 (二進制：1)

迭代 4：
  n % 2 = 1 → count = 3
  n / 2 = 0 (二進制：0)

結束：count = 3 ✓
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(log n) 或 O(32) | 最多循環 32 次（32 位元） |
| **空間複雜度** | O(1) | 只用常數空間 |

### 優缺點

**優點**：
- ✅ 邏輯清晰，容易理解
- ✅ 不需要位運算知識
- ✅ 正確性高

**缺點**：
- ❌ 使用算術運算（% 和 /），效率較低
- ❌ 沒有利用位運算的特性

## 🚀 方法二：位運算版本

### 思路

用位運算取代算術運算：
- `n & 1` 檢查最低位（相當於 `n % 2`）
- `n >>= 1` 右移一位（相當於 `n / 2`）

### 代碼實現

```c
int hammingWeight(int n) {
    int count = 0;
    
    while (n) {
        count += n & 1;  // 檢查最低位
        n >>= 1;         // 右移一位
    }
    
    return count;
}
```

### 位運算詳解

#### `n & 1` - 檢查最低位

```
n = 11 (二進制：1011)
1 的二進制：      0001

n & 1 的計算：
    1011
  & 0001
  ------
    0001  → 結果是 1

如果最低位是 0：
    1010
  & 0001
  ------
    0000  → 結果是 0
```

**作用**：取出最低位的值（0 或 1）

#### `n >>= 1` - 右移一位

```
n = 11 (二進制：1011)

n >> 1 的效果：
  1011 → 0101 (去掉最後一位，變成 5)
  
相當於除以 2：
  11 / 2 = 5
```

**作用**：去掉最低位，處理下一位

### 執行流程

```
n = 11 (二進制：1011)

迭代 1：
  n & 1 = 1 → count = 1
  n >>= 1 → n = 5 (二進制：0101)

迭代 2：
  n & 1 = 1 → count = 2
  n >>= 1 → n = 2 (二進制：0010)

迭代 3：
  n & 1 = 0 → count = 2
  n >>= 1 → n = 1 (二進制：0001)

迭代 4：
  n & 1 = 1 → count = 3
  n >>= 1 → n = 0 (二進制：0000)

結束：count = 3 ✓
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(32) = O(1) | 固定 32 次循環 |
| **空間複雜度** | O(1) | 只用常數空間 |

### 優缺點

**優點**：
- ✅ 使用位運算，效率更高
- ✅ 代碼簡潔
- ✅ 更接近底層實現

**缺點**：
- ⚠️ 仍需要循環 32 次（即使只有 1 個 '1'）

## 🌟 方法三：Brian Kernighan 算法（最優解）

### 核心技巧：`n & (n - 1)`

**神奇性質**：
```
n & (n - 1) 的效果：消除 n 最右邊的一個 '1'

範例：
n = 12 (二進制：1100)
n - 1 = 11 (二進制：1011)

n & (n - 1) 計算：
    1100
  & 1011
  ------
    1000  ← 最右邊的 '1' 被消除了！
```

**為什麼？**

```
觀察 n 和 n-1 的關係：

n     = ...1000  (最右邊的 '1' 及其右邊全是 '0')
n - 1 = ...0111  (最右邊的 '1' 變 '0'，右邊的 '0' 全變 '1')

n & (n-1):
  ...1000
& ...0111
---------
  ...0000  ← 最右邊的 '1' 被消除！
```

### 代碼實現

```c
int hammingWeight(int n) {
    int count = 0;
    
    while (n) {
        n = n & (n - 1);  // 消除最右邊的 '1'
        count++;           // 每消除一個 '1'，計數 +1
    }
    
    return count;
}
```

### 執行流程

```
n = 11 (二進制：1011)

迭代 1：
  n & (n-1) = 1011 & 1010 = 1010
  count = 1
  n = 10 (二進制：1010)

迭代 2：
  n & (n-1) = 1010 & 1001 = 1000
  count = 2
  n = 8 (二進制：1000)

迭代 3：
  n & (n-1) = 1000 & 0111 = 0000
  count = 3
  n = 0 (二進制：0000)

結束：count = 3 ✓
```

### 詳細推演

```
n = 11 (二進制：00000000000000000000000000001011)

步驟 1：
  n     = 00000000000000000000000000001011
  n - 1 = 00000000000000000000000000001010
  結果  = 00000000000000000000000000001010 (消除最右邊的 '1')
  
步驟 2：
  n     = 00000000000000000000000000001010
  n - 1 = 00000000000000000000000000001001
  結果  = 00000000000000000000000000001000 (再消除一個 '1')
  
步驟 3：
  n     = 00000000000000000000000000001000
  n - 1 = 00000000000000000000000000000111
  結果  = 00000000000000000000000000000000 (最後一個 '1' 也消除)
  
總共 3 次 → 有 3 個 '1' ✓
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(k) | k = '1' 的個數，最多 32 次 |
| **空間複雜度** | O(1) | 只用常數空間 |

### 優勢

**相比方法二的優勢**：
```
方法二：總是循環 32 次
方法三：只循環 '1' 的個數次

範例：n = 128 (二進制：10000000)
方法二：需要 32 次循環
方法三：只需要 1 次循環！（因為只有 1 個 '1'）
```

**適用場景**：
- ✅ '1' 的個數很少時，效率提升明顯
- ✅ 是業界常用的技巧（面試加分項）

## 🎯 Brian Kernighan 算法深入理解

### 為什麼 `n & (n-1)` 能消除最右邊的 '1'？

#### 數學證明

```
設 n 的二進制表示為：...abc1000
其中最右邊的 '1' 在某個位置，其右邊全是 '0'

n     = ...abc1000
n - 1 = ...abc0111

觀察：
- 最右邊的 '1' 變成 '0'
- 右邊的所有 '0' 變成 '1'
- 左邊的位保持不變

n & (n-1):
  ...abc1000
& ...abc0111
------------
  ...abc0000  ← 最右邊的 '1' 及其右邊全變 '0'
```

#### 特殊情況分析

```
情況 1：n = 8 (1000)
  n - 1 = 7 (0111)
  n & (n-1) = 0000 ✓

情況 2：n = 7 (0111)
  n - 1 = 6 (0110)
  n & (n-1) = 0110 ✓ (消除最右邊的 '1')
  
情況 3：n = 15 (1111)
  n - 1 = 14 (1110)
  n & (n-1) = 1110 ✓ (消除最右邊的 '1')
```

### 應用場景

這個技巧不僅適用於本題，還可以用於：

1. **判斷是否為 2 的冪**：
   ```c
   bool isPowerOfTwo(int n) {
       return n > 0 && (n & (n - 1)) == 0;
   }
   // 2 的冪只有 1 個 '1'，消除後變 0
   ```

2. **統計兩數二進制不同位數**：
   ```c
   int hammingDistance(int x, int y) {
       return hammingWeight(x ^ y);
   }
   ```

3. **清除最低位的連續 '1'**：
   ```c
   int clearLowestOnes(int n) {
       return n & (n + 1);
   }
   ```

## 🔧 方法四：查表法（進階）

### 思路

預先計算所有 8 位數字（0-255）的 '1' 個數，然後分 4 次查表。

### 代碼實現

```c
// 預先計算的查表
int table[256];

void buildTable() {
    for (int i = 0; i < 256; i++) {
        table[i] = (i & 1) + table[i / 2];
    }
}

int hammingWeight(int n) {
    return table[n & 0xff] +           // 第 1 個字節
           table[(n >> 8) & 0xff] +    // 第 2 個字節
           table[(n >> 16) & 0xff] +   // 第 3 個字節
           table[(n >> 24) & 0xff];    // 第 4 個字節
}
```

### 優缺點

**優點**：
- ✅ 固定 4 次查表，速度極快
- ✅ 適合需要大量計算的場景

**缺點**：
- ❌ 需要額外空間（256 個整數）
- ❌ 需要初始化查表
- ❌ 過度設計（本題不需要）

## ⚠️ 常見錯誤

### 錯誤 1：符號問題（C 語言特有）

```c
// ❌ 錯誤：對有符號整數用除法
int hammingWeight(int n) {  // 注意：int 是有符號的
    while (n) {
        count += n % 2;
        n = n / 2;  // 對負數可能有問題
    }
}

// 問題：負數除以 2 的行為在 C 中是「實現定義」的
// 可能導致無限循環

// ✅ 正確：LeetCode 使用 uint32_t（無符號）
int hammingWeight(uint32_t n) {
    // ... 這樣就沒問題
}
```

### 錯誤 2：Brian Kernighan 算法寫錯

```c
// ❌ 錯誤：忘記賦值
while (n) {
    n & (n - 1);  // 沒有賦值！
    count++;
}

// ✅ 正確
while (n) {
    n = n & (n - 1);  // 一定要賦值
    count++;
}
```

### 錯誤 3：位移方向錯誤

```c
// ❌ 錯誤：左移
while (n) {
    count += n & 1;
    n <<= 1;  // 錯誤：應該右移 >>=
}

// ✅ 正確
while (n) {
    count += n & 1;
    n >>= 1;  // 右移
}
```

## 💡 位運算技巧總結

### 常用位運算技巧

| 技巧 | 代碼 | 作用 |
|------|------|------|
| **檢查第 k 位** | `n & (1 << k)` | 檢查第 k 位是否為 1 |
| **設置第 k 位** | `n \| (1 << k)` | 將第 k 位設為 1 |
| **清除第 k 位** | `n & ~(1 << k)` | 將第 k 位設為 0 |
| **切換第 k 位** | `n ^ (1 << k)` | 翻轉第 k 位 |
| **消除最右邊的 1** | `n & (n - 1)` | Brian Kernighan 技巧 ⭐ |
| **取出最右邊的 1** | `n & -n` | 只保留最右邊的 1 |
| **判斷是否為 2 的冪** | `n > 0 && (n & (n-1)) == 0` | 2 的冪只有 1 個 '1' |

### 記憶技巧

```
「減一反轉右，與操作消一」

n - 1：最右邊的 '1' 變 '0'，右邊的 '0' 變 '1'
n & (n-1)：消除最右邊的 '1'
```
