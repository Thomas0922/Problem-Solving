# LeetCode 92. Reverse Linked List II - 完整學習筆記

## 📋 題目描述

給你單鏈表的頭指針 `head` 和兩個整數 `left` 和 `right`，其中 `left <= right`。

請你反轉從位置 `left` 到位置 `right` 的鏈表節點，返回**反轉後的鏈表**。

**範例**：
```
範例 1：
輸入：head = [1,2,3,4,5], left = 2, right = 4
輸出：[1,2,4,3,5]

原始：1 → 2 → 3 → 4 → 5
         └───────┘
          反轉區間
          
結果：1 → 2 → 4 → 3 → 5
         └───────┘
          反轉後

範例 2：
輸入：head = [5], left = 1, right = 1
輸出：[5]
```

**限制**：
- 鏈表中節點數目為 `n`
- `1 <= n <= 500`
- `-500 <= Node.val <= 500`
- `1 <= left <= right <= n`

**進階**：
你可以使用一趟掃描完成反轉嗎？

**關鍵理解**：
```
部分反轉：
  只反轉指定區間的節點
  其他部分保持不變

範例：[1,2,3,4,5], left=2, right=4

  不動  反轉區間   不動
   1 → 2 → 3 → 4 → 5
       ↑       ↑
     left    right
       
  結果：1 → 4 → 3 → 2 → 5
```

## 💡 基礎知識：部分反轉

### 完整反轉 vs 部分反轉

```
206. Reverse Linked List（完整反轉）：
  1 → 2 → 3 → 4 → 5
  反轉全部
  5 → 4 → 3 → 2 → 1

92. Reverse Linked List II（部分反轉）：
  1 → 2 → 3 → 4 → 5
      └───────┘ 只反轉這部分
  1 → 4 → 3 → 2 → 5

區別：
  206：全部反轉
  92：指定區間反轉，需要重新連接
```

### 部分反轉的挑戰

```
需要處理的連接點：

原始：... → pre → L → ... → R → after → ...
              ↑          ↑
            left       right

反轉區間後：L → ... → R
         變成：R → ... → L

需要連接：
  1. pre → R（前驅指向反轉後的頭）
  2. L → after（反轉後的尾指向後繼）
```

## ✅ 正確解法：原地反轉

### 核心思路

```
三個步驟：

1. 找到反轉區間的前驅節點（pre）
2. 反轉區間內的節點
3. 連接三部分：
   - pre → 反轉後的頭
   - 反轉後的尾 → 區間後的節點

關鍵：在原鏈表上操作，不創建新節點 ⭐
```

### 圖解思路

```
原始：dummy → 1 → 2 → 3 → 4 → 5
            pre  ↑       ↑
                left    right

步驟 1：找到 pre（位置 left-1）
  dummy → 1 → 2 → 3 → 4 → 5
          ↑
         pre

步驟 2：保存關鍵節點
  start = 2 (left 位置的節點)
  then = 3 (start 的下一個節點)

步驟 3：反轉操作（頭插法）
  第1次：把 3 插到 pre 後面
    dummy → 1 → 3 → 2 → 4 → 5
            ↑   ↑   ↑
           pre then start

  第2次：把 4 插到 pre 後面
    dummy → 1 → 4 → 3 → 2 → 5
            ↑   ↑       ↑
           pre then    start

結果：dummy → 1 → 4 → 3 → 2 → 5 ✓
```

### 方法一：頭插法（推薦）⭐

```c
struct ListNode* reverseBetween(struct ListNode* head, int left, int right) {
    // 創建 dummy node
    struct ListNode dummy;
    dummy.next = head;
    struct ListNode* pre = &dummy;
    
    // 步驟 1：找到反轉區間的前驅節點
    for (int i = 1; i < left; i++) {
        pre = pre->next;
    }
    
    // 步驟 2：保存關鍵節點
    struct ListNode* start = pre->next;  // 反轉區間的第一個節點
    struct ListNode* then = start->next; // start 的下一個節點
    
    // 步驟 3：頭插法反轉
    // 反轉 right - left 次
    for (int i = 0; i < right - left; i++) {
        // 保存 then 的下一個節點
        start->next = then->next;
        
        // then 插到 pre 後面
        then->next = pre->next;
        pre->next = then;
        
        // 移動 then
        then = start->next;
    }
    
    return dummy.next;
}
```

### 頭插法執行流程

```
範例：[1,2,3,4,5], left=2, right=4

═══════════════════════════════════════
初始狀態：

  dummy → 1 → 2 → 3 → 4 → 5 → NULL
          ↑   ↑   ↑
         pre start then

═══════════════════════════════════════
迭代 1（i=0）：把 3 插到 pre 後面

操作前：
  dummy → 1 → 2 → 3 → 4 → 5
          ↑   ↑   ↑
         pre start then

步驟 1：start.next = then.next
  2 → 4
  
步驟 2：then.next = pre.next
  3 → 2

步驟 3：pre.next = then
  1 → 3

操作後：
  dummy → 1 → 3 → 2 → 4 → 5
          ↑   ↑   ↑   ↑
         pre     start then

解釋：
  3 被"頭插"到 1 後面
  2 被擠到後面
  現在順序是：1 → 3 → 2 → 4 → 5

═══════════════════════════════════════
迭代 2（i=1）：把 4 插到 pre 後面

操作前：
  dummy → 1 → 3 → 2 → 4 → 5
          ↑       ↑   ↑
         pre     start then

步驟 1：start.next = then.next
  2 → 5

步驟 2：then.next = pre.next
  4 → 3

步驟 3：pre.next = then
  1 → 4

操作後：
  dummy → 1 → 4 → 3 → 2 → 5
          ↑   ↑       ↑   ↑
         pre         start then

解釋：
  4 被"頭插"到 1 後面
  3 被擠到後面
  現在順序是：1 → 4 → 3 → 2 → 5

═══════════════════════════════════════
結束：

  right - left = 4 - 2 = 2 次迭代 ✓
  
  結果：dummy → 1 → 4 → 3 → 2 → 5
  
  返回：dummy.next = 1 → 4 → 3 → 2 → 5 ✓
```

### 為什麼頭插法有效？

```
頭插法的本質：
  每次把 then 節點移到 pre 後面
  相當於把後面的節點逐個"提前"

範例：反轉 2 → 3 → 4

初始：
  1 → 2 → 3 → 4 → 5
  ↑   ↑   ↑
 pre start then

第1次頭插：把 3 提到最前
  1 → 3 → 2 → 4 → 5
  
第2次頭插：把 4 提到最前
  1 → 4 → 3 → 2 → 5

結果：
  原來 2→3→4 的順序
  變成 4→3→2 的順序 ✓
  
這就是反轉！
```

### 方法二：標準反轉法

```c
struct ListNode* reverseBetween(struct ListNode* head, int left, int right) {
    struct ListNode dummy;
    dummy.next = head;
    struct ListNode* pre = &dummy;
    
    // 找到反轉區間的前驅
    for (int i = 1; i < left; i++) {
        pre = pre->next;
    }
    
    // 保存區間起點
    struct ListNode* start = pre->next;
    struct ListNode* curr = start;
    struct ListNode* prev = NULL;
    
    // 反轉區間
    for (int i = 0; i <= right - left; i++) {
        struct ListNode* next = curr->next;
        curr->next = prev;
        prev = curr;
        curr = next;
    }
    
    // 連接三部分
    pre->next = prev;      // 前驅指向反轉後的頭
    start->next = curr;    // 反轉後的尾指向後繼
    
    return dummy.next;
}
```

### 標準反轉法執行流程

```
範例：[1,2,3,4,5], left=2, right=4

═══════════════════════════════════════
初始狀態：

  dummy → 1 → 2 → 3 → 4 → 5 → NULL
          ↑   ↑
         pre start/curr
         
  prev = NULL

═══════════════════════════════════════
反轉迭代（right - left + 1 = 3 次）

迭代 1（i=0）：
  next = 3
  2 → NULL
  prev = 2
  curr = 3
  
  狀態：NULL ← 2   3 → 4 → 5

迭代 2（i=1）：
  next = 4
  3 → 2
  prev = 3
  curr = 4
  
  狀態：NULL ← 2 ← 3   4 → 5

迭代 3（i=2）：
  next = 5
  4 → 3
  prev = 4
  curr = 5
  
  狀態：NULL ← 2 ← 3 ← 4   5 → NULL

═══════════════════════════════════════
連接三部分：

  pre.next = prev
  → 1.next = 4
  
  start.next = curr
  → 2.next = 5
  
  結果：1 → 4 → 3 → 2 → 5 ✓
```

## 💡 頭插法深入理解

### 頭插法的本質

```
頭插法 = 依次把節點移到最前面

原始：1 → 2 → 3 → 4 → 5
      ↑   └───────┘
     pre   要反轉的區間

目標：1 → 4 → 3 → 2 → 5

過程：
  step 1：把 3 移到 2 前面
    1 → 3 → 2 → 4 → 5
    
  step 2：把 4 移到 3 前面
    1 → 4 → 3 → 2 → 5
    
每次都是"頭插"到 pre 後面
```

### 三步操作詳解

```c
// 頭插法的三個步驟（非常重要）⭐

// 假設當前：pre → start → then → ...

// 步驟 1：斷開 then
start->next = then->next;
// 效果：start 跳過 then，指向 then 的下一個

// 步驟 2：then 插到 pre 後面
then->next = pre->next;
// 效果：then 指向原來 pre 的下一個（即 start）

// 步驟 3：pre 指向 then
pre->next = then;
// 效果：完成頭插，then 現在在最前面

// 結果：pre → then → start → ...
```

### 為什麼 start 不動？

```
關鍵觀察：
  start 始終是反轉區間的第一個節點
  隨著反轉進行，start 會逐漸移到最後

範例：反轉 2 → 3 → 4

初始：
  1 → 2 → 3 → 4 → 5
  ↑   ↑
 pre start

第1次頭插後：
  1 → 3 → 2 → 4 → 5
  ↑       ↑
 pre     start（被擠到後面）

第2次頭插後：
  1 → 4 → 3 → 2 → 5
  ↑           ↑
 pre         start（被擠到最後）

start 不需要移動，自然就到最後了 ⭐
```

## 🎓 總結

**92. Reverse Linked List II 的核心**：

```
問題：反轉鏈表的指定區間
關鍵：找到前驅 + 原地反轉 + 連接

兩種方法：
1. 頭插法（推薦）⭐
   - 依次把節點頭插到 pre 後面
   - 代碼簡潔
   
2. 標準反轉法
   - 先反轉區間
   - 再連接三部分
```

**關鍵記憶點**：
1. ✅ **Dummy Node**：簡化處理，統一邏輯
2. ✅ **找前驅**：pre 是 left-1 位置的節點
3. ✅ **頭插法**：三步操作，重複 right-left 次
4. ✅ **不創建新節點**：原地操作，O(1) 空間
5. ✅ **一趟掃描**：符合進階要求
6. ✅ **保存關鍵節點**：start 和 then/curr

**你的錯誤分析**：
```
❌ 錯誤 1：創建新節點
  → 空間 O(n)，不符合要求
  → 應該原地操作

❌ 錯誤 2：邏輯混亂
  → 步驟太多，指針追蹤困難
  → 應該用簡潔的頭插法

❌ 錯誤 3：dummy 初始化
  → dummy.next 應該指向 head
  → 不是 NULL

❌ 錯誤 4：連接錯誤
  → 反轉後的連接邏輯不清
  → 應該在反轉過程中完成連接

改進方向：
✓ 使用頭插法，代碼更簡潔
✓ 不要創建新節點，原地操作
✓ 理解三步操作的本質
✓ 正確初始化 dummy node
```

**面試要點**：
- 理解部分反轉 vs 完整反轉 ⭐⭐⭐⭐⭐
- 掌握頭插法的三步操作 ⭐⭐⭐⭐⭐
- Dummy node 的正確使用 ⭐⭐⭐⭐
- 不創建新節點，O(1) 空間 ⭐⭐⭐⭐
- 理解 start 節點的作用 ⭐⭐⭐

**記憶口訣**：
```
「假前頭插三步走」

假：Dummy node
前：找到前驅 pre
頭插：頭插法反轉
三步：斷then、插then、連pre

每次頭插，重複 right-left 次
```

**頭插法三步（背下來）**：
```c
start->next = then->next;  // 1. 斷開 then
then->next = pre->next;    // 2. then 插到 pre 後
pre->next = then;          // 3. pre 指向 then
then = start->next;        // 4. 移動 then
```
