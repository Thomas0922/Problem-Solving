# LeetCode 86. Partition List - 完整學習筆記

## 📋 題目描述

給你一個鏈表的頭節點 `head` 和一個特定值 `x`，請你對鏈表進行分隔，使得所有**小於** `x` 的節點都出現在**大於或等於** `x` 的節點之前。

你應當**保留**兩個分區中每個節點的初始相對位置。

**範例**：
```
範例 1：
輸入：head = [1,4,3,2,5,2], x = 3
輸出：[1,2,2,4,3,5]

解釋：
  原始：1 → 4 → 3 → 2 → 5 → 2
  
  小於 3：1, 2, 2
  大於等於 3：4, 3, 5
  
  結果：1 → 2 → 2 → 4 → 3 → 5
        └─小於3─┘ └─大於等於3─┘

範例 2：
輸入：head = [2,1], x = 2
輸出：[1,2]

解釋：
  原始：2 → 1
  
  小於 2：1
  大於等於 2：2
  
  結果：1 → 2
```

**限制**：
- 鏈表中節點的數目在範圍 `[0, 200]` 內
- `-100 <= Node.val <= 100`
- `-200 <= x <= 200`

**關鍵理解**：
```
分隔鏈表 = 按照值分成兩組

重要：
1. 保持相對順序（穩定分隔）
2. 小於 x 的在前，大於等於 x 的在後
3. 不需要排序，只需要分組

範例：[1,4,3,2,5,2], x = 3

  不是：[1,2,2,3,4,5] ✗（排序了）
  而是：[1,2,2,4,3,5] ✓（只分組）
        └───┘ └───┘
        順序  順序
        保持  保持
```

## 💡 基礎知識：鏈表分隔

### 什麼是分隔（Partition）？

```
數組分隔（快速排序的分區）：
  [1,4,3,2,5,2], pivot = 3
  
  把小於 3 的移到左邊
  把大於等於 3 的移到右邊
  
  結果：[1,2,2,4,3,5]
        └───┘ └───┘
        < 3   >= 3

鏈表分隔（本題）：
  1 → 4 → 3 → 2 → 5 → 2
  
  分成兩組：
  小於組：1 → 2 → 2
  大於等於組：4 → 3 → 5
  
  合併：1 → 2 → 2 → 4 → 3 → 5 ✓
```

### 穩定 vs 不穩定分隔

```
穩定分隔（本題要求）：
  保持原有的相對順序
  
  原始：1 → 4 → 3 → 2 → 5 → 2
        ↑       ↑       ↑
        第1個2  第2個2
        
  結果：1 → 2 → 2 → 4 → 3 → 5
        ↑   ↑   ↑
        第1個2保持在前面 ✓

不穩定分隔：
  相對順序可能改變
  
  可能結果：1 → 2 → 2 → ... ✓
  或者：2 → 2 → 1 → ... ✗（本題不允許）
```

## ✅ 方法：雙 Dummy Node（你的解法）⭐

### 核心思想

```
創建兩個獨立的鏈表：
1. less 鏈表：存放所有 < x 的節點
2. greater 鏈表：存放所有 >= x 的節點

遍歷原鏈表：
  根據節點值分配到對應鏈表

最後：
  連接兩個鏈表
```

### 你的代碼（完美！）⭐⭐⭐⭐⭐

```c
struct ListNode* partition(struct ListNode* head, int x) {
    // 創建兩個 dummy node
    struct ListNode less_dummy;
    struct ListNode greater_dummy;
    less_dummy.next = NULL;
    greater_dummy.next = NULL;

    // 兩個指針分別追蹤兩個鏈表的尾部
    struct ListNode *less = &less_dummy;
    struct ListNode *greater = &greater_dummy;
    struct ListNode *list = head;

    // 遍歷原鏈表，分配節點
    while(list){
        if(list->val < x){
            // 小於 x：加到 less 鏈表
            less->next = list;
            less = less->next;
        }else{
            // 大於等於 x：加到 greater 鏈表
            greater->next = list;
            greater = greater->next;
        }
        list = list->next;
    }
    
    // 連接兩個鏈表
    less->next = greater_dummy.next;
    
    // ⭐ 關鍵：斷開 greater 的尾部
    greater->next = NULL;

    return less_dummy.next;
}
```

### 代碼解析

```c
關鍵部分詳解：

1. 兩個 Dummy Node：
   struct ListNode less_dummy;
   struct ListNode greater_dummy;
   → 簡化頭節點處理

2. 兩個追蹤指針：
   struct ListNode *less = &less_dummy;
   struct ListNode *greater = &greater_dummy;
   → 追蹤各自鏈表的尾部

3. 分配節點：
   if(list->val < x){
       less->next = list;
       less = less->next;
   }
   → 根據值分配到對應鏈表
   → 保持原有順序 ✓

4. 連接鏈表：
   less->next = greater_dummy.next;
   → less 鏈表的尾部連接 greater 鏈表的頭部

5. 斷開尾部（非常重要）：
   greater->next = NULL;
   → 避免循環鏈表 ⭐
```

### 為什麼 greater->next = NULL 非常重要？

```
關鍵問題：原鏈表中節點之間的指針還在！

原始鏈表：1 → 4 → 3 → 2 → 5 → 2 → NULL
                          ↑   ↑
                          └───┘
                        原本的連接

重新分配後：
  less: 1 → 2 → 2
  greater: 4 → 3 → 5
  
連接：less->next = greater 的頭
  1 → 2 → 2 → 4 → 3 → 5

但問題來了：
  5 原本指向第二個 2
  5->next 還是指向第二個 2！
  
  結果：1 → 2 → 2 → 4 → 3 → 5 → 2 → ...  💀
                              ↑       ↓
                              └───────┘
                              循環！

解決：greater->next = NULL
  強制把 greater 鏈表的最後一個節點的 next 設為 NULL
  
  結果：1 → 2 → 2 → 4 → 3 → 5 → NULL  ✓
```

### 圖解說明

```
原始鏈表的指針關係：

  1 ─→ 4 ─→ 3 ─→ 2 ─→ 5 ─→ 2 ─→ NULL
  ↑    ↑    ↑    ↑    ↑    ↑
  節點還是同一個節點，指針還在！

重新分配到兩個鏈表：

  less:    1 ─→ 2 ─→ 2
           ↑         ↑
           └─────────┘（這兩個2是同一個嗎？不是！）
           
  greater: 4 ─→ 3 ─→ 5
                    ↑
                    └─→ 還指向第二個2！危險！

連接後（沒有 greater->next = NULL）：

  1 ─→ 2 ─→ 2 ─→ 4 ─→ 3 ─→ 5
            ↑                ↓
            └────────────────┘  循環！💀

連接後（有 greater->next = NULL）：

  1 ─→ 2 ─→ 2 ─→ 4 ─→ 3 ─→ 5 ─→ NULL  ✓
```

## 💡 雙 Dummy Node 技巧深入理解

### 為什麼需要兩個 Dummy Node？

```
問題：如何簡化頭節點處理？

方案 1：特殊處理第一個節點
  if (第一個節點 < x) {
      less_head = 第一個節點;
  } else {
      greater_head = 第一個節點;
  }
  // 複雜！需要判斷哪個為空

方案 2：使用 Dummy Node（你的方法）✓
  less_dummy 和 greater_dummy 都初始化
  所有節點統一處理
  最後返回 less_dummy.next
  
  優點：
  - 邏輯統一
  - 不需要特殊處理
  - 代碼簡潔
```

### Dummy Node 的本質

```
Dummy Node = 假頭節點

作用：
  提供一個穩定的起點
  避免空指針判斷
  簡化邊界處理

範例：
  less_dummy → 1 → 2 → 3
      ↑
    假的頭
    
  真正的頭是 less_dummy.next = 1
  
為什麼有效？
  因為 dummy 始終存在
  不管 less 鏈表是否為空
  less_dummy.next 總是正確的頭節點
```

### 雙指針追蹤技巧

```
為什麼需要 less 和 greater 指針？

less_dummy 是頭：
  less_dummy → 1 → 2 → 3
      ↑
     固定
     
less 是尾（移動）：
  less_dummy → 1 → 2 → 3
                       ↑
                      less
                      
作用：
  less_dummy：記住頭部
  less：追蹤尾部，方便添加新節點
  
添加新節點：
  less->next = 新節點;
  less = less->next;  // 移動到新節點
```

#### 問題 1：如果要分成三組怎麼辦？

```c
// 範例：小於 x、等於 x、大於 x

struct ListNode* partitionThree(struct ListNode* head, int x) {
    struct ListNode less_dummy, equal_dummy, greater_dummy;
    less_dummy.next = equal_dummy.next = greater_dummy.next = NULL;
    
    struct ListNode *less = &less_dummy;
    struct ListNode *equal = &equal_dummy;
    struct ListNode *greater = &greater_dummy;
    
    while (head) {
        if (head->val < x) {
            less->next = head;
            less = less->next;
        } else if (head->val == x) {
            equal->next = head;
            equal = equal->next;
        } else {
            greater->next = head;
            greater = greater->next;
        }
        head = head->next;
    }
    
    // 連接三組
    less->next = equal_dummy.next;
    equal->next = greater_dummy.next;
    greater->next = NULL;
    
    return less_dummy.next;
}
```
