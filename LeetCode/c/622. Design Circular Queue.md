# LeetCode 622. Design Circular Queue - 完整學習筆記

## 📋 題目描述

設計你的循環隊列實現。循環隊列是一種線性數據結構，其操作表現基於 FIFO（先進先出）原則並且隊尾被連接在隊首之後以形成一個循環。它也被稱為"環形緩衝器"。

循環隊列的一個好處是我們可以利用這個隊列之前用過的空間。在一個普通隊列裡，一旦一個隊列滿了，我們就不能插入下一個元素，即使在隊列前面仍有空間。但是使用循環隊列，我們能使用這些空間去存儲新的值。

你的實現應該支持如下操作：
- `MyCircularQueue(k)`: 構造器，設置隊列長度為 k
- `Front`: 從隊首獲取元素。如果隊列為空，返回 -1
- `Rear`: 獲取隊尾元素。如果隊列為空，返回 -1
- `enQueue(value)`: 向循環隊列插入一個元素。如果成功插入則返回真
- `deQueue()`: 從循環隊列中刪除一個元素。如果成功刪除則返回真
- `isEmpty()`: 檢查循環隊列是否為空
- `isFull()`: 檢查循環隊列是否已滿

**範例**：
```
MyCircularQueue circularQueue = new MyCircularQueue(3);
circularQueue.enQueue(1);  // 返回 true
circularQueue.enQueue(2);  // 返回 true
circularQueue.enQueue(3);  // 返回 true
circularQueue.enQueue(4);  // 返回 false，隊列已滿
circularQueue.Rear();      // 返回 3
circularQueue.isFull();    // 返回 true
circularQueue.deQueue();   // 返回 true
circularQueue.enQueue(4);  // 返回 true
circularQueue.Rear();      // 返回 4
```

**限制**：
- 所有的值都在 0 至 1000 的範圍內
- 操作數將在 1 至 1000 的範圍內
- 請不要使用內置的隊列庫

**關鍵理解**：
```
循環隊列 vs 普通隊列：

普通隊列：
  [1] [2] [3] [ ] [ ]
   ↑       ↑
  front   rear
  
  deQueue 3 次後：
  [ ] [ ] [ ] [ ] [ ]
           ↑   ↑
         front rear
  
  問題：前面的空間浪費了 ✗

循環隊列：
  [1] [2] [3] [ ] [ ]
   ↑       ↑
  front   rear
  
  deQueue 3 次後：
  [ ] [ ] [ ] [ ] [ ]
           ↑
        front=rear
  
  enQueue(4), enQueue(5)：
  [5] [ ] [ ] [4] [ ]
       ↑       ↑
      rear   front
  
  利用了前面的空間 ✓ ⭐
```

## 💡 基礎知識：循環隊列

### 什麼是循環隊列？

```
普通隊列：
  線性結構
  [0] → [1] → [2] → [3] → [4]
  
  問題：
  - 一旦 rear 到達末尾
  - 即使前面有空間
  - 也無法繼續 enqueue

循環隊列：
  環形結構
  
      [0]
    ↙   ↘
  [4]   [1]
   ↑     ↓
  [3] ← [2]
  
  特點：
  - 尾部連接到頭部
  - 形成一個環
  - 可以循環利用空間 ⭐
```

### 為什麼需要循環隊列？

```
場景：生產者-消費者問題

普通隊列：
  capacity = 5
  
  enQueue 5 次：滿了
  [1] [2] [3] [4] [5]
   ↑               ↑
  front          rear
  
  deQueue 3 次：
  [ ] [ ] [ ] [4] [5]
           ↑       ↑
         front   rear
  
  enQueue(6)：✗ 失敗
  雖然前面有 3 個空位
  但 rear 已經在末尾
  
循環隊列：
  enQueue(6), enQueue(7), enQueue(8)：✓ 成功
  [6] [7] [8] [4] [5]
       ↑       ↑
      rear   front
  
  空間得到充分利用 ⭐
```

## ✅ 你的解法：循環鏈表實現（優秀！）⭐⭐⭐⭐⭐

### 核心思想

```
使用循環鏈表：

結構：
  rear → [3] → [1] → [2] → (回到 [3])
         ↑            ↑
        rear        front
        
特點：
  - 最後一個節點的 next 指向 front
  - 形成一個環
  - front 和 rear 指針標記位置
  - size 追蹤當前元素數量
  - capacity 限制最大容量
```

### 你的代碼（完美！）⭐⭐⭐⭐⭐

```c
typedef struct Node {
    int val;
    struct Node* next;
} Node;

typedef struct {
    Node* rear;      // 隊尾指針
    Node* front;     // 隊首指針
    int size;        // 當前大小
    int capacity;    // 最大容量
} MyCircularQueue;

// ═══════════════════════════════════════
// 創建：O(1)
// ═══════════════════════════════════════
MyCircularQueue* myCircularQueueCreate(int k) {
    MyCircularQueue* obj = (MyCircularQueue*)malloc(sizeof(MyCircularQueue));
    obj->front = NULL;
    obj->rear = NULL;
    obj->size = 0;
    obj->capacity = k;
    return obj;
}

// ═══════════════════════════════════════
// isEmpty：O(1)
// ═══════════════════════════════════════
bool myCircularQueueIsEmpty(MyCircularQueue* obj) {
    return (obj->front == NULL);
}

// ═══════════════════════════════════════
// isFull：O(1)
// ═══════════════════════════════════════
bool myCircularQueueIsFull(MyCircularQueue* obj) {
    return obj->size == obj->capacity;
}

// ═══════════════════════════════════════
// EnQueue：O(1) ⭐
// ═══════════════════════════════════════
bool myCircularQueueEnQueue(MyCircularQueue* obj, int value) {
    // 檢查是否滿了
    if(obj->size == obj->capacity){
        return false;
    }

    // 創建新節點
    Node* new = (Node*)malloc(sizeof(Node));
    new->val = value;
    
    // 情況 1：隊列為空
    if(myCircularQueueIsEmpty(obj)){
        new->next = new;  // 自己指向自己 ⭐
        obj->front = obj->rear = new; 
    }
    // 情況 2：隊列不為空
    else{
        new->next = obj->front;      // 新節點指向 front
        obj->rear->next = new;       // 原 rear 指向新節點
        obj->rear = new;             // 更新 rear
    }
    
    obj->size++;
    return true;
}

// ═══════════════════════════════════════
// DeQueue：O(1) ⭐
// ═══════════════════════════════════════
bool myCircularQueueDeQueue(MyCircularQueue* obj) {
    if(myCircularQueueIsEmpty(obj)){
        return false;
    }

    Node* temp = obj->front;
    
    // 情況 1：只有一個元素
    if(obj->size == 1){
        obj->front = obj->rear = NULL;
    }
    // 情況 2：多個元素
    else{
        obj->front = temp->next;         // 更新 front
        obj->rear->next = obj->front;    // 保持循環 ⭐
    }
    
    free(temp);
    obj->size--;
    return true;
}

// ═══════════════════════════════════════
// Front：O(1)
// ═══════════════════════════════════════
int myCircularQueueFront(MyCircularQueue* obj) {
    if(myCircularQueueIsEmpty(obj)){
        return -1;
    }
    return obj->front->val;
}

// ═══════════════════════════════════════
// Rear：O(1)
// ═══════════════════════════════════════
int myCircularQueueRear(MyCircularQueue* obj) {
    if(myCircularQueueIsEmpty(obj)){
        return -1;
    }
    return obj->rear->val;    
}

// ═══════════════════════════════════════
// Free：O(n)
// ═══════════════════════════════════════
void myCircularQueueFree(MyCircularQueue* obj) {
    while(!myCircularQueueIsEmpty(obj)){
        myCircularQueueDeQueue(obj);  // 逐個釋放
    }
    free(obj);
}
```

## 🔄 方法二：數組實現（對比）

### 核心思想

```
使用固定大小的數組：

數組：[_] [_] [_] [_] [_]
      
指針：
  front：隊首索引
  rear：隊尾索引
  
循環：
  (rear + 1) % capacity
  (front + 1) % capacity
```

### 數組實現代碼

```c
typedef struct {
    int* data;
    int front;
    int rear;
    int size;
    int capacity;
} MyCircularQueue;

MyCircularQueue* myCircularQueueCreate(int k) {
    MyCircularQueue* obj = malloc(sizeof(MyCircularQueue));
    obj->data = (int*)malloc(k * sizeof(int));
    obj->front = 0;
    obj->rear = -1;
    obj->size = 0;
    obj->capacity = k;
    return obj;
}

bool myCircularQueueEnQueue(MyCircularQueue* obj, int value) {
    if (obj->size == obj->capacity) return false;
    
    obj->rear = (obj->rear + 1) % obj->capacity;  // 循環 ⭐
    obj->data[obj->rear] = value;
    obj->size++;
    return true;
}

bool myCircularQueueDeQueue(MyCircularQueue* obj) {
    if (obj->size == 0) return false;
    
    obj->front = (obj->front + 1) % obj->capacity;  // 循環 ⭐
    obj->size--;
    return true;
}

int myCircularQueueFront(MyCircularQueue* obj) {
    if (obj->size == 0) return -1;
    return obj->data[obj->front];
}

int myCircularQueueRear(MyCircularQueue* obj) {
    if (obj->size == 0) return -1;
    return obj->data[obj->rear];
}

bool myCircularQueueIsEmpty(MyCircularQueue* obj) {
    return obj->size == 0;
}

bool myCircularQueueIsFull(MyCircularQueue* obj) {
    return obj->size == obj->capacity;
}

void myCircularQueueFree(MyCircularQueue* obj) {
    free(obj->data);
    free(obj);
}
```

## 💡 循環鏈表深入理解

### 為什麼要保持循環性質？

```
關鍵：rear->next 總是指向 front

好處：
  1. 結構一致性
     無論何時都是環形
     
  2. 遍歷方便
     從任何節點都能回到起點
     
  3. 邏輯清晰
     沒有特殊情況
     
範例：
  正常：[1] → [2] → [3]
        ↑           ↓
        └───────────┘
  
  如果不保持循環：
  deQueue 後：[2] → [3] → ?
              ↑
            front
  
  問題：[3]->next 指向哪裡？
  如果是 NULL，就不是循環了 ✗
  
  正確：[2] → [3]
        ↑     ↓
        └─────┘
  
  [3]->next 指向 [2] ✓
```

### 單節點的特殊處理

```c
// 第一個元素
if(myCircularQueueIsEmpty(obj)){
    new->next = new;  // 自己指向自己 ⭐
    obj->front = obj->rear = new;
}
```

**為什麼自己指向自己？**

```
單節點循環鏈表：

     [1] ←┐
     ↑ ↓  │
     └──┘ │
   front  │
   rear   │

這樣：
  1. 保持循環性質 ✓
  2. front->next = rear ✓
  3. rear->next = front ✓
  
完美的循環結構！
```

### deQueue 時維護循環

```c
else{
    obj->front = temp->next;
    obj->rear->next = obj->front;  // ⭐ 關鍵
}
```

**為什麼要更新 rear->next？**

```
deQueue 前：
  [1] → [2] → [3]
  ↑           ↓
  └───────────┘
  front      rear

deQueue 後（不更新）：
  [2] → [3] → [1]  ❌
        ↑     ↓
      front (已刪除)
      
  問題：rear 還指向被刪除的節點

deQueue 後（正確）：
  [2] → [3]
  ↑     ↓
  └─────┘
  front rear
  
  rear->next = front ✓
  循環性質保持
```
