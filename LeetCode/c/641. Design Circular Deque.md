# LeetCode 641. Design Circular Deque - 完整學習筆記

## 📋 題目描述

設計實現雙端隊列。你的實現需要支持以下操作：

- `MyCircularDeque(k)`: 構造器，設置隊列長度為 k
- `insertFront()`: 將一個元素添加到雙端隊列頭部。如果操作成功返回 true
- `insertLast()`: 將一個元素添加到雙端隊列尾部。如果操作成功返回 true
- `deleteFront()`: 從雙端隊列頭部刪除一個元素。如果操作成功返回 true
- `deleteLast()`: 從雙端隊列尾部刪除一個元素。如果操作成功返回 true
- `getFront()`: 從雙端隊列頭部獲得一個元素。如果隊列為空，返回 -1
- `getRear()`: 獲得雙端隊列的最後一個元素。如果隊列為空，返回 -1
- `isEmpty()`: 檢查雙端隊列是否為空
- `isFull()`: 檢查雙端隊列是否滿了

**範例**：
```
MyCircularDeque circularDeque = new MyCircularDeque(3);
circularDeque.insertLast(1);      // 返回 true
circularDeque.insertLast(2);      // 返回 true
circularDeque.insertFront(3);     // 返回 true
circularDeque.insertFront(4);     // 返回 false，隊列已滿
circularDeque.getRear();          // 返回 2
circularDeque.isFull();           // 返回 true
circularDeque.deleteLast();       // 返回 true
circularDeque.insertFront(4);     // 返回 true
circularDeque.getFront();         // 返回 4
```

**關鍵理解**：
```
雙端隊列（Deque = Double-Ended Queue）

普通隊列：
  只能從尾部 enqueue
  只能從頭部 dequeue
  
雙端隊列：
  可以從兩端 insert
  可以從兩端 delete
  
  ↕ insertFront        ↕ insertLast
  ↕ deleteFront        ↕ deleteLast
  [front] → [2] → [3] → [rear]

更靈活 ⭐
```

## ✅ 你的解法：單向循環鏈表

### 你的代碼分析

```c
typedef struct Node {
    int val;
    struct Node* next;  // 單向
} Node;

// InsertFront：O(1) ✓
bool myCircularDequeInsertFront(MyCircularDeque* obj, int value) {
    if(obj->size == obj->capacity) return false;
    Node* new = malloc(sizeof(Node));
    new->val = value;
    
    if(myCircularDequeIsEmpty(obj)){
        obj->front = obj->rear = new;
        new->next = new;  // 單節點循環
    }else{
        new->next = obj->front;
        obj->front = new;
        obj->rear->next = obj->front;  // 保持循環 ⭐
    }
    obj->size++;
    return true;
}

// DeleteLast：O(n) ⚠️
bool myCircularDequeDeleteLast(MyCircularDeque* obj) {
    if(myCircularDequeIsEmpty(obj)) return false;
    
    // 找到 rear 的前驅節點 ⚠️ O(n) 遍歷
    Node* prev = obj->front;
    while (prev->next != obj->rear) {
        prev = prev->next;
    }
    
    Node* temp = obj->rear;
    if(obj->size == 1){
        obj->front = obj->rear = NULL;
    }else{
        prev->next = obj->front;  // 保持循環
        obj->rear = prev;
    }
    obj->size--;
    free(temp);
    return true;    
}
```

## 🌟 最優解法：雙向循環鏈表

### 核心思想

```
使用雙向循環鏈表：

     [1] ⇄ [2] ⇄ [3]
     ↑             ↓
     └─────────────┘
   front          rear

特點：
  - 雙向鏈表（有 next 和 prev）
  - 循環結構
  - 可以從 rear 直接訪問前驅 ⭐
```

### 完整代碼（雙向鏈表）⭐

```c
typedef struct Node {
    int val;
    struct Node* next;
    struct Node* prev;  // ⭐ 雙向
} Node;

typedef struct {
    Node* front;
    Node* rear;
    int size;
    int capacity;
} MyCircularDeque;

// InsertFront：O(1)
bool myCircularDequeInsertFront(MyCircularDeque* obj, int value) {
    if(obj->size == obj->capacity) return false;
    Node* new = malloc(sizeof(Node));
    new->val = value;
    
    if(obj->size == 0){
        new->next = new;
        new->prev = new;  // 雙向循環
        obj->front = obj->rear = new;
    }else{
        new->next = obj->front;
        new->prev = obj->rear;
        obj->front->prev = new;
        obj->rear->next = new;
        obj->front = new;
    }
    
    obj->size++;
    return true;
}

// InsertLast：O(1)
bool myCircularDequeInsertLast(MyCircularDeque* obj, int value) {
    if(obj->size == obj->capacity) return false;
    Node* new = malloc(sizeof(Node));
    new->val = value;
    
    if(obj->size == 0){
        new->next = new;
        new->prev = new;
        obj->front = obj->rear = new;
    }else{
        new->prev = obj->rear;
        new->next = obj->front;
        obj->rear->next = new;
        obj->front->prev = new;
        obj->rear = new;
    }
    
    obj->size++;
    return true;
}

// DeleteFront：O(1)
bool myCircularDequeDeleteFront(MyCircularDeque* obj) {
    if(obj->size == 0) return false;
    Node* temp = obj->front;
    
    if(obj->size == 1){
        obj->front = obj->rear = NULL;
    }else{
        obj->front = temp->next;
        obj->front->prev = obj->rear;
        obj->rear->next = obj->front;
    }
    
    free(temp);
    obj->size--;
    return true;
}

// DeleteLast：O(1) ⭐⭐⭐
bool myCircularDequeDeleteLast(MyCircularDeque* obj) {
    if(obj->size == 0) return false;
    Node* temp = obj->rear;
    
    if(obj->size == 1){
        obj->front = obj->rear = NULL;
    }else{
        obj->rear = temp->prev;  // ⭐ 直接訪問前驅！
        obj->rear->next = obj->front;
        obj->front->prev = obj->rear;
    }
    
    free(temp);
    obj->size--;
    return true;
}
```

## 💡 為什麼 DeleteLast 在單向鏈表是 O(n)？

### 問題根源

```
單向鏈表的限制：

  [1] → [2] → [3]
  ↑           ↑
front        rear

要刪除 rear（[3]）：
  需要更新 rear = [2]
  但如何找到 [2]？
  
單向鏈表：
  從 [3] 往前看：
    [3]->next = [1]（回到 front）
    無法到達 [2] ✗
  
  必須從 front 開始遍歷：
    [1] → [2] → [3]
          ↑
        找到了
  
  時間：O(n) ⚠️

雙向鏈表：
  [3]->prev = [2]
  直接訪問 O(1) ⭐
```

### 圖解說明

```
單向循環鏈表：

     [1] → [2] → [3]
     ↑           ↓
     └───────────┘
   front        rear

問題：
  從 [3] 如何回到 [2]？
  [3]->next = [1]（回到 front）
  無法直接到 [2] ✗
  
  必須從 [1] 開始走 O(n)

雙向循環鏈表：

     [1] ⇄ [2] ⇄ [3]
     ↑             ↓
     └─────────────┘
   front          rear

解決：
  [3]->prev = [2]
  直接訪問 O(1) ⭐
```

## 🎬 執行流程對比

### 範例：DeleteLast 操作

#### 你的單向鏈表（O(n)）：

```
初始：[1] → [2] → [3]
      ↑           ↑
    front        rear

DeleteLast()：
  
  步驟 1：找前驅 ⚠️
    prev = front = [1]
    檢查：prev->next = [2] ≠ rear
    prev = [2]
    檢查：prev->next = [3] = rear ✓
    找到了！但用了 O(n) 時間
  
  步驟 2：刪除
    [2]->next = [1]（front）
    rear = [2]
    free([3])
  
  結果：[1] → [2]
        ↑     ↓
        └─────┘
      front  rear
```

#### 雙向鏈表（O(1)）：

```
初始：[1] ⇄ [2] ⇄ [3]
      ↑           ↑
    front        rear

DeleteLast()：
  
  步驟 1：直接訪問前驅 ⭐
    rear = temp->prev = [2]
    直接！O(1)
  
  步驟 2：更新指針
    [2]->next = [1]
    [1]->prev = [2]
    free([3])
  
  結果：[1] ⇄ [2]
        ↑     ↓
        └─────┘
      front  rear
```
