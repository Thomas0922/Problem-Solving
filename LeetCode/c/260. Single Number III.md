# LeetCode 260. Single Number III - 完整學習筆記

## 📋 題目描述

給定一個整數數組 `nums`，其中**恰好有兩個元素只出現一次**，其餘所有元素均出現**兩次**。

找出只出現一次的那**兩個**元素。可以按**任意順序**返回答案。

**進階要求**：
- 時間複雜度：O(n)
- 空間複雜度：O(1)

**範例**：
```
輸入：nums = [1,2,1,3,2,5]
輸出：[3,5]
解釋：[5,3] 也是有效答案

輸入：nums = [-1,0]
輸出：[-1,0]

輸入：nums = [0,1]
輸出：[1,0]
```

**限制**：
- `2 <= nums.length <= 3 * 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`
- 除兩個數字外，其餘數字都出現兩次

**關鍵理解**：
```
[1, 2, 1, 3, 2, 5]
       ↑        ↑
    出現 1 次

其他都出現 2 次

目標：找出 3 和 5
```

## 💡 基礎知識：從 136 題到 260 題

### Single Number 系列對比

```
136 題：
  1 個數字出現 1 次，其他出現 2 次
  解法：全部 XOR
  a ^ a ^ b ^ b ^ ... ^ c = c ✓

137 題：
  1 個數字出現 1 次，其他出現 3 次
  解法：位運算狀態機（模 3）

260 題：
  2 個數字出現 1 次，其他出現 2 次
  解法：分組 + 兩次 XOR
```

### 為什麼不能直接用 136 的方法？

```
136 題直接 XOR：
  nums = [1, 2, 1, 3, 2, 5]
  全部 XOR = 1^2^1^3^2^5
           = (1^1)^(2^2)^3^5
           = 0^0^3^5
           = 3^5
           = 6

問題：得到的是 3^5，不是 3 和 5 本身 ❌

需要新方法：如何從 3^5 分離出 3 和 5？
```

## 🔧 方法一：哈希表

### 思路

用哈希表統計每個數字出現次數，找出現 1 次的。

### 代碼實現（C++ 版本）

```cpp
vector<int> singleNumber(vector<int>& nums) {
    unordered_map<int, int> count;
    
    // 統計次數
    for (int num : nums) {
        count[num]++;
    }
    
    // 找出現 1 次的
    vector<int> result;
    for (auto& [num, cnt] : count) {
        if (cnt == 1) {
            result.push_back(num);
        }
    }
    
    return result;
}
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(n) | 兩次遍歷 ✓ |
| **空間複雜度** | O(n) | 哈希表空間 ❌ |

### 優缺點

**優點**：
- ✅ 邏輯簡單直觀
- ✅ 時間複雜度符合要求

**缺點**：
- ❌ 空間複雜度 O(n)，不符合進階要求

## 🚀 方法二：排序

### 思路

排序後，相同的數字會相鄰，遍歷找不重複的。

### 代碼實現

```c
int cmp(const void *a, const void *b) {
    int x = *(int*)a;
    int y = *(int*)b;
    if (x > y) return 1;
    if (x < y) return -1;
    return 0;
}

int* singleNumber(int* nums, int numsSize, int* returnSize) {
    qsort(nums, numsSize, sizeof(int), cmp);
    
    int* result = (int*)malloc(2 * sizeof(int));
    int idx = 0;
    
    for (int i = 0; i < numsSize; ) {
        if (i == numsSize - 1 || nums[i] != nums[i+1]) {
            result[idx++] = nums[i];
            i++;
        } else {
            i += 2;  // 跳過相同的兩個
        }
    }
    
    *returnSize = 2;
    return result;
}
```

### 複雜度分析

| 項目 | 複雜度 | 說明 |
|------|--------|------|
| **時間複雜度** | O(n log n) | 排序的複雜度 ❌ |
| **空間複雜度** | O(1) or O(log n) | qsort 棧空間 |

### 優缺點

**優點**：
- ✅ 邏輯清晰
- ✅ 空間接近 O(1)

**缺點**：
- ❌ 時間複雜度 O(n log n)，不符合要求
- ❌ 修改了原數組

## 🌟 方法三：位運算分組（最優解 - 你的解法）

### 核心思想

```
關鍵洞察：
1. 全部 XOR → 得到 a ^ b
2. a ^ b 中為 1 的位 → a 和 b 在該位不同
3. 用這個「不同」分組 → a 和 b 分到不同組
4. 每組 XOR → 得到答案
```

### 完整推導過程

#### 第一步：全部 XOR

```
問題：兩個數字出現 1 次，如何分離？

觀察：
  nums = [1, 2, 1, 3, 2, 5]
  
  全部 XOR:
  1 ^ 2 ^ 1 ^ 3 ^ 2 ^ 5
  = (1^1) ^ (2^2) ^ 3 ^ 5
  = 0 ^ 0 ^ 3 ^ 5
  = 3 ^ 5

結果：得到兩個單獨數字的 XOR
```

#### 第二步：分析 a ^ b

```
a = 3 = 011
b = 5 = 101
-----------
a^b = 110

關鍵發現：
  a^b 中為 1 的位 = a 和 b 在該位「不同」

例如：
  第 1 位：a[1]=1, b[1]=0 → 不同 → a^b[1]=1 ✓
  第 2 位：a[2]=1, b[2]=1 → 相同 → a^b[2]=0 ✓
  第 0 位：a[0]=1, b[0]=1 → 相同 → a^b[0]=0 ✓
```

#### 第三步：選一個不同的位

```
既然 a 和 b 在某些位不同...

策略：
  選擇 a^b 中「任意一個為 1 的位」
  用這個位把數組分成兩組

為什麼可行？
  - a 和 b 在該位必定不同 → 會分到不同組
  - 其他數字出現 2 次，相同的會在同一組
```

#### 第四步：如何快速找到一個為 1 的位？

```
技巧：x & (-x) 取出最右邊的 1

原理：
  x      = ...abc1000  (最右邊的1)
  -x     = ...xyz1000  (補碼)
  x & -x = ...0001000  (只保留最右邊的1)

例子：
  x = 110 (二進制)
  
  x      = 00000110
  -x     = 11111010  (補碼：取反+1)
  x & -x = 00000010  ← 最右邊的1
```

#### 第五步：分組並 XOR

```
用選定的位分組：

組1：該位是 0 的數字
組2：該位是 1 的數字

每組內全部 XOR：
  組1：出現 2 次的消掉 + a 或 b 其中一個
  組2：出現 2 次的消掉 + a 或 b 另一個

完美！✓
```

### 代碼實現

```c
int* singleNumber(int* nums, int numsSize, int* returnSize) {
    int* result = (int*)malloc(2 * sizeof(int));
    if (!result) return NULL;
    
    // 步驟 1：全部 XOR，得到 a ^ b
    int xor_result = 0;
    for (int i = 0; i < numsSize; i++) {
        xor_result ^= nums[i];
    }
    
    // 步驟 2：找到 a 和 b 不同的某一位（最右邊的 1）
    unsigned int diff = (unsigned int)xor_result & -(unsigned int)xor_result;
    
    // 步驟 3 & 4：分組並 XOR
    int a = 0, b = 0;
    for (int i = 0; i < numsSize; i++) {
        if (nums[i] & diff) {
            a ^= nums[i];  // 該位是 1 的組
        } else {
            b ^= nums[i];  // 該位是 0 的組
        }
    }
    
    *returnSize = 2;
    result[0] = a;
    result[1] = b;
    return result;
}
```

### 執行流程詳解

```
範例：nums = [1, 2, 1, 3, 2, 5]

════════════════════════════════════════════
步驟 1：全部 XOR

xor_result = 0

i=0: xor_result = 0 ^ 1 = 1 (001)
i=1: xor_result = 1 ^ 2 = 3 (011)
i=2: xor_result = 3 ^ 1 = 2 (010)
i=3: xor_result = 2 ^ 3 = 1 (001)
i=4: xor_result = 1 ^ 2 = 3 (011)
i=5: xor_result = 3 ^ 5 = 6 (110)

xor_result = 6 (110) = 3 ^ 5

════════════════════════════════════════════
步驟 2：找最右邊的 1

xor_result = 110 (二進制)
-xor_result = ...11111010 (補碼)

xor_result & -xor_result:
    00000110
  & 11111010
  ----------
    00000010

diff = 2 (010) → 用第 1 位分組

════════════════════════════════════════════
步驟 3：分組並 XOR

用第 1 位分組（從右往左第 2 位）：

檢查每個數字：
  1 = 001, 第1位=0 → b組
  2 = 010, 第1位=1 → a組
  1 = 001, 第1位=0 → b組
  3 = 011, 第1位=1 → a組
  2 = 010, 第1位=1 → a組
  5 = 101, 第1位=0 → b組

a組：[2, 3, 2]
  a = 0 ^ 2 ^ 3 ^ 2
    = 2 ^ 3 ^ 2
    = 3 ✓

  b = 0 ^ 1 ^ 1 ^ 5
    = 0 ^ 5
    = 5 ✓

════════════════════════════════════════════
最終答案：[3, 5] ✓
```

### 為什麼一定能正確分組？

```
關鍵：a 和 b 在 diff 位必定不同

假設：
  a 的 diff 位是 0
  b 的 diff 位是 1

則：
  a 會在「該位是 0」的組
  b 會在「該位是 1」的組
  
其他數字：
  每個數字出現 2 次
  兩個相同的數字，該位也相同
  所以會在同一組，XOR 後消掉

結果：
  一組得到 a
  另一組得到 b
  
完美分離！✓
```

## 💡 核心技巧深入理解

### 技巧 1：x & (-x) 取最右邊的 1

#### 數學原理

```
正數的補碼：
  x     = ...abc1000  (最右邊的1及其右邊)
  ~x    = ...xyz0111  (取反)
  -x    = ...xyz1000  (取反+1)

觀察：
  - 最右邊的1保持不變
  - 最右邊的1左邊全部翻轉
  - 最右邊的1右邊全是0

x & -x:
  x     = ...abc1000
  -x    = ...xyz1000
  AND   = ...0001000  ← 只保留最右邊的1
```

#### 詳細推演

```
x = 6 = 110

步驟 1：表示成 32 位
  x = 00000000000000000000000000000110

步驟 2：取反
  ~x = 11111111111111111111111111111001

步驟 3：加 1（得到 -x）
  -x = 11111111111111111111111111111010

步驟 4：AND
  x     = 00000000000000000000000000000110
  -x    = 11111111111111111111111111111010
  AND   = 00000000000000000000000000000010

結果：2 (010) ← 最右邊的1
```

#### 為什麼你的代碼用 unsigned？

```c
unsigned int diff = (unsigned int)xor_result & -(unsigned int)xor_result;
```

**原因：避免有符號整數的未定義行為**

```
問題場景：
  如果 xor_result 是負數...
  
  int x = -6;  // 負數
  -x;          // 對負數取負，可能有問題
  
  C 標準：有符號整數溢出是「未定義行為」

解決方案：
  轉為 unsigned，模運算定義明確
  
  unsigned int ux = (unsigned int)x;
  -ux;  // 安全！補碼運算定義明確
```

**你的寫法是最佳實踐！** ✓

### 技巧 2：為什麼分組一定正確？

#### 數學證明

```
設兩個單獨的數字為 a 和 b

定義：diff = (a ^ b) & -(a ^ b)

性質 1：diff 只有一個位是 1（最右邊的1）

性質 2：a ^ b 在該位是 1
  → a 和 b 在該位必定不同
  → 一個是 0，一個是 1

性質 3：設 a 在該位是 0，b 在該位是 1
  則：
  - a & diff = 0 → a 進入 b 組
  - b & diff ≠ 0 → b 進入 a 組

性質 4：其他數字成對出現
  - 相同的兩個數字，該位也相同
  - 會進入同一組
  - XOR 後消掉

結論：分組必定正確 ✓
```

### 技巧 3：通用模板

```c
// Single Number 系列通用框架

// 136 題（1個單獨，其他2次）：
int singleNumber(int* nums, int numsSize) {
    int result = 0;
    for (int i = 0; i < numsSize; i++) {
        result ^= nums[i];
    }
    return result;
}

// 260 題（2個單獨，其他2次）：
int* singleNumber(int* nums, int numsSize, int* returnSize) {
    // 1. 全部 XOR
    int xor_all = 0;
    for (...) xor_all ^= nums[i];
    
    // 2. 找區分位
    int diff = xor_all & (-xor_all);
    
    // 3. 分組 XOR
    int a = 0, b = 0;
    for (...) {
        if (nums[i] & diff) a ^= nums[i];
        else b ^= nums[i];
    }
    
    return {a, b};
}
```

## ⚠️ 常見錯誤

### 錯誤 1：忘記分組

```c
// ❌ 錯誤：直接 XOR 全部
int* singleNumber(int* nums, int numsSize, int* returnSize) {
    int xor_all = 0;
    for (int i = 0; i < numsSize; i++) {
        xor_all ^= nums[i];
    }
    // 得到 a ^ b，不是 a 和 b ❌
    return {xor_all, 0};  // 錯誤！
}

// ✓ 正確：必須分組
// ...分組邏輯...
```

### 錯誤 2：diff 計算錯誤

```c
// ❌ 錯誤：直接用 xor_result
int diff = xor_result;  // 錯！可能有多個 1

// ❌ 錯誤：用最高位的 1
int diff = 1 << 31;  // 錯！不一定在最高位

// ✓ 正確：用 x & (-x)
unsigned int diff = (unsigned int)xor_result & -(unsigned int)xor_result;
```

### 錯誤 3：分組條件錯誤

```c
// ❌ 錯誤：用 == 判斷
if (nums[i] == diff) {  // 錯！
    a ^= nums[i];
}

// ✓ 正確：用 & 判斷
if (nums[i] & diff) {  // 對！檢查該位是否為 1
    a ^= nums[i];
}
```

### 錯誤 4：忘記初始化

```c
// ❌ 錯誤：沒有初始化
int a, b;  // 未初始化
for (int i = 0; i < numsSize; i++) {
    if (nums[i] & diff) a ^= nums[i];  // 錯！
    else b ^= nums[i];
}

// ✓ 正確：必須初始化為 0
int a = 0, b = 0;  // XOR 的單位元是 0
```

### 錯誤 5：記憶體處理

```c
// ❌ 錯誤：沒有檢查 malloc
int* result = (int*)malloc(2 * sizeof(int));
result[0] = a;  // 如果 malloc 失敗？

// ✓ 正確：檢查 NULL
int* result = (int*)malloc(2 * sizeof(int));
if (!result) return NULL;
result[0] = a;

// ❌ 錯誤：忘記設置 returnSize
// ... 沒有設置 *returnSize

// ✓ 正確：必須設置
*returnSize = 2;
```

## 🎓 位運算技巧總結

### x & (-x) 的深入理解

#### 補碼原理

```
正數補碼 = 原碼
負數補碼 = 反碼 + 1

例子：x = 6

原碼：00000110
反碼：11111001 (~x)
補碼：11111010 (-x = ~x + 1)

x & -x:
  00000110
& 11111010
----------
  00000010
```

#### 為什麼能取出最右邊的 1？

```
關鍵觀察：
  x     = ...abc1000
         從右往左第一個1

取反：
  ~x    = ...xyz0111
         最右邊的1變0，右邊的0變1

加1：
  -x    = ...xyz1000
         進位後，最右邊的1保持，左邊翻轉

AND：
  x     = ...abc1000
  -x    = ...xyz1000
  結果  = ...0001000
         只有最右邊的1保留！
```

### 其他有用的位運算

    if (a != b) {  // 避免相同地址

        *b ^= *a;
        *a ^= *b;
    }
}

## 🏆 總結

**260. Single Number III 的核心**：

```
問題：2 個數字出現 1 次，其他出現 2 次
關鍵：分組 + 兩次 XOR

四步解法：
1. 全部 XOR → 得到 a ^ b
2. 找不同位 → 用 x & (-x)
3. 用該位分組 → a 和 b 分開
4. 每組 XOR → 得到答案

核心技巧：
- XOR 消除重複：a ^ a = 0
- a ^ b 找不同：為 1 的位表示不同
- x & (-x) 取最右邊的 1
- 分組必定正確：a 和 b 該位不同

時間複雜度：O(n)
空間複雜度：O(1)
```

**關鍵記憶點**：
1. ✅ **全部 XOR**：得到 a ^ b
2. ✅ **x & (-x)**：取最右邊的 1
3. ✅ **用該位分組**：a 和 b 必分開
4. ✅ **每組 XOR**：變成 136 題
5. ✅ **unsigned 轉換**：避免未定義行為
6. ✅ **任意為 1 的位都可以**：不限於最右邊

**與 136 的關係**：
```
136 題（基礎）：
  直接 XOR 全部 → 答案

260 題（進階）：
  XOR 得 a^b → 分組 → 兩次 XOR → 兩個答案
```
