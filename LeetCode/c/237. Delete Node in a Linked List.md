# LeetCode 237. Delete Node in a Linked List - 完整學習筆記

## 📋 題目描述

請編寫一個函數，使其可以刪除某個鏈表中給定的（非末尾）節點。傳入函數的**唯一參數**為**要被刪除的節點**。

**重要特殊性**：
- ❌ 不會給你整個鏈表的頭節點 `head`
- ✅ 直接給你要刪除的節點 `node`
- ✅ 保證要刪除的節點**不是**末尾節點

**範例**：
```
範例 1：
輸入：head = [4,5,1,9], node = 5
輸出：[4,1,9]

  原鏈表：4 → 5 → 1 → 9
             ↑
          要刪除
  
  結果：4 → 1 → 9

範例 2：
輸入：head = [4,5,1,9], node = 1
輸出：[4,5,9]
```

**限制**：
- 鏈表中節點的數目範圍是 `[2, 1000]`
- `-1000 <= Node.val <= 1000`
- 鏈表中每個節點的值都是**唯一**的
- 需要被刪除的節點 `node` 是**鏈表中的一個有效節點**，且**不是末尾節點**

**關鍵理解**：
```
這道題非常特殊！

常規刪除節點（203 題）：
  給定：head
  方法：找到 prev，用 prev->next = node->next
  
  prev → node → next
         刪除

本題的特殊性：
  給定：只有 node 本身
  問題：
    1. 沒有 head
    2. 沒有 prev
    3. 無法訪問前一個節點
    4. 怎麼刪除自己？❓
```

## 💡 基礎知識：為什麼這道題特殊

### 常規刪除 vs 本題

```
常規刪除：
  head → ... → prev → node → next
                ↑      ↑      ↑
              知道   要刪   知道
  
  方法：prev->next = next
  需要：prev 指針

本題：
  ? → ? → node → next
              ↑      ↑
          只知道  可訪問
  
  問題：
  ❌ 不知道 head
  ❌ 不知道 prev
  ❌ 無法刪除自己
```

### 為什麼常規方法行不通？

```c
// ❌ 方法 1：無效
void deleteNode(struct ListNode* node) {
    node = NULL;  // 只改變局部變量，沒用！
}

// ❌ 方法 2：危險
void deleteNode(struct ListNode* node) {
    free(node);  // 危險！外部還有指針指向
}

// ❌ 方法 3：無法實現
void deleteNode(struct ListNode* node) {
    prev->next = node->next;  // prev 是誰？不知道！
}

結論：常規方法全部失效！
      需要新思路！💡
```

## 🌟 方法：複製值 + 刪除下一個（你的解法）

### 核心思想

```
既然無法刪除自己，那就"變成"下一個節點！

關鍵洞察：
  1. 無法刪除 node
  2. 但可以刪除 node->next
  3. 複製 next 的值到 node
  4. 刪除 next
  5. node "變身"成了 next ✨
```

### 圖解"變身"過程

```
原鏈表：
  4 → 5 → 1 → 9
      ↑   ↑
    node next
  (要刪除 5)

步驟 1：複製 next 的值
  node->val = next->val
  
  4 → 1 → 1 → 9
      ↑   ↑
    node next
  (node 的值變成 1)

步驟 2：跳過 next
  node->next = next->next
  
  4 → 1 ─────→ 9
      ↑
    node
  (next 被跳過)

步驟 3：釋放 next
  free(next)
  
  4 → 1 → 9
      ↑
    node
  (完成"變身")

結果：
  雖然沒有刪除原節點 5
  但它"變成"了節點 1
  效果等同於刪除！✓
```

### 代碼實現（你的解法）

```c
void deleteNode(struct ListNode* node) {
    // 保存下一個節點（準備刪除它）
    struct ListNode* tmp = node->next;
    
    // 步驟 1：複製 next 的值到 node
    node->val = tmp->val;
    
    // 步驟 2：跳過 next 節點
    node->next = tmp->next;
    
    // 步驟 3：釋放被跳過的節點
    free(tmp);
}
```

### 執行流程

```
範例：head = [4,5,1,9], node = 5

初始：
  4 → 5 → 1 → 9
      ↑
    node

═══════════════════════════════════════
步驟 1：tmp = node->next
  
  tmp 指向節點 1
  
  4 → 5 → 1 → 9
      ↑   ↑
    node tmp

═══════════════════════════════════════
步驟 2：node->val = tmp->val
  
  node->val = 1
  
  4 → 1 → 1 → 9
      ↑   ↑
    node tmp
  (node 的值改變了)

═══════════════════════════════════════
步驟 3：node->next = tmp->next
  
  跳過 tmp
  
  4 → 1 ─────→ 9
      ↑
    node

═══════════════════════════════════════
步驟 4：free(tmp)
  
  釋放原來的節點 1
  
  4 → 1 → 9
      ↑
    node

最終：4 → 1 → 9 ✓
```

| **時間複雜度** | O(1) | 只需常數操作 ✓ |
| **空間複雜度** | O(1) | 只用一個指針 ✓ |

- ✅ **時間 O(1)**：最優

- ✅ **釋放內存**：free(tmp) ⭐⭐

## 💡 "變身"技巧深入理解

### 為什麼可以"變身"？

```
鏈表節點的"身份"是什麼？

不是內存地址！
而是節點的"內容"！

例子：
  原始：node { val: 5, next: X }
  變身：node { val: 1, next: Y }
  
  內存地址沒變
  但從外部看，它已經是另一個節點了！
```

### 為什麼題目保證不是末尾？

```
如果是末尾節點：
  
  4 → 5 → 1 → 9 → NULL
                  ↑
                node
  
  問題：
    node->next = NULL
    無法複製 next 的值
    "變身"技巧失效！❌

所以題目保證：
  要刪除的節點 ≠ 末尾節點
```

### 這個方法的局限性

```
局限性 1：必須有 next
  ✗ 無法刪除末尾節點

局限性 2：改變了節點內容
  如果外部保存了指向 node 的指針
  這些指針看到的值會改變
  
  例子：
    ListNode* ptr = node;
    deleteNode(node);
    printf("%d", ptr->val);  // 值變了！

局限性 3：節點實際沒被刪
  原節點的內存地址還在
  只是內容變了
```

## ⚠️ 常見錯誤

### 錯誤 1：忘記 free

```c
// ❌ 錯誤：內存洩漏
void deleteNode(struct ListNode* node) {
    node->val = node->next->val;
    node->next = node->next->next;
    // 忘記 free！
}

// ✓ 正確（你的做法）
void deleteNode(struct ListNode* node) {
    struct ListNode* tmp = node->next;
    node->val = tmp->val;
    node->next = tmp->next;
    free(tmp);  // 釋放內存 ⭐
}
```

### 錯誤 2：順序錯誤

```c
// ❌ 錯誤：先改 next
void deleteNode(struct ListNode* node) {
    node->next = node->next->next;  // 先改 next
    node->val = node->next->val;    // 錯！next 變了
}

// ✓ 正確：先複製值
node->val = tmp->val;    // 先複製
node->next = tmp->next;  // 後改 next
```

### 錯誤 3：試圖刪除自己

```c
// ❌ 錯誤：無效操作
void deleteNode(struct ListNode* node) {
    free(node);  // 危險！外部還在用
    node = NULL; // 無效！只改變局部變量
}

// ✓ 正確：刪除 next
// 讓自己"變成" next
```

### 錯誤 4：沒保存 tmp

```c
// ⚠️ 可以但不清晰
void deleteNode(struct ListNode* node) {
    node->val = node->next->val;
    struct ListNode* tmp = node->next;
    node->next = node->next->next;
    free(tmp);
}

// ✓ 更好（你的做法）
// 一開始就保存 tmp
struct ListNode* tmp = node->next;
```

### 203. Remove Linked List Elements

// 203 題：常規刪除（有 head）
struct ListNode* removeElements(struct ListNode* head, int val) {
    struct ListNode Dummy;
    Dummy.next = head;
    struct ListNode* curr = &Dummy;
    
    while (curr && curr->next) {
        if (curr->next->val == val) {
            struct ListNode* temp = curr->next;
            curr->next = curr->next->next;
            free(temp);
        } else {
            curr = curr->next;
        }

}

struct ListNode* deleteDuplicates(struct ListNode* head) {

### 進階思考

#### 問題 1：能刪除末尾節點嗎？

```
答案：不能！

原因：
  末尾節點：node → NULL
  
  無法複製 NULL 的值
  "變身"技巧失效

解決：
  必須要有 head 或 prev
  使用常規方法
```

#### 問題 2：雙向鏈表怎麼做？

```c
// 雙向鏈表更簡單
void deleteNode(struct DoubleListNode* node) {
    // 有 prev 指針，可以常規刪除
    if (node->prev) {
        node->prev->next = node->next;
    }
    if (node->next) {
        node->next->prev = node->prev;
    }
    free(node);
}

// 不需要"變身"技巧
```

#### 問題 3：如何避免改變外部指針？

```
問題：
  ListNode* ptr = node;
  deleteNode(node);
  // ptr 指向的值變了
  
解決：
  - 這是這個方法的固有限制
  - 如果需要保持不變，必須用常規方法
  - 需要有 prev 指針
```
