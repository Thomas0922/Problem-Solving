# 學習筆記：LeetCode 217. Contains Duplicate

## 1. 題目說明

**目標**：判斷陣列中是否有重複的元素。

**限制條件**：
- 如果任一值在陣列中出現**至少兩次**，返回 `true`
- 如果每個元素都是唯一的，返回 `false`

**範例**：
```
輸入: nums = [1, 2, 3, 1]
輸出: true
解釋: 1 出現了兩次

輸入: nums = [1, 2, 3, 4]
輸出: false
解釋: 所有元素都是唯一的

輸入: nums = [1, 1, 1, 3, 3, 4, 3, 2, 4, 2]
輸出: true
```

---

## 2. 你的原始解法分析（哈希表計數）

```cpp
#include <unordered_map>

class Solution {
public:
    bool containsDuplicate(vector<int>& nums) {
        unordered_map<int, int> mp;
        
        for(int i = 0; i < nums.size(); i++){
            mp[nums[i]]++;              // 計數器加1
            if(mp[nums[i]] > 1)        // 發現重複立即返回
                return true;
        }
        return false;
    }
};
```

### ✅ 優點

1. **邏輯正確**：能正確檢測重複元素
2. **早期返回**：一旦發現重複就立即返回，不浪費時間
3. **使用 unordered_map**：平均 $O(1)$ 的查詢和插入時間

### ⚠️ 可改進之處

#### 1. 使用了不必要的計數器

```cpp
unordered_map<int, int> mp;  // 儲存 <數值, 出現次數>
mp[nums[i]]++;
```

**問題**：我們只需要知道「是否存在」，不需要知道「出現幾次」。

**改進**：使用 `unordered_set` 更合適！

```cpp
unordered_set<int> seen;  // 只記錄「是否存在」
```

#### 2. 可以更簡潔的寫法

```cpp
// 你的寫法
mp[nums[i]]++;
if(mp[nums[i]] > 1) return true;

// 可以簡化為
if(++mp[nums[i]] > 1) return true;  // 先加再判斷

// 或者使用 set 的 insert 返回值
if(!seen.insert(nums[i]).second) return true;  // 插入失敗代表已存在
```

### 📊 效能分析

| 項目 | 複雜度 |
|------|--------|
| **時間複雜度** | $O(N)$ - 最壞情況遍歷整個陣列 |
| **空間複雜度** | $O(N)$ - 最壞情況需要存 N 個元素 |

## 3. 最佳解法：哈希集合（Hash Set）

### 💡 核心思路

- 使用 `unordered_set` 記錄已見過的數字
- 遍歷陣列，檢查當前數字是否已在集合中
- 如果存在 → 找到重複，返回 `true`
- 如果不存在 → 加入集合，繼續
- 遍歷完畢都沒重複 → 返回 `false`

### 📝 解法 A：使用 find() 檢查

```cpp
#include <unordered_set>

class Solution {
public:
    bool containsDuplicate(vector<int>& nums) {
        unordered_set<int> seen;
        
        for (int num : nums) {
            // 檢查是否已存在
            if (seen.find(num) != seen.end()) {
                return true;  // 找到重複
            }
            // 加入集合
            seen.insert(num);
        }
        
        return false;  // 沒有重複
    }
};
```

**優點**：
- 邏輯清晰易懂
- 明確表達「先查找後插入」的意圖

---

### 📝 解法 B：使用 insert() 的返回值（更簡潔）

```cpp
#include <unordered_set>

class Solution {
public:
    bool containsDuplicate(vector<int>& nums) {
        unordered_set<int> seen;
        
        for (int num : nums) {
            // insert() 返回 pair<iterator, bool>
            // .second 為 true 表示插入成功（元素不存在）
            // .second 為 false 表示插入失敗（元素已存在）
            if (!seen.insert(num).second) {
                return true;  // 插入失敗 = 找到重複
            }
        }
        
        return false;
    }
};
```

**insert() 返回值說明**：
```cpp
pair<iterator, bool> result = seen.insert(num);
// result.first  -> 指向插入元素的迭代器
// result.second -> true(插入成功) 或 false(元素已存在)
```

**優點**：
- 程式碼更簡潔（一行搞定查找和插入）
- 效能稍好（只查找一次）

---

### 📝 解法 C：使用 count() 方法

```cpp
#include <unordered_set>

class Solution {
public:
    bool containsDuplicate(vector<int>& nums) {
        unordered_set<int> seen;
        
        for (int num : nums) {
            // count() 返回元素數量：0(不存在) 或 1(存在)
            if (seen.count(num)) {
                return true;  // count > 0 表示已存在
            }
            seen.insert(num);
        }
        
        return false;
    }
};
```

**count() 說明**：
- 對於 `set`，`count()` 只會返回 0 或 1
- 相比 `find()`，`count()` 更直觀（直接返回數量）
- 效能與 `find()` 相當

---

### 🔍 執行過程圖解

**範例**：`nums = [1, 2, 3, 1]`

```
i=0: num=1
     seen={}, 1 不存在
     seen={1}

i=1: num=2
     seen={1}, 2 不存在
     seen={1, 2}

i=2: num=3
     seen={1, 2}, 3 不存在
     seen={1, 2, 3}

i=3: num=1
     seen={1, 2, 3}, 1 存在！
     返回 true ✓
```

**範例**：`nums = [1, 2, 3, 4]`

```
遍歷完畢: seen={1, 2, 3, 4}
全部元素都是唯一的
返回 false ✓
```

### 📊 效能分析

| 項目 | 複雜度 |
|------|--------|
| **時間複雜度** | $O(N)$ - 遍歷一次，每次操作 $O(1)$ |
| **空間複雜度** | $O(N)$ - 最壞情況存 N 個唯一元素 |

## 4. 替代解法：排序法

### 💡 核心思路

如果陣列有重複元素，排序後相同的元素一定相鄰。

### 📝 程式碼

```cpp
#include <algorithm>

class Solution {
public:
    bool containsDuplicate(vector<int>& nums) {
        // 邊界檢查
        if (nums.size() <= 1) return false;
        
        // 原地排序
        sort(nums.begin(), nums.end());
        
        // 檢查相鄰元素
        for (int i = 1; i < nums.size(); i++) {
            if (nums[i] == nums[i - 1]) {
                return true;  // 發現相鄰重複
            }
        }
        
        return false;
    }
};
```

### 🔍 執行過程

**範例**：`nums = [3, 1, 2, 1, 4]`

```
原始陣列: [3, 1, 2, 1, 4]
排序後:   [1, 1, 2, 3, 4]
          ↑  ↑
          相鄰且相同！返回 true
```

### 📊 效能分析

| 項目 | 複雜度 |
|------|--------|
| **時間複雜度** | $O(N \log N)$ - 排序主導 |
| **空間複雜度** | $O(1)$ 或 $O(\log N)$ - 取決於排序演算法 |

**優點**：
- 空間複雜度低（原地排序）
- 不需要額外資料結構

**缺點**：
- 時間複雜度較高
- **會修改原陣列**（如果不允許修改，需要複製陣列 → 變成 $O(N)$ 空間）

## 5. 邊界條件處理

### 🛡️ 需要考慮的情況

#### 1️⃣ 空陣列

```cpp
nums = []
```

**處理**：空陣列沒有重複元素，返回 `false`

```cpp
if (nums.empty()) return false;
```

#### 2️⃣ 單一元素

```cpp
nums = [1]
```

**處理**：單一元素不可能重複，返回 `false`

```cpp
if (nums.size() <= 1) return false;
```

#### 3️⃣ 所有元素相同

```cpp
nums = [5, 5, 5, 5, 5]
```

**處理**：第一次比較就會發現重複。

#### 4️⃣ 重複在最後

```cpp
nums = [1, 2, 3, 4, 5, 5]
```

**處理**：需要遍歷到最後才能發現。

#### 5️⃣ 負數和零

```cpp
nums = [-1, 0, 1, -1]
```

**處理**：所有解法都自動支援負數。

## 6. 完整版本（含邊界處理）

### 推薦寫法：unordered_set + insert()

```cpp
#include <unordered_set>

class Solution {
public:
    bool containsDuplicate(vector<int>& nums) {
        // 邊界處理：小於 2 個元素不可能重複
        if (nums.size() <= 1) return false;
        
        unordered_set<int> seen;
        
        for (int num : nums) {
            // 嘗試插入，如果失敗表示已存在
            if (!seen.insert(num).second) {
                return true;
            }
        }
        
        return false;
    }
};
```

**特點**：
- ✅ 簡潔高效
- ✅ 時間複雜度 $O(N)$
- ✅ 處理所有邊界情況
- ✅ 一行完成查找和插入

## 7. 常見錯誤

### ❌ 錯誤一：使用 map 而非 set

```cpp
unordered_map<int, int> mp;  // 不必要的計數
```

**問題**：只需要知道「存在與否」，不需要計數。

**修正**：使用 `unordered_set`。

---

### ❌ 錯誤二：排序後沒有檢查邊界

```cpp
sort(nums.begin(), nums.end());
for (int i = 0; i < nums.size(); i++) {  // 錯誤！
    if (nums[i] == nums[i + 1]) return true;  // i+1 可能越界
}
```

**修正**：從索引 1 開始，比較 `nums[i]` 和 `nums[i-1]`。

---

### ❌ 錯誤三：忘記處理空陣列

```cpp
int first = nums[0];  // 空陣列會崩潰
```

**修正**：先檢查 `nums.size()`。

---

### ❌ 錯誤四：使用 set 而非 unordered_set

```cpp
set<int> seen;  // 有序集合，效能較差
```

**問題**：
- `set`：基於紅黑樹，查找 $O(\log N)$
- `unordered_set`：基於哈希表，查找 $O(1)$

**修正**：除非需要有序，否則用 `unordered_set`。

## 9. 各解法的選擇時機

### 🎯 什麼時候用哈希集合？

- ✅ 需要最快的解法
- ✅ 允許使用額外空間
- ✅ 不能修改原陣列
- ✅ **大多數情況的最佳選擇**

### 🎯 什麼時候用排序法？

- ✅ 空間受限（記憶體不足）
- ✅ 可以修改原陣列
- ✅ 陣列規模不大
- ✅ 後續需要有序陣列

### 🎯 什麼時候用暴力法？

- ✅ 陣列非常小（< 10 個元素）
- ✅ 程式碼簡單性優先於效能

## 10. 從你的解法到最佳解法的演進

```cpp
// 階段 1：你的解法（使用 map 計數）
unordered_map<int, int> mp;
mp[nums[i]]++;

unordered_set<int> seen;
```

**進步路徑**：
1. ✅ 選對資料結構（map → set）
2. ✅ 減少操作次數（計數 → 存在檢查）
3. ✅ 善用 API 特性（find + insert → insert 返回值）

## 11. STL 容器選擇指南

### unordered_set vs set

| 特性 | unordered_set | set |
|------|--------------|-----|
| 底層實作 | 哈希表 | 紅黑樹 |
| 查找時間 | O(1) 平均 | O(log N) |
| 插入時間 | O(1) 平均 | O(log N) |
| 是否有序 | ❌ | ✅ |
| 適用場景 | 快速查找 | 需要有序 |

**結論**：本題不需要有序，用 `unordered_set` 最快！

### unordered_set vs unordered_map

| 特性 | unordered_set | unordered_map |
|------|--------------|--------------|
| 儲存內容 | 鍵 | 鍵值對 |
| 記憶體開銷 | 小 | 大 |
| 適用場景 | 存在檢查 | 需要額外資訊 |

**結論**：只需要檢查存在，用 `unordered_set` 更省空間！

## 12. 學習重點總結

1. **選對資料結構**：
   - 只需「存在與否」→ `unordered_set`
   - 需要「計數」→ `unordered_map`

2. **善用 STL API**：
   - `insert().second`：插入成功/失敗
   - `count()`：元素數量
   - `find()`：查找元素

3. **時間換空間**：
   - 哈希表：O(N) 時間、O(N) 空間
   - 排序：O(N log N) 時間、O(1) 空間

4. **邊界處理**：
   - 空陣列、單元素陣列
   - 考慮負數、零

5. **早期返回**：
   - 一旦發現重複立即返回
   - 不浪費無謂的運算
