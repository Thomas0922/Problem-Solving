# 學習筆記：LeetCode 1. Two Sum

## 1. 題目說明

**目標**：在陣列中找出兩個數字，使其和等於目標值 `target`，並回傳這兩個數字的索引。

**限制條件**：
- 每個輸入只會有**唯一解**
- 不能使用同一個元素兩次
- 答案可以任意順序回傳

**範例**：
```
輸入: nums = [2, 7, 11, 15], target = 9
輸出: [0, 1]
解釋: nums[0] + nums[1] = 2 + 7 = 9

輸入: nums = [3, 2, 4], target = 6
輸出: [1, 2]

輸入: nums = [3, 3], target = 6
輸出: [0, 1]
```

---

## 2. 你的原始解法分析（暴力法）

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        vector<int> ans = {};
        for(int i = 0; i < nums.size(); i++){
            for(int j = i; j < nums.size(); j++){  // ⚠️ 應從 i+1 開始
                if((nums[i] + nums[j]) == target && (i != j)){
                    ans.push_back(i);
                    ans.push_back(j);
                }   
            }
        }
        return ans;
    }
};
```

### ✅ 優點
1. **邏輯正確**：能找到正確答案
2. **容易理解**：暴力枚舉所有可能的配對
3. **空間省**：只使用常數額外空間

### ⚠️ 可改進之處

#### 1. 內層迴圈起點問題
```cpp
for(int j = i; j < nums.size(); j++)  // 目前寫法
```

雖然有 `i != j` 檢查，但 `j` 從 `i` 開始會做無用功：
- 當 `j = i` 時，`i != j` 永遠是 false，這次迴圈白跑
- **建議**：直接從 `i+1` 開始

```cpp
for(int j = i + 1; j < nums.size(); j++)  // 改進寫法
```

#### 2. 找到答案後應立即返回
```cpp
if((nums[i] + nums[j]) == target && (i != j)){
    ans.push_back(i);
    ans.push_back(j);
    // ⚠️ 應該加上 return ans; 避免繼續搜尋
}
```

題目保證有唯一解，找到後應該立即返回，不需要繼續迴圈。

#### 3. 不必要的初始化語法
```cpp
vector<int> ans = {};  // 可以簡化
vector<int> ans;       // 更簡潔
```

或者直接：
```cpp
return {i, j};  // 找到後直接返回
```

### 📊 效能分析

| 項目 | 複雜度 |
|------|--------|
| **時間複雜度** | $O(N^2)$ - 雙層迴圈 |
| **空間複雜度** | $O(1)$ - 只用常數空間（不計回傳值） |

**時間複雜度說明**：
- 外層迴圈：N 次
- 內層迴圈：平均 N/2 次
- 總計：$N \times \frac{N}{2} = \frac{N^2}{2} = O(N^2)$

## 3. 改進的暴力法

在不改變演算法的前提下，做小幅優化：

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        // 從 i 開始遍歷
        for (int i = 0; i < nums.size(); i++) {
            // 從 i+1 開始，避免重複和自己配對
            for (int j = i + 1; j < nums.size(); j++) {
                if (nums[i] + nums[j] == target) {
                    return {i, j};  // 找到立即返回
                }
            }
        }
        return {};  // 理論上不會執行（題目保證有解）
    }
};
```

**改進點**：
1. ✅ 內層迴圈從 `i+1` 開始
2. ✅ 移除不必要的 `i != j` 檢查
3. ✅ 找到答案立即返回
4. ✅ 簡化括號和初始化語法

## 4. 最佳解法：哈希表（Hash Map）

### 💡 核心思路

暴力法為什麼慢？因為對於每個 `nums[i]`，都要遍歷剩餘元素找 `target - nums[i]`。

**關鍵洞察**：
- 當遍歷到 `nums[i]` 時，我們需要找的是 `complement = target - nums[i]`
- 如果能**快速查詢** `complement` 是否存在，就能大幅加速
- **哈希表**提供 $O(1)$ 的查詢時間！

### 🎯 演算法步驟

1. 建立哈希表 `map<數值, 索引>`
2. 遍歷陣列，對每個 `nums[i]`：
   - 計算 `complement = target - nums[i]`
   - 檢查 `complement` 是否在哈希表中
   - 如果存在：返回 `[map[complement], i]`
   - 如果不存在：將 `nums[i]` 存入哈希表

### 📝 完整程式碼（含邊界處理）

```cpp
#include <unordered_map>

class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        // 邊界條件：陣列太小
        if (nums.size() < 2) {
            return {};  // 無解
        }
        
        // 哈希表：<數值, 索引>
        unordered_map<int, int> seen;
        
        for (int i = 0; i < nums.size(); i++) {
            int complement = target - nums[i];
            
            // 檢查互補數是否已存在
            if (seen.find(complement) != seen.end()) {
                return {seen[complement], i};
            }
            
            // 將當前數字存入哈希表
            seen[nums[i]] = i;
        }
        
        // 理論上不會執行（題目保證有解）
        return {};
    }
};
```

### 🔍 執行過程圖解

**範例**：`nums = [2, 7, 11, 15], target = 9`

```
i=0: nums[0]=2, complement=7
     seen={}, 7 不存在
     seen={2:0}

i=1: nums[1]=7, complement=2
     seen={2:0}, 2 存在！
     返回 [0, 1] ✓
```

**範例**：`nums = [3, 2, 4], target = 6`

```
i=0: nums[0]=3, complement=3
     seen={}, 3 不存在
     seen={3:0}

i=1: nums[1]=2, complement=4
     seen={3:0}, 4 不存在
     seen={3:0, 2:1}

i=2: nums[2]=4, complement=2
     seen={3:0, 2:1}, 2 存在！
     返回 [1, 2] ✓
```

### 📊 效能分析

| 項目 | 複雜度 |
|------|--------|
| **時間複雜度** | $O(N)$ - 單次遍歷 |
| **空間複雜度** | $O(N)$ - 哈希表最多存 N 個元素 |

**對比暴力法**：
- 時間從 $O(N^2)$ 降到 $O(N)$ 🚀
- 空間從 $O(1)$ 增加到 $O(N)$（時間換空間）

## 5. 邊界條件處理

### 🛡️ 需要考慮的情況

#### 1️⃣ 空陣列或元素不足

```cpp
nums = []          // 大小 0
nums = [5]         // 大小 1
```

**處理**：
```cpp
if (nums.size() < 2) {
    return {};
}
```

#### 2️⃣ 重複元素

```cpp
nums = [3, 3], target = 6
```

**注意**：
- 可以使用同一個**數值**但不同索引
- `[0, 1]` 是正確答案
- 哈希表法會自動處理（後面的 3 會覆蓋前面的 3）

**驗證**：
```
i=0: nums[0]=3, complement=3
     seen={}, 3 不存在
     seen={3:0}

i=1: nums[1]=3, complement=3
     seen={3:0}, 3 存在！
     返回 [0, 1] ✓
```

#### 3️⃣ 負數

```cpp
nums = [-1, -2, -3, -4, -5], target = -8
// 答案: [2, 4] (因為 -3 + -5 = -8)
```

**處理**：無需特別處理，哈希表法自動支援。

#### 4️⃣ 零

```cpp
nums = [0, 4, 3, 0], target = 0
// 答案: [0, 3] (兩個零相加)
```

**處理**：無需特別處理。

#### 5️⃣ 無解的情況

雖然題目保證有唯一解，但穩健的程式碼應該處理：

```cpp
return {};  // 迴圈結束仍未找到
```

## 6. 常見錯誤

### ❌ 錯誤一：使用同一個索引兩次

```cpp
// 錯誤：沒有檢查 i != j
if (nums[i] + nums[j] == target) {
    return {i, j};  // 可能 i == j
}
```

**修正**：確保 `j` 從 `i+1` 開始，或加上 `i != j` 判斷。

### ❌ 錯誤二：哈希表重複寫入

```cpp
// 錯誤：先寫入再檢查
seen[nums[i]] = i;
if (seen.find(complement) != seen.end()) {
    return {seen[complement], i};
}
```

這會導致 `nums = [3, 3], target = 6` 時失敗。

**修正**：先檢查後寫入（如最佳解法所示）。

### ❌ 錯誤三：未考慮陣列大小

```cpp
// 未檢查 nums.size() < 2
int complement = target - nums[0];
```

可能導致存取越界。

## 8. 進階思考

### 💡 如果要找三數之和呢？（3Sum）

- 暴力法：$O(N^3)$
- 優化法：排序 + 雙指標，$O(N^2)$

### 💡 如果陣列已排序呢？

可以使用**雙指標**法：
- 左指標從頭開始
- 右指標從尾開始
- 根據和與目標值的大小移動指標
- 時間複雜度：$O(N)$
- 空間複雜度：$O(1)$（比哈希表更省空間）

## 9. 推薦的最終版本

結合效能與穩健性：

```cpp
#include <unordered_map>

class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        // 邊界檢查
        if (nums.size() < 2) return {};
        
        unordered_map<int, int> seen;
        
        for (int i = 0; i < nums.size(); i++) {
            int complement = target - nums[i];
            
            // 先查詢後插入，避免重複元素問題
            auto it = seen.find(complement);
            if (it != seen.end()) {
                return {it->second, i};
            }
            
            seen[nums[i]] = i;
        }
        
        return {};  // 保險處理
    }
};
```

**特點**：
- ✅ 時間複雜度 $O(N)$
- ✅ 處理所有邊界條件
- ✅ 程式碼簡潔清晰
- ✅ 使用 `auto it` 避免重複查找

## 10. 學習重點總結

1. **暴力法 → 哈希表**：典型的時間換空間優化
2. **先查詢後插入**：避免重複元素導致的錯誤
3. **邊界檢查**：穩健程式碼的必備要素
4. **立即返回**：找到答案就停止，不浪費運算
5. **善用 STL**：`unordered_map` 提供 $O(1)$ 查詢
